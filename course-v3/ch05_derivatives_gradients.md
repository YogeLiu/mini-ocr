## 5.1 斜率

直线 `f(x) = 2x + 1` 上，x 每增加 1，f 增加 2。这个"x 变一点、f 变多少"的比例叫**斜率**：

```
斜率 = Δf / Δx = (f(x₂) − f(x₁)) / (x₂ − x₁)
```

`Δ`（读作 delta）表示"变化量"。直线的斜率处处相同。

但曲线不一样。`f(x) = x²` 在 x = 0 附近很平，在 x = 3 附近很陡。我们想知道**在某一点上**有多陡。

## 5.2 导数：放大后的斜率

### 直觉

把曲线 `f(x) = x²` 在 x = 3 附近不断放大。放大到足够大时，那一小段曲线看起来几乎是一条直线。**这条直线的斜率，就是 f 在 x = 3 处的导数。**

用数字来"放大"：取 x = 3 和旁边的一个点 3 + h，算两点之间的斜率，然后让 h 越来越小。演示第 1 部分（`python -m labs.ch05.calculus_tour`）：

```
  h = 1.0     (f(3+h) - f(3)) / h = 7.000000
  h = 0.1     (f(3+h) - f(3)) / h = 6.100000
  h = 0.01    (f(3+h) - f(3)) / h = 6.010000
  h = 0.001   (f(3+h) - f(3)) / h = 6.001000
```

h 越小，斜率越接近 6。我们说 `f(x) = x²` 在 x = 3 处的导数是 6，写作 `f'(3) = 6`。

### 定义与手算

```
f'(x) = lim_{h→0} (f(x + h) − f(x)) / h
```

`lim_{h→0}` 读作"当 h 趋近于 0 时的极限"，意思是"h 越来越小时，这个式子越来越接近的那个值"。

**手算 `f(x) = x²` 的导数**：

```
(f(x + h) − f(x)) / h = ((x + h)² − x²) / h
                      = (x² + 2xh + h² − x²) / h
                      = (2xh + h²) / h
                      = 2x + h
```

h 趋近于 0 时，`2x + h` 趋近于 `2x`。所以 `(x²)' = 2x`，`f'(3) = 6`。

而且我们还看清了上面数字的规律：斜率恰好是 `6 + h`——h = 0.1 时 6.1，h = 0.01 时 6.01。误差正好是 h。

**另一种记号**：`f'(x)` 也写作 `df/dx`，读作"f 对 x 的导数"。它提醒我们导数的含义：**f 的微小变化 df 与 x 的微小变化 dx 之比**。由此可以得到一个极其有用的近似：

```
f(x + Δx) ≈ f(x) + f'(x) · Δx         （Δx 很小时）
```

x 变一点点，f 大约变 "导数 × 变化量"。梯度下降的全部道理就藏在这个式子里（5.6 节）。

### 导数的符号说明了什么

- `f'(x) > 0`：x 增大时 f 增大（上坡）；
- `f'(x) < 0`：x 增大时 f 减小（下坡）；
- `f'(x) = 0`：在这一点是平的——可能是谷底、山顶，或者一个"平台"。

所以，**想让 f 变小，就让 x 朝导数的反方向走**：导数为正就减小 x，导数为负就增大 x。第 0 章那个 `f(x) = w·x` 的例子就是这样。

## 5.3 求导法则

每次都用定义算太麻烦。下面这些法则覆盖了本书用到的所有函数。

### 基本函数

| 函数 | 导数 | 说明 |
|---|---|---|
| 常数 `c` | `0` | 不变的东西，变化率为 0 |
| `xⁿ` | `n xⁿ⁻¹` | 幂法则：`(x³)' = 3x²`，`(1/x)' = (x⁻¹)' = −x⁻²`，`(√x)' = (x^½)' = ½ x^(−½)` |
| `eˣ` | `eˣ` | e 的特殊之处：导数等于自己 |
| `ln x` | `1/x` | |
| `sin x` / `cos x` | `cos x` / `−sin x` | 本书很少用 |

### 组合法则

| 法则 | 公式 | 例子 |
|---|---|---|
| 数乘 | `(c·f)' = c·f'` | `(3x²)' = 6x` |
| 和 | `(f + g)' = f' + g'` | `(x² + x)' = 2x + 1` |
| 积 | `(f·g)' = f'·g + f·g'` | `(x·eˣ)' = eˣ + x·eˣ` |
| **链式** | `(f(g(x)))' = f'(g(x)) · g'(x)` | `(e^(2x))' = e^(2x) · 2` |

### 链式法则

链式法则处理"函数套函数"。设 `y = f(u)`，`u = g(x)`，那么：

```
dy/dx = dy/du · du/dx
```

**直觉**：x 变一点点，u 变 `du/dx` 倍；u 变一点点，y 变 `dy/du` 倍。所以 x 变一点点，y 变 `dy/du × du/dx` 倍。**变化率沿着链条相乘。**

**手算** `y = (3x + 1)²`：设 `u = 3x + 1`，`y = u²`。`dy/du = 2u`，`du/dx = 3`，所以 `dy/dx = 2u · 3 = 6(3x + 1)`。验证：展开 `y = 9x² + 6x + 1`，`y' = 18x + 6 = 6(3x + 1)`。✓

链条可以任意长：`y = f(g(h(x)))` 时 `dy/dx = f' · g' · h'`（每个导数在对应的位置取值）。神经网络就是几十上百层函数套在一起，它的梯度就是沿着这条长链相乘——第 8 章会让计算机自动完成这件事。

### sigmoid 函数

神经网络里一个重要的函数是 **sigmoid**（也叫 logistic 函数）：

```
σ(z) = 1 / (1 + e^(−z))
```

它把任何实数压到 0 和 1 之间：`σ(0) = 0.5`，z 很大时接近 1，z 很小（很负）时接近 0。第 7 章用它把一个分数变成"是某一类的概率"。

**手算它的导数**（用链式法则）：设 `u = 1 + e^(−z)`，`σ = u⁻¹`。

```
dσ/du = −u⁻²
du/dz = −e^(−z)              （链式法则：e^(−z) 的导数是 e^(−z) · (−1)）
dσ/dz = −u⁻² · (−e^(−z)) = e^(−z) / (1 + e^(−z))²
```

再整理一下。注意 `e^(−z) / (1 + e^(−z)) = 1 − 1/(1 + e^(−z)) = 1 − σ`，所以：

```
σ'(z) = [1 / (1 + e^(−z))] · [e^(−z) / (1 + e^(−z))] = σ(z) · (1 − σ(z))
```

这个结果非常漂亮：sigmoid 的导数可以用它自己的值算出来。`σ'(0) = 0.5 × 0.5 = 0.25`，是导数的最大值；z 很大或很小时，σ 接近 1 或 0，导数接近 0——函数变"平"了。这个"两端变平"的性质会在第 11 章带来**梯度消失**问题。

演示第 7 部分用数值导数验证了表中的每一条（x = 0.7）：

```
  x³        公式导数 1.47000000   数值导数 1.47000000
  eˣ        公式导数 2.01375271   数值导数 2.01375271
  ln x      公式导数 1.42857143   数值导数 1.42857143
  1/x       公式导数 -2.04081633   数值导数 -2.04081633
  √x        公式导数 0.59761430   数值导数 0.59761430
  σ(x)      公式导数 0.22171287   数值导数 0.22171287
  tanh x    公式导数 0.63473959   数值导数 0.63473959
  max(0,x)  公式导数 1.00000000   数值导数 1.00000000
```

最后一行的 `max(0, x)` 叫 **ReLU**，是今天最常用的激活函数（第 10 章）：x > 0 时导数是 1，x < 0 时导数是 0，在 x = 0 处没有导数（左右斜率不同，有个"尖角"），实践中约定取 0。

## 5.4 一个"迷你神经元"的梯度

把这些法则用在一个真正的例子上。一个最简单的"神经元"：

```
z = w·x + b            线性部分（第 4 章的线性层，只有一个输入）
p = σ(z)               把分数变成 0–1 之间的"预测"
L = (p − y)²           损失：预测与正确答案 y 差多少
```

参数是 w 和 b。我们想知道：**w 和 b 各变一点点，L 怎么变？** 也就是 `dL/dw` 和 `dL/db`。

L 通过 p、p 通过 z、z 通过 w，这是一条链：

```
dL/dw = dL/dp · dp/dz · dz/dw
dL/db = dL/dp · dp/dz · dz/db
```

逐个求：

- `dL/dp = 2(p − y)`（幂法则加链式：`(p − y)²` 对 p 求导）；
- `dp/dz = p(1 − p)`（sigmoid 的导数）；
- `dz/dw = x`（`w·x + b` 对 w 求导，x 和 b 都看作常数）；
- `dz/db = 1`。

**手算**：x = 2，y = 1，w = 0.5，b = −0.3。先算**前向**（从输入到损失）：

```
z = 0.5 × 2 − 0.3 = 0.7
p = σ(0.7) = 1 / (1 + e^(−0.7)) = 1 / (1 + 0.4966) = 0.6682
L = (0.6682 − 1)² = 0.1101
```

再算**反向**（从损失往回，把各段导数乘起来）：

```
dL/dp = 2 × (0.6682 − 1) = −0.6636
dp/dz = 0.6682 × 0.3318 = 0.2217
dL/dw = −0.6636 × 0.2217 × 2 = −0.2943
dL/db = −0.6636 × 0.2217 × 1 = −0.1471
```

演示第 3 部分的输出（以及数值梯度的验证，见 5.8 节）：

```
  前向：z = w·x + b = 0.7000   p = σ(z) = 0.6682   L = (p - y)² = 0.1101
  反向：dL/dp = 2(p-y) = -0.6636   dp/dz = p(1-p) = 0.2217   dz/dw = x = 2.0
        dL/dw = -0.6636 × 0.2217 × 2.0 = -0.294268   dL/db = -0.147134
  数值梯度：dL/dw = -0.294268   dL/db = -0.147134   相对误差 1.2e-11
```

**怎么读**：`dL/dw = −0.294` 是负的，意思是"w 增大，L 减小"。所以应该**增大** w。这符合直觉：正确答案 y = 1，当前预测 0.668 偏小；x = 2 是正的，增大 w 会让 z 变大、p 变大、更接近 1。

**注意计算的顺序**：先前向算出 z、p、L（并把它们记下来），再反向用这些值算导数。反向时，`dL/dp · dp/dz` 这一段是 `dL/dw` 和 `dL/db` 共用的，只算一次。这就是第 8 章**反向传播**（backpropagation）的核心思想：**沿着计算的反方向，把导数一段段乘回去，共用的部分只算一次。**

## 5.5 多元函数、偏导数与梯度

### 偏导数

神经网络有很多参数，损失是所有参数的函数：`L(w₀, w₁, ..., w_n)`。**偏导数** `∂L/∂w₀` 的意思是：**只让 w₀ 变一点点，其他参数都不动**，L 变多少。求偏导时，把其他变量当作常数即可。`∂` 读作"偏"（partial），用来和单变量的 `d` 区分。

**手算**：`f(w₀, w₁) = (w₀ − 1)² + 4(w₁ + 0.5)²`

```
∂f/∂w₀ = 2(w₀ − 1)          （第二项不含 w₀，导数为 0）
∂f/∂w₁ = 4 · 2(w₁ + 0.5) = 8(w₁ + 0.5)
```

### 梯度

把所有偏导数排成一个向量，就是**梯度**（gradient），记作 `∇f`（∇ 读作"nabla"）：

```
∇f = (∂f/∂w₀, ∂f/∂w₁, ...)
```

**梯度和参数的形状完全一样**：如果参数是一个 `(1024, 62)` 的权重矩阵，它的梯度也是一个 `(1024, 62)` 的矩阵，每个元素是损失对那个权重的偏导数。

演示第 4 部分，在点 (−1, 1) 处：

```
  f(w0, w1) = (w0-1)² + 4(w1+0.5)²  在 [-1.0, 1.0] 处的值 13.00
  手算梯度 (2(w0-1), 8(w1+0.5)) = [-4.0, 12.0]
  数值梯度                       = [-4.0, 12.0]
```

`∂f/∂w₀ = 2(−1 − 1) = −4`，`∂f/∂w₁ = 8(1 + 0.5) = 12`。

## 5.6 为什么负梯度方向下降最快

### 方向导数

站在点 w 上，沿某个**单位方向** u（长度为 1 的向量）走一小步 ε，f 变多少？由 5.2 节的近似推广到多元：

```
f(w + εu) ≈ f(w) + ε · (∇f · u)
```

每个分量各贡献"偏导数 × 这个方向上走的距离"，加起来就是点积 `∇f · u`。它叫 f 沿方向 u 的**方向导数**。

### 证明

由第 4 章，`∇f · u = |∇f| · |u| · cos θ = |∇f| cos θ`（u 是单位向量），θ 是 u 与梯度的夹角。所以：

- θ = 0（u 与梯度同向）：`cos θ = 1`，f **增加**最快，增加速率 `|∇f|`；
- θ = 180°（u 与梯度反向）：`cos θ = −1`，f **减少**最快；
- θ = 90°（u 与梯度垂直）：`cos θ = 0`，f 几乎不变——这是沿着**等高线**走。

**结论**：负梯度方向 `−∇f / |∇f|` 是让 f 下降最快的方向。梯度的长度 `|∇f|` 是"坡有多陡"。

### 实验验证

演示第 5 部分：在 (−1, 1) 处，随机生成 1000 个单位方向，每个方向走 ε = 0.001，看哪个方向下降最多：

```
  随机方向里下降最多的方向 [0.315, -0.949]，下降 0.012645
  负梯度方向（单位化）     [0.316, -0.949]，下降 0.012645
  两者夹角 0.05°
  沿梯度垂直方向走：下降 -1.30e-06（几乎为 0：沿等高线走）
```

1000 个随机方向中最好的那个，和负梯度方向只差 0.05°。负梯度方向：`−(−4, 12)/|(−4, 12)| = (4, −12)/12.65 = (0.316, −0.949)`。

垂直方向的"下降"是 −1.3×10⁻⁶，不是精确的 0：因为 5.6 节的式子是**近似**，忽略了 ε² 量级的项（曲线的弯曲）。ε² = 10⁻⁶，和观测一致。

## 5.7 等高线与"碗"的形状

二元函数 `f(w₀, w₁)` 可以画成**等高线图**：把 f 值相同的点连成线，就像地图上的等高线。打开 `outputs/ch05/contour.png`：

- 等高线是一圈圈的**椭圆**，中心（五角星）在最低点 (1, −0.5)；
- 椭圆在 w₁ 方向更"扁"：因为 `4(w₁ + 0.5)²` 的系数是 4，w₁ 方向的坡更陡；
- 黑色箭头是 (−1, 1) 处的负梯度，它**垂直于等高线**（由上一节：沿等高线走 f 不变，所以梯度和等高线垂直），但**并不指向最低点**！

最后一点非常重要。负梯度是"**此时此地**最陡的下坡方向"，不是"通向谷底的方向"。在一个椭圆形的碗里，最陡的方向会偏向陡的那一维。

### 梯度下降的路径

**梯度下降**：从某个起点出发，反复执行 `w ← w − η ∇f(w)`。η（读作 eta）是**学习率**。图中画了两条路径，都从 (−1.5, 1.2) 出发（离最低点 (1, −0.5) 在 w₀ 方向差 2.5、在 w₁ 方向差 1.7）：

```
  学习率 0.05：25 步后到达 [0.8205, -0.5]，函数值 3.22e-02
  学习率 0.2：25 步后到达 [1.0, -0.5]，函数值 1.44e-10
```

**手算为什么**：这个函数的两个方向是独立的，可以分开算。

- w₀ 方向：`w₀ ← w₀ − η · 2(w₀ − 1)`，即 `(w₀ − 1) ← (1 − 2η)(w₀ − 1)`。每步，到最低点的距离乘以 `1 − 2η`；
- w₁ 方向：`(w₁ + 0.5) ← (1 − 8η)(w₁ + 0.5)`。每步乘以 `1 − 8η`。

| η | w₀ 方向每步乘以 | w₁ 方向每步乘以 | 结果 |
|---|---|---|---|
| 0.05 | 0.9 | 0.6 | w₁ 很快到位，w₀ 慢慢爬：0.9²⁵ ≈ 0.07，起点距离 2.5 → 剩 0.18 |
| 0.2 | 0.6 | **−0.6** | w₁ 方向符号反复翻转——**来回震荡**，但幅度在缩小，最终收敛 |
| 0.25 | 0.5 | −1 | w₁ 方向永远在两个值之间跳，不收敛 |
| 0.3 | 0.4 | −1.4 | w₁ 方向越跳越远——**发散** |

0.9²⁵ × 2.5 ≈ 0.18，和实测 1 − 0.8205 = 0.18 一致。

这个表揭示了训练中最核心的矛盾：**学习率受最陡的那个方向限制**。η 必须小于 0.25（`|1 − 8η| < 1`），否则陡的方向会发散；但这样一来，平缓的方向（w₀）走得很慢。碗越"扁"（不同方向的陡度差别越大），这个矛盾越严重。第 7 章会在真实的训练中看到"学习率的四种结局"，第 11 章的 Adam 优化器就是为了缓解这个矛盾——它给每个方向用不同的步长。

## 5.8 数值导数与梯度检查

### 练习 5.1：中心差分

5.2 节的定义式取一个很小但不为 0 的 h，就得到一个**数值导数**。有两种写法：

```
前向差分：f'(x) ≈ (f(x + h) − f(x)) / h
中心差分：f'(x) ≈ (f(x + h) − f(x − h)) / (2h)
```

中心差分用 x 两边对称的两个点。5.2 节手算过，`x²` 的前向差分误差恰好是 h；而中心差分：

```
((x + h)² − (x − h)²) / (2h) = (4xh) / (2h) = 2x
```

**没有误差**！对一般的函数，中心差分的误差是 h² 量级，前向差分是 h 量级（"深入一步"会用泰勒展开证明）。

```python
def numerical_derivative(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2 * h)
```

打开 `outputs/ch05/h_tradeoff.png`，两条曲线都是"V"字形：

- **左半边**（h 大）：误差随 h 减小而减小。前向差分每次 h 缩小 10 倍，误差缩小 10 倍（斜率 1）；中心差分缩小 100 倍（斜率 2）。这是**截断误差**——用直线近似曲线带来的误差；
- **右半边**（h 小）：误差反而增大！这是**舍入误差**。电脑的小数只有约 16 位有效数字（float64），`f(x + h)` 和 `f(x)` 非常接近时，相减会丢掉大部分有效数字（第 4 章的灾难性抵消），再除以一个很小的 h，误差被放大。

所以存在一个最佳的 h。对 float64，中心差分在 h ≈ 10⁻⁵ 到 10⁻⁷ 时误差在 10⁻¹⁰ 左右，本书默认 `h = 1e-5`。**用 float32 时舍入误差大得多（只有约 7 位有效数字），最佳 h 在 10⁻³ 左右，数值梯度也只能准到 10⁻⁴ 左右**——所以梯度检查一定要用 float64。

### 练习 5.2：数值梯度

多元函数的数值梯度：对每个参数分别做一次中心差分。

```python
def numerical_gradient(f, x, h=1e-5):
    x = np.array(x, dtype=np.float64)            # 副本，不修改调用者的数组
    grad = np.zeros_like(x)
    for idx in np.ndindex(x.shape):              # 遍历每一个下标
        old = x[idx]
        x[idx] = old + h
        fp = f(x)
        x[idx] = old - h
        fm = f(x)
        x[idx] = old                             # 恢复！
        grad[idx] = (fp - fm) / (2 * h)
    return grad
```

- `np.ndindex(shape)` 依次给出所有下标：形状 `(2, 3)` 时是 `(0,0), (0,1), (0,2), (1,0), ...`。这样同一段代码对向量、矩阵、任何形状都适用；
- `np.zeros_like(x)` 造一个和 x 形状、类型都相同的全 0 数组；
- **恢复原值**这一行绝不能忘。忘了的话，第一个参数会停在 `old − h`，后面所有参数都在一个错误的点上求导——结果"差不多对"，最难发现。测试 `test_numerical_gradient_does_not_modify_input` 检查了调用者的数组没有被改动。

**代价**：n 个参数需要计算 2n 次 f。一个 27 万参数的 MLP，每次 f 要算一遍整个数据集的损失，数值梯度要算 55 万遍——太慢了，所以训练时绝不用它。它只用来在**小规模**上检查手推的或自动的梯度。

### 梯度检查

比较两个梯度用**相对误差**：

```python
def rel_error(a, b, eps=1e-12):
    return max |a − b| / max(|a| + |b|, eps)
```

为什么不用绝对误差 `|a − b|`？因为梯度可能很大（10³）也可能很小（10⁻⁶），同样的绝对误差在两种情况下意义完全不同。经验标准（float64）：

| 相对误差 | 结论 |
|---|---|
| < 10⁻⁷ | 正确 |
| 10⁻⁷ – 10⁻⁴ | 可疑；如果函数有"尖角"（如 ReLU 在 0 附近），可能是正常的 |
| > 10⁻⁴ | 几乎肯定有 bug |

5.4 节的迷你神经元，手算梯度与数值梯度的相对误差是 1.2×10⁻¹¹——正确。

测试 `test_numerical_gradient_matches_analytic` 用了一个经典例子：`f(x) = xᵀAx` 的梯度是 `(A + Aᵀ)x`（选做题 5 让你推导它）。

## 5.10 常见错误

| 现象 | 原因 | 怎么查 |
|---|---|---|
| 数值梯度与手推梯度差一个固定的倍数（比如 2 倍） | 手推时漏了链式法则的某一段，或者损失定义里有平均/求和的差别 | 在单个样本、单个参数上逐段对比 |
| 数值梯度"差不多对"，误差 1e-3 | 用了 float32；或 h 太小/太大 | 梯度检查一律用 float64、h = 1e-5 |
| 数值梯度的结果和参数顺序有关 | 求完一个参数后没有恢复原值 | 检查"恢复"那一行；测试调用前后数组是否不变 |
| 梯度检查在某些点失败、其他点通过 | 函数有尖角（ReLU、max、abs），恰好在尖角附近 | 换一个远离尖角的检查点 |
| 梯度符号反了，训练时损失越来越大 | 手推时把 `y − p` 写成了 `p − y` | 先检查一个能直观判断方向的简单例子 |

## 5.11 真实世界对照

- **训练循环里的梯度**（第 9 章起）由 PyTorch 自动计算，`loss.backward()` 一行搞定。但"自动"不等于"不会错"：自定义的层、自定义的损失（第 13 章的 CTC、第 31 章的 GRPO 目标）都可能出错，PyTorch 提供了 `torch.autograd.gradcheck`，做的就是本章的数值梯度检查（也要求 float64）；
- **学习率**：本章的"碗"只有两维；真实模型的损失是几亿维空间里的一个曲面，有的方向极陡、有的极平，"学习率受最陡方向限制"的矛盾更加严重。这就是为什么大模型训练要用 Adam（第 11 章）、要有 warmup（学习率从小慢慢升高）、要裁剪梯度；
- **sigmoid 的导数最大只有 0.25**：几十层 sigmoid 连在一起，梯度要乘几十个不超过 0.25 的数，很快就变成 0。这是早期深层网络训练不动的原因之一，ReLU（导数是 1）和残差连接（第 16 章）解决了它。

## 5.12 深入一步：用泰勒展开理解数值导数的误差

**泰勒展开**说，光滑函数在 x 附近可以写成一个多项式：

```
f(x + h) = f(x) + f'(x)·h + f''(x)·h²/2 + f'''(x)·h³/6 + ...
```

其中 `f''` 是导数的导数（二阶导数，表示"弯曲程度"）。这正是 5.2 节近似式 `f(x + h) ≈ f(x) + f'(x)h` 的延续：后面的项是越来越小的修正。

**前向差分**：

```
(f(x + h) − f(x)) / h = f'(x) + f''(x)·h/2 + ...
```

误差的首项是 `f''(x)·h/2`，和 h 成正比。对 `eˣ` 在 x = 1：`e/2 · h ≈ 1.36h`，h = 0.1 时 0.136——和实测的 1.4×10⁻¹ 完全吻合。

**中心差分**：把 `f(x − h)` 也展开（h 换成 −h，奇数次项变号）：

```
f(x − h) = f(x) − f'(x)·h + f''(x)·h²/2 − f'''(x)·h³/6 + ...
f(x + h) − f(x − h) = 2f'(x)·h + f'''(x)·h³/3 + ...
(f(x + h) − f(x − h)) / (2h) = f'(x) + f'''(x)·h²/6 + ...
```

`f''` 项**抵消了**！误差首项是 `f'''(x)·h²/6`，和 h² 成正比。对 `eˣ`：`e/6 · h² ≈ 0.45h²`，h = 0.1 时 4.5×10⁻³——和实测一致。对 `x²`，三阶导数是 0，所以中心差分没有截断误差。

**最佳 h**：舍入误差大约是 `ε·|f|/h`，ε ≈ 2.2×10⁻¹⁶ 是 float64 的"机器精度"（第 11 章）。前向差分的总误差约 `h + ε/h`，在 `h ≈ √ε ≈ 1.5×10⁻⁸` 时最小，约 10⁻⁸——实测最佳 h = 10⁻⁸、误差 6.6×10⁻⁹。中心差分的总误差约 `h² + ε/h`，在 `h ≈ ε^(1/3) ≈ 6×10⁻⁶` 时最小，约 10⁻¹¹——实测 h = 10⁻⁵ 到 10⁻⁷ 时误差 6×10⁻¹¹。理论和实验对上了。

**二阶导数与"碗"**：多元函数的二阶导数排成一个矩阵，叫 **Hessian 矩阵**。5.7 节的碗 `(w₀ − 1)² + 4(w₁ + 0.5)²` 的 Hessian 是 `diag(2, 8)`，两个对角元就是两个方向的"弯曲程度"。梯度下降收敛的条件是 `η < 2 / 最大弯曲度 = 2/8 = 0.25`——正是 5.7 节表格里的临界值。最大和最小弯曲度之比（这里是 4）叫**条件数**，条件数越大，碗越扁，梯度下降越慢。

## 5.13 横向对照：怎样得到梯度

| 方法 | 怎么做 | 速度 | 精度 | 用在哪里 |
|---|---|---|---|---|
| 手推 | 用求导法则推出公式，写成代码 | 快 | 精确（如果推对了） | 第 7 章线性/逻辑回归；理解原理 |
| 数值差分 | 每个参数扰动一次 | 极慢（参数数 × 2 次前向） | 约 10⁻¹⁰（float64） | 梯度检查 |
| 符号求导 | 计算机代数系统推出公式 | 公式可能爆炸式变长 | 精确 | 数学软件；深度学习中很少用 |
| 自动求导（反向模式） | 记录计算过程，沿反方向应用链式法则 | 约 1–3 次前向的代价，**与参数数无关** | 精确到浮点误差 | PyTorch、JAX；第 8 章自己写 |
| 自动求导（前向模式） | 沿计算方向同时传播导数 | 每个输入方向一次前向 | 精确 | 输入少、输出多的情形 |

神经网络的情形是"输入（参数）极多、输出（损失）只有一个"，反向模式自动求导的代价与参数个数无关，这是深度学习能训练几亿参数模型的根本原因。第 8 章会亲手实现它。

## 5.14 本章小结

- 导数是放大后的斜率：`f'(x) = lim (f(x+h) − f(x))/h`；`f(x + Δx) ≈ f(x) + f'(x)Δx`；
- 求导法则：幂、和、积、链式；`(eˣ)' = eˣ`，`(ln x)' = 1/x`，`σ' = σ(1 − σ)`；
- 链式法则：变化率沿链条相乘；反向计算时共用的部分只算一次——这就是反向传播；
- 偏导数：只动一个变量；梯度：所有偏导数排成的向量，形状和参数相同；
- 负梯度是下降最快的方向（方向导数 = `|∇f| cos θ`），垂直于等高线，但不一定指向最低点；
- 梯度下降 `w ← w − η∇f`：学习率受最陡方向限制，太大会震荡或发散，碗越扁越慢；
- 数值导数用中心差分（误差 h²），h ≈ 1e-5、float64；数值梯度用于检查，不用于训练；用相对误差判断。

## 参考答案

1. x 增大时 f 减小（处于下坡）。要让 f 变小，应该增大 x（朝导数的反方向走）。
2. 负梯度是局部最陡的方向，垂直于等高线；在椭圆形的碗里，最陡的方向偏向陡的维度，不指向中心。在圆形的碗里（各方向弯曲程度相同，等高线是圆），负梯度恰好指向圆心。
3. n 个参数需要 2n 次完整的前向计算，对上百万参数的模型太慢；而且它只是近似。反向模式自动求导只需要大约一次前向的代价，并且精确。
4. `f(x+h)` 和 `f(x−h)` 极其接近，相减时有效数字大量丢失（舍入误差），再除以很小的 h，误差被放大。
5. `f'(x) = 12x³ − 2`；`g'(x) = 3e^(3x+1)`，`g'(0) = 3e ≈ 8.155`。
6. `∂f/∂a = 2ab`，`∂f/∂b = a² + 3`。在 (1, 2)：`∇f = (4, 4)`。下降最快的单位方向 `−(4, 4)/|(4, 4)| = (−0.707, −0.707)`。
7. 前向不变：p = 0.6682。`dL/dp = 2(0.6682 − 0) = 1.3364`，`dp/dz = 0.2217`，`dL/dw = 1.3364 × 0.2217 × 2 ≈ 0.5926`。梯度为正，应该减小 w（让 z、p 变小，接近 0）。
8. 梯度 `10w`，`w ← w − 0.15 × 10w = −0.5w`。w：1 → −0.5 → 0.25 → −0.125。每步乘以 −0.5，符号来回翻转（震荡），幅度减半，会收敛到 0。
9. (a) 如果 x 是整数数组，`x[i] += 1e-5` 会被截断，扰动为 0，梯度全是 0（应先 `x = np.array(x, dtype=np.float64)`）；(b) `x[i] += h` 再 `x[i] -= 2h` 之后，x[i] 停在 `old − h`，没有恢复，后面的分量在错误的点上求导，而且调用者的数组被修改了（应先复制，并在每个分量后恢复）。另外 `len(x)` 只适用于一维数组。
10. `f(W) = Σ_j Σ_i x_i W_ij²`，对 W_ij 求偏导：`2 x_i W_ij`，即梯度 `2 * x[:, None] * W`（形状 `(5, 3)`）。检查：`rel_error(numerical_gradient(lambda M: (x @ M ** 2).sum(), W), 2 * x[:, None] * W)` 应小于 1e-7。
