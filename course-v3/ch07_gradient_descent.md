## 7.1 学习问题的三个要素

任何一个监督学习问题都由三样东西组成：

| 要素 | 含义 | 线性回归的例子 |
|---|---|---|
| **模型** | 带参数的函数 `ŷ = f(x; θ)` | `ŷ = w·x + b`，参数 θ = (w, b) |
| **损失** | 衡量一个预测有多差 | `(ŷ − y)²` |
| **优化** | 找到让平均损失最小的参数 | 梯度下降 |

训练的目标是最小化**训练集上的平均损失**：

```
L(θ) = (1/N) Σ_i loss(f(x_i; θ), y_i)
```

这叫**经验风险**（empirical risk）。我们真正关心的是模型在**没见过的数据**上的平均损失（期望风险），但只能用训练集来近似它——第 6 章的大数定律保证样本足够多时两者接近；第 10 章会看到样本不够时会发生什么（过拟合）。

## 7.2 线性回归

### 问题

ShapesWorld 里只放一个物体，数一数它占了多少像素（面积），能不能猜出它的边长？

`miniocr/data/tasks.py` 里的 `shape_sizes` 生成这样的数据：

```
  前 5 个样本 (面积, 边长, 形状): [(221, 17, 'circle'), (52, 8, 'circle'), (225, 15, 'square'), (256, 16, 'square'), (97, 11, 'circle')]
```

（`python -m labs.ch07.regression` 的第 1 部分。）正方形的面积就是边长的平方（15² = 225），圆的面积约是 `π/4 ≈ 0.785` 倍边长平方（17² × 0.785 = 227，实测 221，因为像素化有误差）。

所以用 **√面积** 当特征 x，它和边长 y 应该接近线性关系：`y ≈ w·x + b`。

### 模型与损失

对 N 个样本，把特征排成 `(N, D)` 的矩阵 X（这里 D = 1），模型一次算出所有预测：

```
ŷ = X w + b          (N, D) @ (D,) + 数 = (N,)
```

损失用**均方误差**（mean squared error，MSE）：

```
L = (1/N) Σ_i (ŷ_i − y_i)²
```

为什么用平方？平方让正负误差都变成正的，并且对大误差惩罚更重；它的梯度简单；而且可以证明：如果数据的噪声服从正态分布，最小化 MSE 就是最大似然估计（第 6 章的思想，"深入一步"中推导）。

### 梯度（练习 7.1）

定义**残差** `r = ŷ − y`（形状 `(N,)`）。用链式法则：

```
∂L/∂ŷ_i = (2/N) r_i
∂ŷ_i/∂w_d = X[i, d]      ∂ŷ_i/∂b = 1
∂L/∂w_d = Σ_i (2/N) r_i X[i, d]   →   ∂L/∂w = (2/N) Xᵀ r      (D, N) @ (N,) = (D,)
∂L/∂b   = (2/N) Σ_i r_i
```

**形状检查**：梯度必须和参数形状相同。w 是 `(D,)`，`Xᵀ r` 是 `(D, N) @ (N,) = (D,)`。✓ 这是检查手推梯度最快的方法——**先对形状，再对数值**。

```python
def mse_loss_grad(X, y, w, b):
    r = X @ w + b - y
    N = len(y)
    return float((r ** 2).mean()), 2.0 / N * (X.T @ r), 2.0 / N * float(r.sum())
```

`Xᵀ r` 的含义：每个特征的梯度，是"残差 × 这个特征的值"在所有样本上的总和。如果某个特征大的样本，残差恰好也大（预测偏高），这个特征的权重就该减小。

测试 `test_mse_grad` 用第 5 章的数值梯度验证了它。

### 梯度下降

```python
def gd(loss_grad, params, lr, steps, log_every=None):
    params = [np.array(p, dtype=np.float64) for p in params]
    hist = []
    for t in range(steps):
        out = loss_grad(*params)               # (损失, 梯度1, 梯度2, ...)
        hist.append(out[0])
        if not np.isfinite(out[0]):            # 损失变成 inf 或 nan：发散了，停下
            break
        for p, g in zip(params, out[1:]):
            p -= lr * g                        # 原地更新：每个参数沿负梯度走一步
        ...
    return params, hist
```

每一步用**全部**训练数据计算梯度，叫**全批量梯度下降**（full-batch gradient descent）。

`p -= lr * g` 是**原地**修改（第 1 章），所以 `params` 列表里的数组被直接更新了。这正是我们想要的；但也要注意 `params = [np.array(p, ...) ...]` 那一行先复制了一份，不会改动调用者传进来的初始值。

```
    第    0 步  损失 185.3250
    第 5000 步  损失 2.4034
    第 10000 步  损失 2.4033
    ...
  梯度下降得到  边长 ≈ 0.8902·√面积 + 2.9114
  最小二乘闭式解 边长 ≈ 0.8902·√面积 + 2.9114
```

梯度下降找到的解，和**闭式解**（用线性代数直接解出来的精确最优解，`np.linalg.lstsq`，见"深入一步"）完全一样。线性回归有闭式解，本来不需要梯度下降；我们用它，是因为它是唯一一个能**直接核对**梯度下降结果的模型。

为什么要 30000 步？下一节解释。

### 残差分析：模型缺了什么

```
  测试集均方误差 2.410，平均绝对误差 1.305 像素
    circle   平均残差 +0.088
    square   平均残差 +1.491
    triangle 平均残差 -1.796
```

**按形状分开看残差**：对圆，预测几乎没有偏差；对正方形，预测系统性地偏大 1.5 像素；对三角形，偏小 1.8 像素。原因很清楚：同样的边长，三角形的面积最小（约 0.53 倍边长平方）、正方形最大（1 倍）。一个只看面积的模型，只能取一个"平均"的换算比例，对每种形状都有系统误差。

**残差不是随机的，而是和某个我们没给模型的信息（形状）有关**——这说明模型缺了这个信息。把形状也作为特征（用第 1 章的独热编码，去掉第一列"圆"作为基准）：

```
  加上形状特征后的闭式解 w = [1.129, -1.783, 2.333]，b = 0.060
  加上形状特征后：w = [1.129, -1.783, 2.333]，b = 0.060；测试集平均绝对误差 0.333 像素
```

误差从 1.305 降到 0.333 像素。读权重：√面积的系数 1.129 ≈ `1/√(π/4) = 1.128`，正好是圆的换算比例；"是正方形"让预测减小 1.78，"是三角形"让预测增大 2.33。

但它仍不完美。正方形的真实关系是 `边长 = 1.0 × √面积`，三角形是约 `1.38 × √面积`——**不同形状的斜率不同**，而我们的模型只能给不同形状加不同的**常数**，不能改变斜率。要表达"斜率随形状变化"，需要"√面积 × 是三角形"这样的**交互特征**（选做题 6）。或者——让模型自己学会组合特征。这正是第 10 章隐藏层的作用。

**这一节的方法论，在全书中反复使用**：不只看总的误差，而是**分组看误差**（按形状、按难度、按长度），找出系统性的错误，再判断模型缺了什么。第 25 章称之为"分桶评测"。

## 7.3 学习率的四种结局

### 实验

为了让问题更明显，用两个特征 `[√面积, 面积]`，它们的尺度差了约 15 倍：

```
  特征 √面积 的范围 [6, 18]，面积 的范围 [36, 324]
  raw          lr = 3e-06   第 10 步        22.12  第 200 步 17.084
  raw          lr = 1e-05   第 10 步        17.31  第 200 步 16.475
  raw          lr = 3.5e-05  第 10 步        38.39  第 200 步 14.496
  raw          lr = 4e-05   第 10 步         4126  第 200 步 发散
  standardized lr = 0.01    第 10 步        122.7  第 200 步 2.636
  standardized lr = 0.1     第 10 步        4.604  第 200 步 2.410
  standardized lr = 0.48    第 10 步        3.828  第 200 步 2.240
  standardized lr = 0.52    第 10 步        34.72  第 200 步 发散
```

打开 `outputs/ch07/lr_outcomes.png` 看曲线（纵轴是对数刻度）。以标准化后的特征为例，四种学习率对应四种结局：

| 结局 | 学习率 | 曲线的样子 | 发生了什么 |
|---|---|---|---|
| 太小 | 0.01 | 平稳但缓慢地下降，200 步后还没到底 | 每步走得太短 |
| 合适 | 0.1 | 快速下降后平稳 | |
| 震荡 | 0.48 | 前几步上下跳动，然后下降 | 最陡的方向上"一步迈过谷底"，来回跳但幅度在缩小 |
| 发散 | 0.52 | 越来越大，最后变成 inf | 最陡的方向上每一步跳得比上一步更远 |

### 为什么临界值在 0.5 左右

第 5 章"深入一步"讲过：梯度下降收敛的条件是 `η < 2 / λ_max`，λ_max 是损失曲面最陡方向的"弯曲度"（Hessian 矩阵的最大特征值）。对均方误差，Hessian 是 `(2/N) AᵀA`（A 是在 X 后面加一列 1 的矩阵，对应偏置）。算一下（`np.linalg.eigvalsh`）：

| 特征 | Hessian 的特征值 | 学习率上限 2/λ_max | 条件数 λ_max/λ_min |
|---|---|---|---|
| 原始 `[√面积, 面积]` | 0.0118、15.1、54333 | 3.7×10⁻⁵ | 约 460 万 |
| 标准化后 | 0.0185、2.0、3.98 | 0.502 | 约 215 |
| 只用 √面积（7.2 节） | 0.147、290.8 | 0.0069 | 约 1980 |

和实验完全吻合：原始特征在 3.5×10⁻⁵ 时震荡、4×10⁻⁵ 时发散；标准化后在 0.48 时震荡、0.52 时发散。

**而真正决定训练速度的是条件数**。最平缓方向每步的收敛因子是 `1 − η λ_min`，η 最大只能取约 `2/λ_max`，所以收敛因子约 `1 − 2/条件数`。原始特征的条件数是 460 万，意味着最平缓的方向几乎不动——200 步后损失还停在 14.5，远高于最优的 2.24。7.2 节只用 √面积时条件数约 2000，也需要上万步，这就是那里用 30000 步的原因。

### 特征缩放

**标准化**（standardization）把每个特征变成"均值 0、标准差 1"：

```python
def standardize(X_train, *others, eps=1e-8):
    mu, sd = X_train.mean(0), X_train.std(0) + eps
    return [(X - mu) / sd for X in (X_train,) + others]
```

它让各特征的尺度相同，Hessian 的特征值不再相差几个数量级，条件数从 460 万降到 215。同样 200 步，损失从 14.5 降到 2.24。

为什么条件数还有 215？因为 √面积 和面积**高度相关**（相关系数约 0.99），两个特征几乎在说同一件事。标准化只解决了"尺度不同"，解决不了"相关"。第 11 章的 Adam 和归一化层会进一步处理这类问题。

**两个注意事项**：

1. **只能用训练集的均值和标准差**，然后把同样的变换应用到验证集、测试集。如果用整个数据集（包括测试集）的统计量，测试集的信息就"泄漏"进了训练过程（第 25 章的数据泄漏）。测试 `test_standardize_uses_train_stats` 检查了这一点；
2. 第 2 章图像的 `(x − mean) / std` 就是同一件事：mean 和 std 来自（预训练模型的）训练数据。

## 7.4 逻辑回归：二分类

### 问题与模型

区分字符 b 和 d（它们是左右镜像）。每张图对齐到 16×16（第 2 章 `normalize_glyph`），拉平成 256 个特征。标签 y = 1 表示 d，y = 0 表示 b。

线性回归的输出可以是任何实数，但我们要的是"是 d 的概率"，必须在 0 和 1 之间。用第 5 章的 sigmoid 把线性部分的输出压进 (0, 1)：

```
z = X w + b              (N,)：分数（logit）
p = σ(z)                 (N,)：是 d 的概率
```

这就是**逻辑回归**（logistic regression）——名字里有"回归"，其实是分类模型（历史原因）。预测规则：p > 0.5（等价于 z > 0）就判为 d。

### 损失与梯度（练习 7.2）

二分类的交叉熵（二元交叉熵，binary cross-entropy）：

```
L = −(1/N) Σ_i [y_i log p_i + (1 − y_i) log(1 − p_i)]
```

y = 1 时只剩 `−log p`，y = 0 时只剩 `−log(1 − p)`——都是"−log 给正确答案的概率"。

梯度：第 5 章自己动手第 4 题已经推导过，交叉熵和 sigmoid 合在一起，`∂L/∂z_i = (p_i − y_i)/N`，和第 6 章 softmax 的 `p − y` 一模一样。于是：

```
∂L/∂w = Xᵀ (p − y) / N        ∂L/∂b = Σ (p − y) / N
```

和线性回归的梯度形状完全一样，只是残差 `ŷ − y` 换成了 `p − y`（以及没有因子 2）。

**数值稳定**：`log σ(z) = −log(1 + e^{−z})`，`log(1 − σ(z)) = −log(1 + e^{z})`。`log(1 + eˣ)` 在 x 很大时，eˣ 会溢出。`np.logaddexp(0, x)` 计算 `log(e⁰ + eˣ)`，内部用了和第 6 章 logsumexp 相同的减最大值技巧：

```python
def logistic_loss_grad(X, y, w, b):
    z = X @ w + b
    N = len(y)
    loss = float((y * np.logaddexp(0, -z) + (1 - y) * np.logaddexp(0, z)).mean())
    g = (sigmoid(z) - y) / N
    return loss, X.T @ g, float(g.sum())
```

测试里有一项专门把输入放大 1000 倍，检查损失仍然是有限的数。`miniocr/calculus.py` 里的 `sigmoid` 也改成了同样稳定的写法：`σ(z) = exp(−log(1 + e^{−z}))`。

### 结果

```
  梯度检查（20 个样本，256 个权重）：相对误差 1.2e-08
    第    0 步  损失 0.6931
    第  100 步  损失 0.0030
    第  200 步  损失 0.0015
    第  300 步  损失 0.0010
  训练集准确率 100.0%，测试集准确率 100.0%
```

初始损失 0.6931 = ln 2（两类均匀猜测，第 6 章）。100 步之后训练集和测试集都完全分对了。

### 看看权重

打开 `outputs/ch07/logistic_weights.png`：把 256 个权重排回 16×16。**红色**是正权重（这个像素有墨迹时，投票给 d），**蓝色**是负权重（投票给 b）。你会看到：

- 字符左侧的竖线区域（b 的竖笔画所在）是蓝色，右侧（d 的竖笔画所在）是红色；
- 中间圆圈的部分颜色较淡——b 和 d 都有圆圈，这些像素对区分它们没有帮助。

**线性分类器的权重就是一张"模板之差"**：哪些像素在一类里常见、在另一类里少见。这和第 4 章说的"线性层的每一列是一个模板"是同一个意思。可视化权重是理解简单模型最直接的方法；第 12 章可视化卷积核、第 19 章可视化 ViT 的注意力，用的是同样的思路。

## 7.5 softmax 回归：62 类

### 模型、损失与梯度（练习 7.3）

把逻辑回归推广到 K 类：权重变成 `(D, K)` 的矩阵，每一列是一类的模板，输出 K 个 logits，用 softmax 变成概率：

```
Z = X W + b              (N, D) @ (D, K) + (K,) = (N, K)
P = softmax(Z)           (N, K)
L = −(1/N) Σ_i log P[i, y_i]
```

由第 6 章，`∂L/∂Z = (P − Y) / N`（Y 是独热矩阵）。再用线性层的链式法则：

```
∂L/∂W = Xᵀ ∂L/∂Z        (D, N) @ (N, K) = (D, K)    ✓ 与 W 同形
∂L/∂b = Σ_i ∂L/∂Z[i]    (K,)                         ✓ 与 b 同形
```

```python
def softmax_loss_grad(X, y, W, b):
    Z = X @ W + b
    N = len(y)
    loss = float(-log_softmax(Z)[np.arange(N), y].mean())
    G = softmax(Z)
    G[np.arange(N), y] -= 1.0              # P - Y：只需在正确类的位置减 1，不用真的造独热矩阵
    G /= N
    return loss, X.T @ G, G.sum(0)
```

`G[np.arange(N), y] -= 1.0` 是一个省内存的技巧：`P − Y` 只在每行正确类那个位置和 P 不同，直接在那里减 1 即可。

**"线性层的梯度是 `Xᵀ × 输出的梯度`"** 这条规则会在第 8 章被自动求导系统地使用，请记住它：对 `Z = XW`，`∂L/∂W = Xᵀ (∂L/∂Z)`，`∂L/∂X = (∂L/∂Z) Wᵀ`。

### 小批量随机梯度下降

62 类、每类 60 张，训练集 3720 个样本。全批量梯度下降每一步都要看全部样本，样本多时很慢。**小批量随机梯度下降**（mini-batch SGD）每一步只用一小批样本估计梯度：

```python
for epoch in range(30):                                  # 每一轮把训练集过一遍
    for idx in minibatches(len(Xtr), 64, rng):           # 第 1 章的工具：每轮打乱，每批 64 个
        _, gW, gb = softmax_loss_grad(Xtr[idx], ytr[idx], W, b)
        W -= 0.5 * gW
        b -= 0.5 * gb
```

一批的梯度是整体梯度的一个**有噪声的估计**（第 6 章：样本均值是期望的估计，误差随批大小的平方根缩小）。虽然每一步不那么准，但一轮里能更新 3720/64 ≈ 58 次，而全批量只能更新 1 次。实践中，小批量几乎总是更快。

```
  训练集 (3720, 256)，验证集 (1240, 256)
  初始损失 4.1271（ln 62 = 4.1271）
    第  1 轮  训练损失 0.9469 准确率 72.7%   验证损失 0.9864 准确率 71.0%
    第  5 轮  训练损失 0.2635 准确率 93.0%   验证损失 0.2803 准确率 92.2%
    第 10 轮  训练损失 0.1533 准确率 95.7%   验证损失 0.1702 准确率 94.0%
    第 15 轮  训练损失 0.2181 准确率 96.5%   验证损失 0.2394 准确率 95.5%
    第 20 轮  训练损失 0.1283 准确率 95.5%   验证损失 0.1392 准确率 95.8%
    第 25 轮  训练损失 0.0851 准确率 98.3%   验证损失 0.0984 准确率 98.2%
    第 30 轮  训练损失 0.1240 准确率 96.8%   验证损失 0.1577 准确率 96.9%
  用时 0.3 秒（CPU，NumPy）
```

### 怎么读

1. **初始损失恰好是 ln 62**：W 和 b 初始化为 0，所有 logits 都是 0，softmax 是均匀分布。第 6 章的检查通过；
2. **一轮之后就有 72.7%**，30 轮后约 97%。第 2 章的模板分类器在同样的 16×16 对齐数据上是 85.3%。**同样是"线性"的模板匹配，学出来的模板比平均出来的模板好得多**：平均模板只反映"这一类长什么样"，而学出来的模板反映"这一类和**其他类**有什么不同"——就像 b/d 的权重图里，两者共有的圆圈部分权重很淡；
3. **损失不是单调下降的**：第 15 轮比第 10 轮高，第 30 轮比第 25 轮高。这是小批量 SGD 的噪声，加上学习率 0.5 偏大——参数在最优点附近"晃动"。第 11 章的学习率衰减（训练后期把学习率调小）就是为了让它最后"停稳"；
4. **训练集和验证集的损失、准确率非常接近**：模型没有过拟合。一个线性模型只有 256 × 62 + 62 = 15,934 个参数，而训练样本有 3720 个，每个 256 维，模型还"记不住"训练集。第 10 章的 MLP 参数多得多，就会看到两者分开。

   **一个要留到第 10 章才揭开的问题**：归一化抹掉了字符的位置，而渲染器只有十几种"写法"（字号 × 是否加粗），所以验证集里的图绝大多数和训练集里的某张图**逐像素完全相同**（本节的数据实测为 92.3%，第 10 章的 32×32 版本为 97.6%）。这里的 97% 因此偏乐观——它更接近"认出见过的图"，而不是"认出没见过的写法"。第 10 章会给渲染器加上随机形变，重新衡量。

### 剩下的错误

```
  最常见的混淆: [(('O', 'o'), 20), (('v', 'V'), 5), (('c', 'o'), 4), (('I', 'i'), 3), ...]
```

第 2 章的模板分类器混淆最多的是 `c/C`、`s/S`、`z/Z`、`x/X`，而这里这些几乎都分开了，只剩 `O→o` 这一对很突出。为什么学出来的模型能分开大部分大小写？因为 `normalize_glyph` 把小写字母**放大**到和大写同样大小时，**笔画也被放大变粗了**——小写 c 的笔画相对更粗。平均模板对这种细微差别不敏感，学出来的权重却能抓住它。但 O 和 o 的这种差别最小，仍然分不开。

这再次说明第 2 章的结论：要可靠地区分大小写，模型需要看到字符相对于整行文字的大小——单字符分类的上限就在这里。

## 7.7 常见错误

| 现象 | 原因 | 怎么查 |
|---|---|---|
| 损失一开始就变大，然后变成 inf/nan | 学习率太大 | 从小的学习率（如 1e-3）开始，每次放大 3 倍，找到发散的临界点，取它的 1/3 到 1/10 |
| 损失下降得极慢 | 学习率太小；或者特征尺度相差太大（条件数大） | 标准化特征；看曲线是否还在稳步下降 |
| 梯度形状和参数不一样 | 手推时转置写错（`X @ r` 而不是 `X.T @ r`） | 先检查形状，再做数值梯度检查 |
| 梯度大了 N 倍或 2 倍 | 忘了除以 N（损失是平均还是求和），或 MSE 漏了因子 2 | 数值梯度检查会发现固定倍数的差异 |
| 训练准确率很高，测试准确率很低 | 过拟合；或测试集用了不同的预处理 | 确保训练和测试用同一个预处理函数和同一组统计量 |
| 测试准确率高得可疑 | 测试集和训练集用了相同的随机种子，样本重叠 | 训练、验证、测试用不同的种子 |
| 逻辑回归的损失出现 inf | 直接写 `np.log(sigmoid(z))`，z 很负时 σ 下溢为 0 | 用 `np.logaddexp` |

## 7.8 真实世界对照

- **"线性探针"**（linear probe）：评价一个预训练视觉编码器好不好，标准做法是冻结编码器，在它的输出特征上训练一个 softmax 回归（就是本章的模型），看准确率多高。CLIP 的论文就用这种方法比较了几十个模型（第 20 章）。一个好的编码器，应该让"线性模型就能分开"各个类别；
- **VLM 的最后一层**：语言模型的输出层（叫 LM head）就是一个 softmax 回归：输入是最后一层的隐藏向量（比如 1024 维），权重是 `(1024, 词表大小)`，输出每个 token 的概率。它的梯度就是本章的 `Xᵀ(P − Y)`；
- **学习率**：大模型训练对学习率极其敏感。一个 0.8B 参数的模型，学习率通常在 10⁻⁴ 到 10⁻⁵ 量级；微调时更小。没有人去算 Hessian 的特征值，而是用"学习率搜索"（从小到大试）加上 warmup 和衰减（第 11、18 章）；
- **标准化**：现代网络不仅标准化输入，还在网络内部的每一层标准化（LayerNorm、RMSNorm，第 11、16 章），原理和本章相同：让每层的输入尺度稳定，训练更快更稳。

## 7.9 深入一步

### 线性回归的闭式解

令 A = [X, 1]（在 X 右边加一列全 1，把偏置并入权重），θ = (w, b)。损失 `L = (1/N)|Aθ − y|²`。梯度 `(2/N) Aᵀ(Aθ − y)`，令它为 0：

```
AᵀA θ = Aᵀ y        →      θ = (AᵀA)⁻¹ Aᵀ y
```

这叫**正规方程**（normal equation）。`np.linalg.lstsq` 用一种数值上更稳定的方法（QR 或 SVD 分解）求解它，不直接求逆。为什么不总用闭式解？因为 `AᵀA` 是 `(D+1)×(D+1)` 的矩阵，D 很大时求解代价是 D³；而且对逻辑回归、softmax 回归和神经网络，令梯度为 0 的方程**没有闭式解**，只能迭代求解。

### MSE 与最大似然

假设 `y = ŷ + ε`，噪声 ε 服从均值 0、方差 σ² 的正态分布：

```
p(y | x) = (1/√(2πσ²)) · exp(−(y − ŷ)² / (2σ²))
−log p(y | x) = (y − ŷ)² / (2σ²) + 常数
```

所以负对数似然（对所有样本求平均）就是 MSE 乘以常数再加常数，**最小化 MSE 就是在高斯噪声假设下做最大似然**。同理，第 6 章的交叉熵是在类别分布假设下做最大似然。**损失函数的选择，就是对"数据怎样产生"的假设的选择。** 如果噪声不是高斯分布（比如有很多离群点），MSE 就不是最好的选择，可能要换成绝对值误差。

### 为什么逻辑回归在 b/d 上能达到 100%：线性可分

如果存在一个超平面（`w·x + b = 0`）把两类完全分开，数据就叫**线性可分**的。b 和 d 对齐后，竖笔画在左还是在右，就足以完全区分它们，所以线性可分。这时逻辑回归的损失可以无限接近 0：只要把 w 不断放大，所有 z 的绝对值都变大，p 都趋向 0 或 1。所以训练损失从 0.0030 降到 0.0010 时，w 的长度一直在增长，永远不会停下来。这在实践中是一个问题（权重无限增大，模型过度自信），解决方法是**正则化**：在损失里加上 `λ|w|²`，惩罚过大的权重（第 11 章的权重衰减）。

### 随机梯度的噪声有多大

一批 B 个样本的平均梯度，是整体梯度的无偏估计，它的方差约是 `σ²_g / B`（σ²_g 是单个样本梯度的方差，第 6 章）。批大小加倍，梯度噪声的标准差只缩小 √2 倍，而计算量加倍。所以存在一个"划算"的批大小：太小时噪声太大，太大时多花的计算换来的精度提升很少。第 18 章会讨论大批量训练时学习率怎么跟着调。

## 7.10 横向对照：三个模型的对比

| | 线性回归 | 逻辑回归 | softmax 回归 |
|---|---|---|---|
| 输出 | 一个实数 | 一个概率 | K 个概率 |
| 模型 | `Xw + b` | `σ(Xw + b)` | `softmax(XW + b)` |
| 损失 | 均方误差 | 二元交叉熵 | 交叉熵 |
| 对应的噪声假设 | 高斯 | 伯努利（0/1） | 类别分布 |
| 输出层梯度 | `2(ŷ − y)/N` | `(p − y)/N` | `(P − Y)/N` |
| 参数梯度 | `Xᵀ × 输出层梯度` | 同左 | 同左 |
| 闭式解 | 有 | 无 | 无 |
| 在本书里 | 回归坐标（第 21 章的框回归） | 二值掩码的每个像素（第 34 章 Q-Mask） | 所有分类、语言模型的输出层 |

三者的梯度形式几乎完全一样：**输出层的梯度是"预测 − 目标"，参数的梯度是"输入的转置 × 输出层的梯度"**。这不是巧合——它们都属于"广义线性模型"，损失都是对应分布下的负对数似然。

## 7.11 本章小结

- 监督学习 = 模型 + 损失 + 优化；训练就是最小化训练集上的平均损失；
- 线性回归：MSE 损失，梯度 `(2/N)Xᵀr`；有闭式解，可以用来核对梯度下降；
- 残差分析：按组看误差，系统性的残差说明模型缺了某个信息；
- 学习率：太小、合适、震荡、发散；上限约 `2/λ_max`，收敛速度由条件数决定；
- 特征标准化降低条件数、加速训练；只能用训练集的统计量；
- 逻辑回归：sigmoid + 二元交叉熵，梯度 `Xᵀ(p − y)/N`；用 `logaddexp` 保证数值稳定；
- softmax 回归：62 类对齐字符上约 97%，远超平均模板的 85%：学出来的模板关注"类与类的差别"；
- 小批量 SGD：每步用一小批样本，更新更频繁，带来噪声；
- 线性层的梯度规则：`∂L/∂W = Xᵀ(∂L/∂Z)`。

## 参考答案

1. 闭式解可以用来**核对**梯度下降的结果，让我们确信梯度和训练循环是对的；而后面所有的模型（逻辑回归、神经网络）都没有闭式解，只能用梯度下降。此外特征很多时，闭式解的计算代价（约 D³）也太大。
2. 学习率太大，在最陡的方向上越跳越远（发散）。把学习率减小（比如除以 3 或 10），或者先标准化特征。
3. 不同特征的尺度不同时，损失曲面在各方向的弯曲度相差很大（条件数大），学习率受最陡方向限制，平缓方向走得极慢；标准化让各方向的尺度相近，条件数变小。用测试集的统计量会让测试集的信息进入训练过程（数据泄漏），评测结果会偏乐观，而且在真实部署时，未来的数据是拿不到的。
4. 平均模板只描述每类自己的平均样子，类之间共有的部分（比如 b 和 d 的圆圈）也被同等看重；学出来的模板通过最小化交叉熵，自动强调能区分各类的像素、忽略共有的像素。
5. ŷ = (0, 1, 2)，r = (−1, −2, −3)，MSE = (1 + 4 + 9)/3 = 4.667。`∂L/∂w = (2/3)(0·(−1) + 1·(−2) + 2·(−3)) = (2/3)(−8) = −5.333`；`∂L/∂b = (2/3)(−6) = −4`。
6. z = 0.5 − 0.5 = 0，p = 0.5，损失 `−ln 0.5 = 0.693`。`∂L/∂z = p − y = −0.5`，`∂L/∂w = −0.5 × (1, −1) = (−0.5, 0.5)`。
7. 上限 `2/200 = 0.01`；用 0.005 时，最平缓方向的收敛因子 `1 − 0.005 × 0.5 = 0.9975`。`0.9975ⁿ = 1/e` → `n ≈ 1/0.0025 = 400` 步。
8. `1024 × 62 + 62 = 63,550`；`∂L/∂W` 的形状 `(1024, 62)`，和 W 相同。
