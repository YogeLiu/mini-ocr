## F.1 softmax + 交叉熵的梯度是 p − y（第 6、7 章）

**结论**：logits z 经过 softmax 得到 p，标签是类别 c（独热向量 y），损失 L = −log p_c。那么 ∂L/∂z_k = p_k − y_k。

**推导**：先把损失写成 z 的函数：

```
L = −log p_c = −log( e^{z_c} / Σ_j e^{z_j} ) = −z_c + log Σ_j e^{z_j}
```

两项分别对 z_k 求导：

- 第一项 −z_c：k = c 时导数是 −1，否则是 0，也就是 −y_k；
- 第二项 log S，其中 S = Σ_j e^{z_j}：链式法则，(1/S) · ∂S/∂z_k = e^{z_k} / S = p_k。

相加得 ∂L/∂z_k = p_k − y_k。

**为什么重要**：这个梯度没有除法、没有 log，数值上非常稳定；它的意思也很直观——预测概率比目标高的类别被往下推，目标类别被往上拉，推拉的力度就是"差了多少"。所以框架总是把 softmax 和交叉熵合在一起算（`F.cross_entropy` 的输入是 logits，不是概率）。

**数值核对**（第 1 节）：

```
autograd： [ 0.611823  0.097711 -0.98517   0.231338  0.044297]
p − y   ： [ 0.611823  0.097711 -0.98517   0.231338  0.044297]
```

**同一个推导的推广**：对一批 B 个样本取平均时，梯度是 (p − y) / B；InfoNCE（F.10）、语言模型的每个位置都是这个结论。

## F.2 中心差分的误差是 h² 级（第 5 章）

**结论**：单边差分 (f(x + h) − f(x)) / h 的误差约为 f″(x) h / 2；中心差分 (f(x + h) − f(x − h)) / 2h 的误差约为 f‴(x) h² / 6。

**推导**：泰勒展开（第 5 章"放大后是直线"的更精确版本，多保留几项）：

```
f(x + h) = f(x) + f′(x) h + f″(x) h²/2 + f‴(x) h³/6 + …
f(x − h) = f(x) − f′(x) h + f″(x) h²/2 − f‴(x) h³/6 + …
```

- 单边：第一行减 f(x) 再除以 h，得到 f′(x) + f″(x) h/2 + …，误差的首项是 f″(x) h / 2；
- 中心：两行相减，偶数次项（f(x)、h² 项）抵消，得到 2f′(x) h + f‴(x) h³/3 + …；除以 2h，得到 f′(x) + f‴(x) h²/6 + …。

h 缩小 10 倍时，单边的误差缩小 10 倍，中心的误差缩小 100 倍。

**h 不能无限小**：f(x + h) 和 f(x − h) 的值很接近，相减会损失有效数字（灾难性抵消）。舍入误差约为 ε_机器 / h，截断误差约为 h²，两者之和在 h ≈ ε_机器^{1/3} 附近最小。float64 的 ε ≈ 1e-16，所以 h ≈ 1e-5；float32 的 ε ≈ 1e-7，最好的 h 约 5e-3，精度也只有 1e-5 左右——这就是第 5 章要求用 float64 做梯度检查的原因。

**数值核对**（第 2 节，f = sin，x = 1）：

```
h = 0.1   单边误差 -4.29e-02   中心误差 -9.00e-04   中心误差 / h² = -0.0900（推导：f‴(x)/6 = −cos(1)/6 = -0.0901）
h = 0.01   单边误差 -4.22e-03   中心误差 -9.00e-06   中心误差 / h² = -0.0900（推导：f‴(x)/6 = −cos(1)/6 = -0.0901）
h = 0.001   单边误差 -4.21e-04   中心误差 -9.01e-08   中心误差 / h² = -0.0901（推导：f‴(x)/6 = −cos(1)/6 = -0.0901）
```

## F.3 Adam 的偏差修正（第 11 章）

**结论**：m_t = β₁ m_{t−1} + (1 − β₁) g_t，m_0 = 0。如果梯度的期望一直是 E[g]，那么 E[m_t] = (1 − β₁ᵗ) E[g]。所以要除以 (1 − β₁ᵗ) 才是 E[g] 的无偏估计。v_t 同理。

**推导**：把递推式展开：

```
m_1 = (1 − β₁) g_1
m_2 = β₁ (1 − β₁) g_1 + (1 − β₁) g_2
m_t = (1 − β₁) Σ_{i=1..t} β₁^{t−i} g_i
```

取期望，E[g_i] 都等于 E[g]：

```
E[m_t] = (1 − β₁) E[g] · Σ_{i=1..t} β₁^{t−i} = (1 − β₁) E[g] · (1 − β₁ᵗ) / (1 − β₁) = (1 − β₁ᵗ) E[g]
```

中间用了等比数列求和 1 + β + … + β^{t−1} = (1 − βᵗ) / (1 − β)。

**为什么重要**：不修正时，m_1 = 0.1 g_1，v_1 = 0.001 g_1²，前几步的步长被严重扭曲（m 偏小 10 倍，√v 偏小约 30 倍，两者的比值偏大约 3 倍）。修正后第一步的更新量是 lr · g_1 / |g_1| = lr · sign(g_1)，与梯度的大小无关——这就是第 11 章说的"Adam 每个参数的步长约为 lr"。

**数值核对**（第 3 节，g 恒为 0.3）：

```

t = 5   m = 0.1229   m̂ = 0.3000   v = 0.000449   v̂ = 0.0900   这一步的更新 / lr = 1.0000
```

## F.4 KL ≥ 0，以及 H(p, q) = H(p) + KL(p‖q)（第 6、29、32 章）

**结论一**：H(p, q) = H(p) + KL(p‖q)。

**推导**：直接展开：

```
H(p, q) = −Σ p_i log q_i = −Σ p_i log p_i + Σ p_i log(p_i / q_i) = H(p) + KL(p‖q)
```

**结论二**：KL(p‖q) ≥ 0，当且仅当 p = q 时取等号。

**推导**：只用一个不等式：log x ≤ x − 1（对所有 x > 0 成立，只在 x = 1 时取等号）。它的证明：f(x) = x − 1 − log x，f′(x) = 1 − 1/x 在 x = 1 处为 0，f″(x) = 1/x² > 0，所以 x = 1 是最小值点，f(1) = 0。

令 x = q_i / p_i：

```
−KL(p‖q) = Σ p_i log(q_i / p_i) ≤ Σ p_i (q_i / p_i − 1) = Σ q_i − Σ p_i = 1 − 1 = 0
```

所以 KL ≥ 0。等号要求每个 q_i / p_i = 1。

**为什么重要**：

1. 由结论一，训练时最小化交叉熵 H(p_数据, q_模型)，等于最小化 KL（H(p_数据) 是常数）；损失的下界是数据本身的熵 H(p)，第 16 章"接近随机语料的熵"说的就是它；
2. 第 29 章 k3 估计量非负，用的是同一个不等式（F.8）。

**数值核对**（第 4 节）：

```
H(p) = 1.534686   H(p, q) = 1.801371   KL(p‖q) = 0.266685   H(p) + KL = 1.801371
KL(q‖p) = 0.249450（不对称）
```

## F.5 初始化的方差公式（第 11 章）

**结论**：z_j = Σ_{i=1..n} h_i W_ij。若 W_ij 独立、均值 0、方差 σ_w²，且与 h 独立，则 Var(z_j) = n σ_w² E[h²]。ReLU 网络的 E[h²] = Var(z_前一层) / 2，所以要 σ_w² = 2/n（Kaiming）才能让方差逐层不变。

**推导**：

1. 每一项 h_i W_ij 的均值：E[h_i W_ij] = E[h_i] E[W_ij] = 0（独立，且 E[W] = 0）；
2. 每一项的方差：Var(h_i W_ij) = E[h_i² W_ij²] − 0 = E[h_i²] E[W_ij²] = E[h²] σ_w²；
3. n 项互不相关（不同的 W_ij 独立），方差相加：Var(z_j) = n σ_w² E[h²]。

注意第 2 步用的是 E[h²]，不是 Var(h)：ReLU 的输出均值不是 0，两者不同。

**ReLU 的 E[h²]**：z 关于 0 对称时，h = max(z, 0) 一半时间是 0，一半时间等于 z，所以 E[h²] = E[z²] / 2 = Var(z) / 2。代入：Var(z_下一层) = n σ_w² Var(z) / 2。σ_w² = 2/n 时每层乘 1；PyTorch 默认的初始化方差约为 1/(3n)，每层乘 1/6，深层网络的信号会迅速变小。

**数值核对**（第 5 节，n = 512，输入方差 1）：

```
ReLU，σ_w² = 1/n：Var(z)  第  1 层 1.0037   第  5 层 0.0672   第 10 层 0.0022   （推导：第 1 层 = n σ_w² = 1，之后每层乘 n σ_w² / 2 = 0.5）
ReLU，σ_w² = 2/n：Var(z)  第  1 层 1.9964   第  5 层 1.8299   第 10 层 1.7499   （推导：第 1 层 = n σ_w² = 2，之后每层乘 n σ_w² / 2 = 1）
```

1/n 时 10 层后的方差 0.0022 与推导的 1/2⁹ ≈ 0.0020 一致；2/n 时基本保持（有限宽度带来的随机波动会慢慢累积，所以深层网络还需要第 11 章的归一化）。

## F.6 注意力为什么除以 √d（第 15 章）

**结论**：q、k 的每一维独立、均值 0、方差 1，则 q·k 的方差是 d。除以 √d 后方差回到 1。

**推导**：q·k = Σ_{i=1..d} q_i k_i。每一项均值 E[q_i] E[k_i] = 0，方差 E[q_i²] E[k_i²] = 1。d 项独立，方差相加得 d。

**为什么重要**：d = 64 时不缩放的分数标准差是 8。softmax 的输入相差几十时，输出几乎是独热的。softmax 的雅可比矩阵是 diag(p) − p pᵀ，p 接近独热时它几乎全是 0，梯度传不回去，训练不动。

**数值核对**（第 6 节）：

```
d =  16   Var(q·k) =   16.00   Var(q·k/√d) = 1.000
d =  64   Var(q·k) =   63.76   Var(q·k/√d) = 0.996
d = 256   Var(q·k) =  255.59   Var(q·k/√d) = 0.998
```

## F.7 策略梯度定理与基线（第 29 章）

**结论一**：J(θ) = E_{y~π_θ}[R(y)]，则 ∇J = E_{y~π_θ}[R(y) ∇log π_θ(y)]。

**推导**：把期望写成求和，R(y) 与 θ 无关：

```
∇J = ∇ Σ_y π_θ(y) R(y) = Σ_y R(y) ∇π_θ(y)
```

这一步之后无法采样估计（Σ_y 遍历所有可能的回答）。技巧是乘一个 π/π：

```
∇π_θ(y) = π_θ(y) · ∇π_θ(y) / π_θ(y) = π_θ(y) ∇log π_θ(y)       （对数导数技巧：(log f)′ = f′/f）
∇J = Σ_y π_θ(y) R(y) ∇log π_θ(y) = E_{y~π_θ}[R(y) ∇log π_θ(y)]
```

现在可以采样：从模型生成 y，算 R(y) ∇log π(y)，取平均。写成损失就是 −R · log π(y)（R 不求梯度）；SFT 是 R ≡ 1、y 来自数据的特例。

**结论二**：减去一个与 y 无关的基线 b，期望不变：E[(R − b) ∇log π] = E[R ∇log π]。

**推导**：

```
E[b ∇log π] = b Σ_y π(y) ∇log π(y) = b Σ_y ∇π(y) = b ∇ Σ_y π(y) = b ∇1 = 0
```

期望不变，但方差会变。b 接近 E[R] 时，R − b 的绝对值小，方差小；b 离 E[R] 很远时，方差巨大。

**结论三**（第 29 章"含自己的均值缩小 (n − 1)/n"）：对同一个题采样 n 个回答，用组内均值 R̄ 做基线：A_i = R_i − R̄。A_i 里有 R_i / n 这一项，它和 y_i 相关，不再满足结论二的条件：

```
A_i = (1 − 1/n) R_i − (1/n) Σ_{j≠i} R_j
E[A_i ∇log π(y_i)] = (1 − 1/n) E[R_i ∇log π(y_i)] − (1/n) Σ_{j≠i} E[R_j] E[∇log π(y_i)]
                   = (1 − 1/n) ∇J − 0
```

第二项是 0：y_j 和 y_i 独立，E[∇log π(y_i)] = 0（结论二里 b = 1 的情形）。所以梯度的方向不变，长度乘 (n − 1)/n。用"留一"均值 (1/(n−1)) Σ_{j≠i} R_j 做基线就没有这个缩放。

**数值核对**（第 7 节，4 个回答的 softmax 策略，20 万次采样）：

```
基线 b =   0.0   估计 [ 0.0545 -0.1334 -0.116   0.1949]   每个样本的方差之和     0.797
基线 b =   1.0   估计 [ 0.055  -0.1339 -0.118   0.1968]   每个样本的方差之和     0.292
基线 b = 100.0   估计 [ 0.1038 -0.1799 -0.3086  0.3847]   每个样本的方差之和  6973.246
```

b = 1（接近平均奖励）把方差降到约 1/3；b = 100 时期望虽然不变，但 20 万个样本的平均值仍然偏离精确值很远：方差太大，有限的样本估计不准。第 29 章"奖励整体平移 100 时没有基线训练不起来"就是这个现象。

## F.8 KL 的三个估计量（第 29、31 章）

**设定**：y ~ π，r = π_ref(y) / π(y)。三个估计量：

| | 公式 | 期望 |
|---|---|---|
| k1 | −log r | KL(π‖π_ref)（无偏） |
| k2 | (log r)² / 2 | 两个分布接近时 ≈ KL（有偏） |
| k3 | (r − 1) − log r | KL(π‖π_ref)（无偏），而且每个样本都 ≥ 0 |

**期望**：E_π[−log r] = Σ π log(π / π_ref) = KL(π‖π_ref)，k1 无偏。E_π[r] = Σ π · π_ref / π = Σ π_ref = 1，所以 E[r − 1] = 0，k3 = k1 + (r − 1) 的期望和 k1 相同。k3 ≥ 0 来自 F.4 的 log r ≤ r − 1。

**梯度：把估计量直接放进损失时得到什么**

实现时我们对采样到的 y 计算 k(y)，然后对 θ 求导；y 是采样出来的，**不对采样过程求导**。所以得到的是 E_π[∇k(y)]，它不一定等于 ∇E_π[k(y)]。

只有 log π 依赖 θ，log r = log π_ref − log π，所以 ∇log r = −∇log π，∇r = r ∇log r = −r ∇log π。

- **k1**：∇(−log r) = ∇log π。E_π[∇log π] = 0（F.7 结论二）。**放进损失后梯度的期望是 0**：k1 适合监控，不适合做损失。
- **k2**：∇(log r)²/2 = log r · ∇log r = log(π / π_ref) ∇log π。期望 Σ π log(π / π_ref) ∇log π。另一方面

  ```
  ∇KL(π‖π_ref) = Σ ∇π · log(π / π_ref) + Σ π ∇log π = Σ π ∇log π · log(π / π_ref) + 0
  ```

  两者相同。**k2 的梯度是 ∇KL(π‖π_ref)**，这正是我们想要的约束方向。
- **k3**：∇[(r − 1) − log r] = −r ∇log π + ∇log π = (1 − r) ∇log π。期望

  ```
  E_π[(1 − r) ∇log π] = E_π[∇log π] − Σ π · (π_ref / π) ∇log π = 0 − Σ π_ref ∇log π = ∇[−Σ π_ref log π] = ∇KL(π_ref‖π)
  ```

  **k3 的梯度是反方向的 KL(π_ref‖π) 的梯度。** 两个分布接近时两种 KL 近似相等，所以 GRPO 用 k3 做损失在实践中可行，但它约束的不是你以为的那个方向。

## F.9 带 KL 约束的最优策略与 DPO（第 30 章）

**结论一**：目标 J(π) = E_π[R(y)] − β KL(π‖π_ref) 的最大值点是

```
π*(y) = π_ref(y) exp(R(y) / β) / Z，   Z = Σ_y π_ref(y) exp(R(y) / β)
```

**推导**：把 J 改写成一个 KL。由 π* 的定义，R(y) = β log(π*(y) / π_ref(y)) + β log Z。代入：

```
J(π) = Σ π R − β Σ π log(π / π_ref)
     = Σ π [β log(π* / π_ref) + β log Z] − β Σ π log(π / π_ref)
     = β log Z − β Σ π log(π / π*)
     = β log Z − β KL(π‖π*)
```

β log Z 与 π 无关；KL ≥ 0（F.4），只在 π = π* 时为 0。所以 π* 是唯一的最大值点，最大值是 β log Z。

**结论二（DPO）**：反过来，奖励可以用最优策略表示：R(y) = β log(π*(y) / π_ref(y)) + β log Z。Bradley–Terry 模型 P(y_w ≻ y_l) = σ(R(y_w) − R(y_l)) 只用到奖励之差，β log Z 是同一个常数（与 y 无关），相减时消掉：

```
P(y_w ≻ y_l) = σ( β log(π*(y_w) / π_ref(y_w)) − β log(π*(y_l) / π_ref(y_l)) )
```

把未知的 π* 换成要训练的 π_θ，对偏好数据做最大似然，损失就是 −log σ(·)，即 DPO。

**Bradley–Terry 为什么是 σ**：它假设 P(y_w ≻ y_l) = e^{R_w} / (e^{R_w} + e^{R_l})。分子分母同除以 e^{R_w}：1 / (1 + e^{−(R_w − R_l)}) = σ(R_w − R_l)。

**数值核对**（第 9 节，4 个回答，β = 0.5）：

```
J(π*) = 0.529986   β log Z = 0.529986
随机试 2 万个策略，最大的 J = 0.528010（不超过 J(π*)）
任取一个 π：J(π) = 0.222568，β log Z − β KL(π‖π*) = 0.222568
反推的奖励 β log(π*/π_ref) = [ 0.47 -0.33 -0.53  0.17]，减去真实奖励 = [-0.53 -0.53 -0.53 -0.53]（全是同一个常数 −β log Z）
```

最后一行说明：从 π* 只能反推出"差一个常数"的奖励，而 DPO 恰好只需要奖励之差。

## F.10 InfoNCE 的梯度（第 20 章）

**结论**：B 对图文，相似度矩阵 s_ij = img_i · txt_j，损失 L = (1/B) Σ_i CE(s_i· / τ, 标签 i)（这里只写"按行"的一半，CLIP 再按列做一次取平均）。则 ∂L/∂s_ij = (p_ij − δ_ij) / (τB)，其中 p_ij 是第 i 行的 softmax，δ_ij 在 i = j 时为 1。

**推导**：第 i 行的 logits 是 s_ij / τ。由 F.1，CE 对 logits 的梯度是 p_ij − δ_ij；链式法则乘 ∂(s/τ)/∂s = 1/τ；对 B 行取平均再乘 1/B。

再往下一步，对文字向量 txt_j 的梯度：∂L/∂txt_j = Σ_i (p_ij − δ_ij) img_i / (τB)。正例（i = j）的系数是负的 (p_jj − 1)，梯度下降时 txt_j 被拉向 img_j；负例（i ≠ j）按概率 p_ij 加权推开：**模型越容易混淆的负例，推得越用力**。τ 越小，p 越尖，力量越集中在最难的几个负例上（第 20 章"温度不能太低"）。

## F.11 MinHash 与 LSH 的概率（第 33 章）

**结论一**：对集合 A、B，随机打乱全集的顺序，取两者各自排在最前面的元素。两者相同的概率等于 Jaccard 相似度 J = |A ∩ B| / |A ∪ B|。

**推导**：只看 A ∪ B 里的元素。随机排列下，A ∪ B 中排在最前的那个元素，等可能地是其中任何一个。"A 的最小值 = B 的最小值"当且仅当这个元素同时属于 A 和 B（如果它只属于 A，那么 A 的最小值是它，B 的最小值是另一个元素）。所以概率 = |A ∩ B| / |A ∪ B| = J。

用 k 个独立的哈希函数代替随机排列，"签名相同的比例"就是 J 的无偏估计，标准误约为 √(J(1 − J)/k)。

**结论二**：签名分成 b 段，每段 r 个哈希值；只要有一段完全相同，两个样本就成为候选对。候选的概率是 1 − (1 − J^r)^b。

**推导**：一段的 r 个值全相同的概率是 J^r（各哈希独立）；这一段不全相同的概率是 1 − J^r；b 段都不全相同的概率是 (1 − J^r)^b；至少一段全相同的概率是 1 − (1 − J^r)^b。

这个函数是一条 S 形曲线：J 小时几乎为 0，J 大时几乎为 1，陡峭的位置约在 J ≈ (1/b)^{1/r}。r = 4、b = 16 时约在 0.5。r 越大曲线越往右（候选越少、漏掉的越多），b 越大越往左。

**数值核对**（第 11 节）：

```
Jaccard = 0.4000   最小哈希相同的比例 = 0.4011
J = 0.3   公式 1 − (1 − J^r)^b = 0.1220   模拟 = 0.1203
J = 0.5   公式 1 − (1 − J^r)^b = 0.6439   模拟 = 0.6454
J = 0.8   公式 1 − (1 − J^r)^b = 0.9998   模拟 = 0.9998
```

## F.12 bootstrap 与标准误（第 6、25 章）

**结论**：n 个独立样本的平均数，标准误是 σ / √n。正确率（每个样本是 0 或 1）的 σ² = p(1 − p)，所以标准误是 √(p(1 − p) / n)。

**推导**：x̄ = (1/n) Σ x_i。独立变量的方差相加，常数提出来要平方：Var(x̄) = (1/n²) · n σ² = σ² / n。开方得 σ / √n。

**bootstrap 做的事**：我们不知道总体，只有这 n 个样本。bootstrap 把这 n 个样本当成总体，有放回地抽 n 个、算一次指标，重复几千次，看指标的分布有多宽。对平均数，它给出的标准误和公式一致；对 CER、TEDS 这种没有简单公式的指标，它仍然能用——这是第 25 章用它的原因。

**例子**：n = 200、正确率 70% 时，标准误约 √(0.7 × 0.3 / 200) = 3.2%，95% 区间宽约 ±6.4 个百分点。两个系统差 3 个百分点，在这个测试集上分不出来。

**数值核对**（第 12 节，200 个样本）：

```
正确率 0.635   bootstrap 标准误 0.0341   公式 √(p(1−p)/n) = 0.0340
95% 区间（百分位法）[0.565, 0.700]   正态近似 ±1.96 SE = ±0.067
```

## F.13 Dice 损失的梯度（第 34 章）

**结论**：p_j = σ(z_j)，Dice = (2 Σ p_j t_j + ε) / (Σ p_j + Σ t_j + ε)，损失 L = 1 − Dice。记分子 N = 2 Σ p t + ε，分母 M = Σ p + Σ t + ε，则

```
∂L/∂z_j = −(2 t_j M − N) / M² · p_j (1 − p_j)
```

前景 token（t_j = 1）：−(2M − N)/M² · p(1 − p)，负的，梯度下降把它的 z 往上推；背景 token（t_j = 0）：+N/M² · p(1 − p)，正的，往下压。

**推导**：商的求导法则，∂N/∂p_j = 2 t_j，∂M/∂p_j = 1：

```
∂Dice/∂p_j = (2 t_j · M − N · 1) / M²
```

再乘 ∂p_j/∂z_j = p_j(1 − p_j)（第 5 章 sigmoid 的导数），加负号。

**和按 token 平均的 BCE 比较**：BCE 对 z_j 的梯度是 (p_j − t_j) / n_总（F.1 的二分类版本），分母是**全部 token 数**。前景很少时，背景越多，每个前景 token 分到的梯度越小，损失值也被大量"容易判对的背景"拉低。Dice 的分母 M 是"预测的前景 + 真实的前景"，背景只通过它们的 p 进入 M：背景判得越准（p 越小），对 M 的影响越小。

**数值核对**（第 13 节：ε = 1；3 个前景 token，p = 0.5，还没学会；背景 p ≈ 0.01，基本判对了）：

```
共   64 个 token   Dice 损失 0.345，前景 token 的梯度 -0.0551（公式 -0.0551）   BCE 损失 0.0420，前景 token 的梯度 -0.00781（公式 (p − 1)/N = -0.00781）
共 1024 个 token   Dice 损失 0.745，前景 token 的梯度 -0.0278（公式 -0.0278）   BCE 损失 0.0120，前景 token 的梯度 -0.00049（公式 (p − 1)/N = -0.00049）
```

背景从 61 个增加到 1021 个时，BCE 对前景的梯度缩小到 1/16，损失只有 0.012，"看起来已经训练好了"；Dice 的梯度只缩小到 1/2，损失 0.745 如实地说明前景还没学会。这就是第 34 章第 3 部分"3 个前景 token 时 CE 0.241、Dice 0.765"的原因，也是 Q-Mask 同时用 Dice 和 CE 的原因：CE 给每个 token 稳定的梯度，Dice 保证小前景不被淹没。

注意背景的 p 不小时，它们会让 M 变大，Dice 也会被稀释（这时 M 里背景的 Σ p 占大头）；而 sigmoid 饱和（p 接近 0 或 1）时 p(1 − p) 很小，Dice 的梯度会消失，BCE 没有这个因子。两种损失的缺点互补。

## F.14 训练计算量 ≈ 6ND（第 18 章）

**结论**：参数量 N 的模型，训练 D 个 token，总计算量约 6ND 次浮点运算。

（这一节没有数值核对。第 18 章用 6ND 把实测的训练速度换算成了每秒的浮点运算数：31,461 token/秒 → 656 GFLOP/秒。）

**推导**：只数矩阵乘法（它占绝大多数）。一个 (d_in × d_out) 的线性层处理一个 token：

- **前向**：y = xW，每个输出元素做 d_in 次乘法、d_in 次加法，共 2 · d_in · d_out = 2 × 该层参数数；
- **反向**，两个矩阵乘法（第 7 章的线性层梯度规则）：
  - 对输入的梯度 ∂L/∂x = (∂L/∂y) Wᵀ，又是 2 · d_in · d_out；
  - 对权重的梯度 ∂L/∂W = xᵀ (∂L/∂y)，又是 2 · d_in · d_out。

每个参数每个 token：前向 2 次、反向 4 次，共 6 次。对所有层求和得 6N，乘 D 个 token 得 6ND。

**没算进去的部分**：注意力的 QKᵀ 和 (·)V 不含参数。前向每层每 token 约 4Td 次运算，训练时约 3 倍即 12Td。一层 Transformer 约有 12d² 个参数，6N 这部分是 72d²，两者之比是 T / (6d)（第 19 章的 N / 6d）：序列长度远小于 6d 时可以忽略，长序列时要加上。冻结参数时，冻结的层不需要"对权重的梯度"，但"对输入的梯度"还要算（梯度要穿过它），所以是 4N 而不是 2N——这和第 28 章"冻结不能省激活值"是同一个道理。

## F.15 InfoNCE 给出互信息的下界（第 20 章）

**结论**：一批 B 对配对的图文，按行的 InfoNCE 损失（F.10）记为 L。不管打分函数 f 是什么，都有

```
ln B − L ≤ I(X; Y)
```

其中 I(X; Y) 是图和文字的互信息。第 20 章用这个式子解释"批越大越好"：B 越大，这个下界能达到的上限 ln B 越高。

**要用到的三个事实**（都来自 F.4）：

1. **熵**：均匀分布在 B 个值上的随机变量，熵是 ln B；
2. **交叉熵 ≥ 熵**：用任何一个分类器 q 预测 k，平均损失 E[−log q(k | D)] ≥ H(k | D)（H(p, q) = H(p) + KL ≥ H(p)，对每个 D 成立，再取平均）；
3. **互信息**：I(A; B) = H(A) − H(A | B) ≥ 0，所以"多知道一些条件，熵不会变大"：H(A | B, C) ≤ H(A | B)。

**把 InfoNCE 看成一个"猜编号"的游戏**：随机选一个编号 k ∈ {1, …, B}（均匀）。从联合分布 p(x, y) 抽一对 (x, y_k)，再从 p(y) 独立地抽另外 B − 1 个 y_j 放进其余位置。把 D = (x, y_1, …, y_B) 交给模型，模型要猜哪一个 y 和 x 是一对。InfoNCE 的一行就是用 softmax_j f(x, y_j) 做这个猜测的交叉熵（实际训练时批里的配对总在对角线上，但每个位置都是对称的，和随机打乱编号是一回事）。

**第一步：ln B − L ≤ I(k; D)。**

```
I(k; D) = H(k) − H(k | D) = ln B − H(k | D) ≥ ln B − L
```

第二个等号用了事实 1，最后的不等号用了事实 2：L 是一个具体分类器的交叉熵，不会小于 H(k | D)。

**第二步：I(k; D) ≤ I(X; Y)。** 把 D 拆成 y 的部分和 x 的部分（互信息的链式法则，和熵的 H(A, B) = H(A) + H(B | A) 是同一个道理）：

```
I(k; D) = I(k; y_1, …, y_B) + I(k; x | y_1, …, y_B)
```

- **第一项是 0**：只看 y 不看 x 时，每个 y_j 的分布都是 p(y)（配对的那个 y_k 的边缘分布也是 p(y)），B 个 y 独立同分布，和 k 无关；
- **第二项**：

  ```
  I(k; x | y_1..y_B) = H(x | y_1..y_B) − H(x | k, y_1..y_B)
  ```

  知道 k 以后，x 只和 y_k 有关，所以 H(x | k, y_1..y_B) = H(X | Y)；不知道 k 时，由事实 3，H(x | y_1..y_B) ≤ H(x) = H(X)。所以第二项 ≤ H(X) − H(X | Y) = I(X; Y)。

两步合起来：ln B − L ≤ I(k; D) ≤ I(X; Y)。

**三个推论**：

1. **下界最多是 ln B**：L ≥ 0，所以 ln B − L ≤ ln B。互信息很大时（图文高度相关），小批无论怎么训练都"测不满"它，这就是"批越大越好"的理论理由；
2. **f 越好，下界越紧**：最好的打分函数是 f(x, y) = log p(x, y) / (p(x) p(y)) 加任意只依赖 x 的常数（这一行的 softmax 不受影响）——对比学习其实是在学"这对图文比随机配对的可能性大多少倍"；
3. **这只是一个下界**：训练让 L 变小，等于把下界往上推，并不直接告诉你 I 是多少；第 20 章的零样本分类、检索、线性探针才是检验表示好不好的办法。

**数值核对**（第 15 节）：8 种图、8 种文字，80% 的概率配对正确，其余均匀，精确算出 I(X; Y) = 1.1899（输出里的 K = 8 是种类数，I(X; Y) ≤ H(Y) = ln K = 2.0794，是互信息可能的最大值）；然后真的按 InfoNCE 抽批、算 L：
