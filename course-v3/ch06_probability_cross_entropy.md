# 第 6 章　概率、交叉熵与最大似然

## 本章在全景图中的位置

一个 OCR 模型看到一个模糊的字符，它不会说"这是 o"，而是说"70% 是 o、25% 是 O、5% 是 0"。语言模型写下一个 token 时也一样：它给词表里每个 token 一个概率。**模型的输出是概率分布**，训练的目标就是让"正确答案的概率"尽可能大。

本章讲清楚这一过程的数学：概率分布、期望与方差、把分数变成概率的 **softmax**、衡量"模型给正确答案多少概率"的**交叉熵**，以及它背后的原理**最大似然**。本书从第 7 章的逻辑回归到第 26 章的 VLM 微调，用的损失函数**全都是交叉熵**；第 30、31 章的 DPO 和 GRPO 也是在"回答的对数概率"上做文章（第 27 章）。所以这一章的每个公式都值得反复推敲。

## 6.1 求和与连乘

### Σ

```
Σ_{i=1}^{n} a_i = a₁ + a₂ + ... + a_n
```

读作"对 i 从 1 到 n，把 a_i 加起来"。下标的范围经常省略（"对所有 i"），写成 `Σ_i a_i`。代码里就是 `a.sum()`。几条规则：

- 常数可以提出来：`Σ_i c·a_i = c · Σ_i a_i`；
- 和可以拆开：`Σ_i (a_i + b_i) = Σ_i a_i + Σ_i b_i`；
- **两个求和可以交换顺序**：`Σ_i Σ_j a_ij = Σ_j Σ_i a_ij`（先按行加再加起来，等于先按列加再加起来）。

### Π

```
Π_{i=1}^{n} a_i = a₁ × a₂ × ... × a_n
```

连乘。代码里是 `np.prod(a)`。对数把连乘变成求和：

```
ln(Π_i a_i) = Σ_i ln a_i
```

这条恒等式是本章最重要的工具之一（6.6 节）。

## 6.2 概率分布、期望与方差

### 随机变量与分布

**随机变量**是一个取值不确定的量，比如"掷一次骰子的点数" X。它的**分布**说明每个取值的概率：

```
P(X = 1) = P(X = 2) = ... = P(X = 6) = 1/6
```

所有概率都 ≥ 0，加起来等于 1。只能取有限个值的分布叫**离散分布**。分类问题里，"这个字符是哪一类"就是一个有 K 个可能取值的离散分布，叫**类别分布**（categorical distribution），可以用一个长度为 K、元素非负、和为 1 的向量 `p` 表示。第 1 章的独热向量 `[0, 0, 1, 0]` 也是一个分布：100% 是第 2 类。

### 期望

**期望**（expectation）是"按概率加权的平均值"：

```
E[X] = Σ_x P(X = x) · x
```

掷骰子：`E[X] = (1 + 2 + 3 + 4 + 5 + 6)/6 = 3.5`。期望不一定是能取到的值。

更一般地，对任何函数 f：`E[f(X)] = Σ_x P(x) f(x)`。**损失函数就是一个期望**：训练的目标是"在数据分布上的平均损失"最小（第 7 章）。

### 方差

**方差**（variance）衡量取值"散开"的程度：

```
Var[X] = E[(X − E[X])²] = Σ_x P(x) (x − E[X])²
```

掷骰子：`((1−3.5)² + (2−3.5)² + ... + (6−3.5)²)/6 = (6.25 + 2.25 + 0.25 + 0.25 + 2.25 + 6.25)/6 = 17.5/6 = 2.9167`。方差的平方根叫**标准差**，和 X 有相同的单位：1.708。

### 大数定律

演示第 1 部分（`python -m labs.ch06.prob_tour`）：

```
  理论：E[X] = Σ p·x = 3.5000   Var[X] = Σ p·(x-E)² = 2.9167   标准差 1.7078
  掷      10 次：样本均值 2.8000   样本方差 2.9600
  掷     100 次：样本均值 3.6700   样本方差 2.7411
  掷   10000 次：样本均值 3.5053   样本方差 2.9324
  掷 1000000 次：样本均值 3.5021   样本方差 2.9173
```

样本越多，**样本均值越接近期望**。这叫**大数定律**。它是一切"用数据估计"的基础：我们无法知道真实的数据分布，但可以用大量样本的平均来近似。

样本均值的波动有多大？可以证明，n 个独立样本的均值的标准差是 `σ/√n`（σ 是单个样本的标准差）。10 次时 `1.708/√10 = 0.54`，所以 2.8 与 3.5 相差 0.7，大约是 1.3 个标准差，并不奇怪；10000 次时只有 0.017。**样本数增加 100 倍，误差缩小 10 倍**。第 25 章评测时会用这个规律估计"测试集上的准确率有多可信"：在 1000 个样本上测得 90% 准确率，它的标准差约为 `√(0.9 × 0.1 / 1000) ≈ 0.95%`。

## 6.3 从计数到概率，以及熵

### 频率

最简单的估计概率的方法：数一数。演示第 2 部分统计 2000 个公式（第 3 章的 level 3）里每个字符的出现频率：

```
  47565 个字符，27 种；概率最高的 5 个: [('{', 0.1627), ('}', 0.1627), ('a', 0.0708), ('c', 0.07), ('f', 0.0484)]
  熵 H = 2.8993 nat = 4.1828 bit；均匀分布（27 种）的熵 = 3.2958 nat
```

花括号占了 1/3 的字符——和第 1 章的观察一致。

### 熵：平均的"意外程度"

如果一个事件的概率是 p，看到它发生时的"意外程度"定义为 `−log p`：

- 必然发生（p = 1）：`−log 1 = 0`，毫不意外；
- 概率 1/2：`−log(1/2) = log 2`；
- 概率很小：意外程度很大。

为什么用 log？因为两个独立事件同时发生的概率是 `p₁p₂`，意外程度 `−log(p₁p₂) = −log p₁ − log p₂`，正好是两者之和。"意外"可以相加，这符合直觉。

一个分布的**熵**（entropy）是平均的意外程度：

```
H(p) = E[−log p(X)] = −Σ_k p_k log p_k
```

（约定 `0 · log 0 = 0`：不可能发生的事件不贡献意外。）

- 用自然对数 ln 时，单位叫 **nat**；用 log₂ 时，单位叫 **bit**（比特）。`1 nat = 1/ln 2 ≈ 1.443 bit`；
- 熵的含义：**如果你知道真实分布，平均要用多少 bit 才能编码一个样本**。公式字符的熵是 4.18 bit，意思是理论上平均每个字符用 4.18 bit 就能编码，而如果把 27 种字符当作等可能，需要 `log₂ 27 = 4.75` bit；
- K 种取值的分布中，**均匀分布的熵最大**，等于 `log K`；只有一种取值必然发生时，熵为 0。

**手算**：`H([0.5, 0.5]) = −2 × 0.5 ln 0.5 = ln 2 = 0.693 nat = 1 bit`（抛一次硬币的信息量）。`H([0.9, 0.1]) = −(0.9 ln 0.9 + 0.1 ln 0.1) = 0.0948 + 0.2303 = 0.325 nat`——一个很偏的硬币，结果不怎么出人意料。

## 6.4 softmax：从分数到概率

### 定义

模型的最后一层（比如第 4 章的线性层）输出 K 个任意实数，叫 **logits**（未归一化的对数概率）。要把它们变成一个概率分布，需要：每个都变成正数，并且和为 1。**softmax** 函数：

```
softmax(z)_k = e^{z_k} / Σ_j e^{z_j}
```

- `e^{z_k}` 总是正数；
- 除以总和，保证和为 1；
- 保持大小顺序：z 越大，概率越大。

**手算** `z = (2, 1, 0.1)`：`e² = 7.389`，`e¹ = 2.718`，`e^0.1 = 1.105`，总和 11.212。概率 `(0.659, 0.242, 0.099)`。

```
  logits [2.0, 1.0, 0.1] -> softmax [0.659, 0.2424, 0.0986]
```

为什么叫 softmax？因为它是 argmax 的一个"柔和"版本：argmax 把最大的设为 1、其余为 0；softmax 让最大的概率最大，但其他的也有份。

### 性质一：平移不变

```
  所有 logits 加 100: [0.659, 0.2424, 0.0986]  ← 不变
```

**证明**：`e^{z_k + c} / Σ_j e^{z_j + c} = e^c · e^{z_k} / (e^c · Σ_j e^{z_j}) = e^{z_k} / Σ_j e^{z_j}`。分子分母的 `e^c` 约掉了。所以 **只有 logits 之间的差才有意义**。

### 性质二：缩放改变"尖锐程度"——温度

```
  所有 logits 乘 2  : [0.8638, 0.1169, 0.0193]  ← 更"尖"
  温度 T = 0.5 : softmax(z / T) = [0.8638, 0.1169, 0.0193]
  温度 T = 1.0 : softmax(z / T) = [0.659, 0.2424, 0.0986]
  温度 T = 2.0 : softmax(z / T) = [0.5017, 0.3043, 0.194]
  温度 T = 10.0: softmax(z / T) = [0.3661, 0.3312, 0.3027]
```

把 logits 除以一个数 T（叫**温度**，temperature）：T < 1 让分布更尖（更"确定"），T > 1 让分布更平（更"随机"），T → ∞ 时趋向均匀分布，T → 0 时趋向 argmax。第 17 章生成文字时，温度控制模型输出的随机性；第 20 章的 CLIP 有一个可学习的温度参数。

### 数值稳定（练习 6.1）

```
  logits [1000, 1001, 1002]：直接算 [nan, nan, nan]   减最大值后 [0.09, 0.2447, 0.6652]
```

`e^1000` 超出了 float64 能表示的范围（约 `e^709`），变成 `inf`，`inf / inf = nan`。利用平移不变性，先**减去最大值**：最大的 logit 变成 0，`e^0 = 1`，其他的都是 `e^{负数} ≤ 1`，永远不会溢出。

```python
def softmax(logits):
    z = np.asarray(logits, dtype=np.float64)
    z = z - z.max(axis=-1, keepdims=True)        # 沿最后一维减去最大值；keepdims 以便广播
    e = np.exp(z)
    return e / e.sum(axis=-1, keepdims=True)
```

`axis=-1` 让它对任意形状的输入都沿最后一维（类别维）计算：`(N, K)` 的一批 logits，每一行独立做 softmax。

### log-softmax（练习 6.2）

```
  log(softmax([0, -800])) = [0.0, -inf]   log_softmax = [0.0, -800.0]
```

第二个类的概率是 `e^{−800}`，比 float64 能表示的最小正数还小，下溢成 0，`log 0 = −inf`。但我们需要的是它的**对数**，−800 这个数本身完全可以表示。所以直接计算对数：

```
log softmax(z)_k = z_k − log Σ_j e^{z_j}
```

后面一项叫 **logsumexp**，同样用减最大值的技巧计算：`log Σ_j e^{z_j} = m + log Σ_j e^{z_j − m}`。

```python
def log_softmax(logits):
    z = np.asarray(logits, dtype=np.float64)
    m = z.max(axis=-1, keepdims=True)
    return z - (m + np.log(np.exp(z - m).sum(axis=-1, keepdims=True)))
```

**原则：需要对数概率时，直接算对数概率，永远不要先算概率再取 log。** PyTorch 的 `F.log_softmax` 和 `F.cross_entropy` 内部就是这样实现的（第 9 章）。

## 6.5 交叉熵

### 第一种理解：−log（给正确答案的概率）

分类问题的损失函数：模型对一个样本输出分布 p，正确答案是第 y 类。损失是

```
L = −log p_y
```

演示第 4 部分：

```
  正确类的概率 0.99   -> 损失 0.0101
  正确类的概率 0.9    -> 损失 0.1054
  正确类的概率 0.5    -> 损失 0.6931
  正确类的概率 0.1    -> 损失 2.3026
  正确类的概率 0.01   -> 损失 4.6052
  正确类的概率 0.001  -> 损失 6.9078
```

- 给正确答案的概率越接近 1，损失越接近 0；
- 概率越小，损失越大，而且增长得越来越快：从 0.1 到 0.01，损失增加 2.3；从 0.01 到 0.001，又增加 2.3。**每差 10 倍，损失加 2.3（= ln 10）**；
- 只关心正确类的概率，不关心其他类之间怎么分配。

一批 N 个样本的损失是平均值：`L = −(1/N) Σ_i log p_{i, y_i}`。

### 练习 6.3：实现

```python
def cross_entropy(logits, labels):
    lp = log_softmax(logits)                                      # (N, K)
    labels = np.asarray(labels)
    return float(-lp[np.arange(len(labels)), labels].mean())      # 每一行取出正确类那一列
```

花式下标 `lp[np.arange(N), labels]` 取出每个样本正确类的对数概率——和第 1 章 `one_hot` 用的是同一个技巧。

### 一个极其有用的检查：初始损失应该是 ln K

```
       2 类均匀猜测的损失 ln K = 0.6931
      10 类均匀猜测的损失 ln K = 2.3026
      62 类均匀猜测的损失 ln K = 4.1271
     100 类均匀猜测的损失 ln K = 4.6052
  151936 类均匀猜测的损失 ln K = 11.9312
  随机初始化（logits 很小）的模型，在 1000 个样本上的交叉熵 = 4.1271
  logits 很大的随机模型（"自信地乱猜"）= 23.7893
```

一个**刚初始化**的模型，什么都不会，logits 都接近 0，softmax 接近均匀分布，每个类的概率约 1/K，损失约 `−log(1/K) = ln K`。

- 62 类字符识别：初始损失应该约是 **4.13**；
- 151936 是 Qwen 系列词表的大小，语言模型的初始损失应该约是 11.93。

**这是训练开始前的第一项检查**（第 10 章的"体检清单"）。如果你的 62 类模型初始损失是 23.8，说明初始化时 logits 太大，模型在"自信地乱猜"——对大部分样本给正确答案的概率极小，损失巨大，训练初期的梯度也会很不稳定。第 11 章讲初始化时会回到这个问题。

### 第二种理解：两个分布之间的交叉熵

把正确答案也看成一个分布：独热向量 `y`（第 y 类为 1，其余为 0）。两个分布 p（真实）和 q（模型）之间的**交叉熵**定义为：

```
H(p, q) = −Σ_k p_k log q_k
```

当 p 是独热向量时，求和里只剩第 y 项：`H(y, q) = −log q_y`，正是上面的损失。这就是名字的来源。

交叉熵的含义：**用分布 q 去编码来自分布 p 的样本，平均需要多少 nat**。如果 q = p，就是熵 H(p)；q 和 p 差得越远，需要的越多。

### 熵、交叉熵与 KL 散度（练习 6.4）

```
H(p, q) = −Σ p_k log q_k
        = −Σ p_k log p_k + Σ p_k log(p_k / q_k)
        = H(p) + KL(p || q)
```

第二项叫 **KL 散度**（Kullback–Leibler divergence）：

```
KL(p || q) = Σ_k p_k log(p_k / q_k)
```

它衡量"用 q 代替 p 多花了多少"。性质：

- `KL(p || q) ≥ 0`，当且仅当 p = q 时等于 0（证明见"深入一步"）；
- **不对称**：`KL(p || q) ≠ KL(q || p)`，所以它不是真正的"距离"；
- 如果某处 p > 0 而 q = 0，KL 是无穷大：模型认为不可能的事情发生了。

演示第 6 部分（p = (0.7, 0.2, 0.1)）：

```
  q1 接近 p  KL(p||q) = 0.0227  KL(q||p) = 0.0241   交叉熵 H(p,q) = 0.8245 = H(p) 0.8018 + KL 0.0227
  q2 均匀    KL(p||q) = 0.2968  KL(q||p) = 0.3243   交叉熵 H(p,q) = 1.0986 = H(p) 0.8018 + KL 0.2968
  q3 很偏    KL(p||q) = 1.2928  KL(q||p) = 1.3996   交叉熵 H(p,q) = 2.0946 = H(p) 0.8018 + KL 1.2928
```

**训练的含义**：真实分布 p 是固定的（数据决定），H(p) 是常数。所以**最小化交叉熵 = 最小化 KL(p || q) = 让模型分布尽量接近真实分布**。交叉熵的最小值是 H(p)，不是 0——如果数据本身有不确定性（比如一个模糊的字符，标注员一半标 o、一半标 O），模型再好也无法让损失低于数据的熵。

KL 散度在第 29–31 章会再次出现：强化学习时，常常要求新模型不要偏离原模型太远，用的就是 KL 散度（Xiaomi-OCR-0 的 Mix-RL 选择了**不加** KL 惩罚，第 31、34 章讨论这个选择）。

## 6.6 最大似然

### 第三种理解：交叉熵是负对数似然

为什么训练要用交叉熵，而不是别的什么？答案来自统计学的**最大似然估计**（maximum likelihood estimation，MLE）。

**似然**（likelihood）：给定模型参数 θ，**观测到的数据**在这个模型下出现的概率：

```
L(θ) = P(数据 | θ) = Π_i P(y_i | x_i, θ)       （样本独立时，联合概率是各自概率的乘积）
```

**最大似然**：选择让观测数据出现概率最大的参数。直觉是：好的模型应该认为"真实发生的事情"是很可能发生的。

### 硬币的例子

抛 10 次硬币，7 次正面。设正面概率为 p，这串结果的似然是 `p⁷(1 − p)³`。哪个 p 让它最大？

演示第 5 部分：

```
  似然最大的 p = 0.70，对数似然最大的 p = 0.70（= 7/10）
  p = 0.5: 似然 0.000977   对数似然 -6.9315
  p = 0.6: 似然 0.001792   对数似然 -6.3247
  p = 0.7: 似然 0.002224   对数似然 -6.1086
  p = 0.8: 似然 0.001678   对数似然 -6.3903
```

**手推**：取对数（log 是增函数，不改变最大值的位置）：

```
ℓ(p) = ln L = 7 ln p + 3 ln(1 − p)
dℓ/dp = 7/p − 3/(1 − p) = 0
7(1 − p) = 3p   →   p = 7/10
```

最大似然估计就是频率 7/10。推广：类别分布的最大似然估计是**各类的出现频率**——6.3 节的"数一数"其实就是最大似然。

### 为什么取对数

```
  2000 个 0.1–0.9 之间的概率连乘 = 0.0（下溢成 0）；它们的 log 之和 = -1671.6
```

有很多样本时，似然是成千上万个小于 1 的数的乘积，会**下溢**成 0，没法比较。对数把乘积变成求和（6.1 节），既不会下溢，求导也方便得多。

### 最大似然 = 最小化交叉熵

```
最大化  Π_i P(y_i | x_i, θ)
⟺ 最大化  Σ_i log P(y_i | x_i, θ)
⟺ 最小化  −(1/N) Σ_i log P(y_i | x_i, θ)       （取负、除以 N 都不改变最优的 θ）
```

最后一行正是交叉熵损失！**用交叉熵训练分类器，就是在做最大似然估计。** 这不是一个随意的选择，而是有统计学根据的。语言模型（第 14、16 章）的损失同样是交叉熵：每个位置预测下一个 token，损失是 `−log P(正确的下一个 token)`，整句话的对数似然就是各位置对数概率之和（第 27 章）。

## 6.7 交叉熵的梯度：p − y

训练需要损失对 logits 的梯度。对一个样本，`L = −log softmax(z)_y = −z_y + log Σ_j e^{z_j}`。对 `z_k` 求偏导：

```
∂L/∂z_k = −[k = y] + e^{z_k} / Σ_j e^{z_j}
        = p_k − y_k
```

其中 `[k = y]` 在 k = y 时为 1、否则为 0，就是独热向量 `y_k`；第二项用了 `d/dz_k log Σ_j e^{z_j} = e^{z_k} / Σ_j e^{z_j}`（链式法则：log 的导数是 1/u，u 对 z_k 的导数是 e^{z_k}）。

**结果美得惊人：梯度 = 预测分布 − 真实分布。**

- 对正确类：`p_y − 1 < 0`，梯度下降会**增大**它的 logit；
- 对错误类：`p_k > 0`，会**减小**它的 logit，减小的幅度与模型给它的概率成正比——**越"自信地犯错"，被纠正得越厉害**；
- 当预测完全正确（p = y）时，梯度为 0。

N 个样本平均时，梯度再除以 N。测试 `test_cross_entropy_gradient_is_p_minus_y` 用第 5 章的数值梯度验证了这个公式：`(softmax(z) − one_hot(y)) / N`，相对误差小于 10⁻⁷。

**手算**：z = (2, 1, 0.1)，正确类 y = 1。p = (0.659, 0.242, 0.099)。梯度 = (0.659, 0.242 − 1, 0.099) = (0.659, −0.758, 0.099)。梯度下降会降低类 0 和类 2 的分数，提高类 1 的分数——提高的量恰好等于降低的总量（梯度各分量之和为 0，因为 p 和 y 的和都是 1）。

## 6.8 一个最简单的"语言模型"

演示第 7 部分：用训练集的字符频率（6.3 节）作为模型，去"预测"另外 500 个公式（不同种子生成的测试集）里的每个字符，计算平均的 `−log p`——也就是交叉熵：

```
  测试集 11827 个字符
  均匀模型   的平均 -log p = 3.2958 nat   困惑度 e^H = 27.0
  字符频率模型的平均 -log p = 2.9007 nat   困惑度 = 18.2
  把频率与均匀分布混合（alpha=0.0）: 2.9007 nat
  把频率与均匀分布混合（alpha=0.5）: 2.9394 nat
  把频率与均匀分布混合（alpha=2.0）: 3.0522 nat
```

### 困惑度

交叉熵的指数 `e^H` 叫**困惑度**（perplexity）。它的含义是：**模型平均在多少个选项之间"犹豫"**。均匀模型在 27 个字符之间犹豫，困惑度 27；字符频率模型知道 `{` 和 `}` 很常见，困惑度降到 18.2。困惑度是语言模型最常用的指标之一（第 14、16 章）。

### 读这个结果

- 频率模型在测试集上的交叉熵 2.9007，非常接近训练集分布的熵 2.8993（6.3 节）。这符合 `交叉熵 = 熵 + KL`：模型（训练集频率）和测试数据的分布几乎一样，KL 接近 0。这个模型已经是"不看上下文"的模型里最好的了；
- 混入均匀分布（叫**平滑**，smoothing）反而变差——因为这里训练集足够大、字符集固定，没有"训练时没见过"的字符。如果测试集里出现一个训练集里从未出现的字符，频率模型给它的概率是 0，`−log 0 = ∞`，平滑就必不可少了；
- 要做得更好，模型必须**看上下文**：看到 `\fra` 之后，下一个几乎肯定是 `c`。第 14 章的 bigram 模型和第 16 章的 GPT 就是这样做的，它们在同样的数据上的困惑度会远低于 18.2。

## 6.10 常见错误

| 现象 | 原因 | 怎么查 |
|---|---|---|
| 损失是 `nan` 或 `inf` | softmax 没有减最大值而溢出；或者先 softmax 再 log | 用 log-softmax；检查 logits 的最大值 |
| 初始损失远大于 ln K | 初始化时 logits 太大 | 打印第一步的 logits 的标准差（应接近 0） |
| 初始损失远小于 ln K | 标签泄漏进了输入；或者损失只在部分样本上算 | 检查数据管道 |
| 把 softmax 的输出又传给了 cross_entropy | PyTorch 的 `F.cross_entropy` 要求输入 **logits**，内部自己做 log-softmax；传概率进去相当于做了两次 softmax | 模型最后一层不要加 softmax（第 9、10 章） |
| softmax 沿错了维度 | `axis=0` 和 `axis=-1` 混淆 | 检查 `p.sum(axis=-1)` 是否全为 1 |
| 交叉熵看起来"不下降了"，停在某个值 | 可能已经接近数据的熵（无法再降）；也可能是 bug | 对比一个已知的下界（如 6.8 节的频率模型） |

## 6.11 真实世界对照

- **语言模型的损失**：Qwen3.5 这样的模型，词表约 15 万，初始损失约 11.9；训练好的模型在普通文本上的损失通常在 2 左右（困惑度约 7）。VLM 微调时（第 26 章），只在**回答**部分的 token 上算交叉熵，提示词和图像 token 被掩码掉；

## 6.12 深入一步

### 为什么 KL ≥ 0

用一个不等式：对任何 x > 0，`ln x ≤ x − 1`（等号仅在 x = 1 时成立；画出 `ln x` 和直线 `x − 1` 的图，直线在 x = 1 处与曲线相切，曲线始终在直线下方）。于是

```
−KL(p || q) = Σ_k p_k ln(q_k / p_k) ≤ Σ_k p_k (q_k / p_k − 1) = Σ_k q_k − Σ_k p_k = 1 − 1 = 0
```

（求和只对 p_k > 0 的项；`Σ q_k` 只对这些项求和时 ≤ 1，不等式仍然成立。）所以 KL ≥ 0，等号当且仅当所有 `q_k / p_k = 1`，即 p = q。由此也得到：交叉熵 `H(p, q) ≥ H(p)`，以及 K 类分布的熵 ≤ `ln K`（取 q 为均匀分布：`0 ≤ KL(p || u) = ln K − H(p)`）。

### softmax 的雅可比矩阵

6.7 节直接对 `log softmax` 求导。也可以分两步：先求 softmax 本身的导数，再乘 `∂L/∂p`。softmax 的输出有 K 个、输入有 K 个，它的导数是一个 K×K 的矩阵（叫**雅可比矩阵**，Jacobian）：

```
∂p_i/∂z_j = p_i ([i = j] − p_j)      即  J = diag(p) − p pᵀ
```

（i = j 时是 `p_i(1 − p_i)`，和 sigmoid 的导数形式一样；i ≠ j 时是 `−p_i p_j`。）而 `∂L/∂p_i = −y_i / p_i`。链式法则：

```
∂L/∂z_j = Σ_i ∂L/∂p_i · ∂p_i/∂z_j = Σ_i (−y_i/p_i) · p_i([i = j] − p_j) = −y_j + p_j Σ_i y_i = p_j − y_j
```

两种推导结果相同。注意，如果分两步计算，中间要先算 `−y/p`，p 很小时会出现巨大的数，数值很不稳定；把 softmax 和交叉熵**合在一起**求导，得到的 `p − y` 既简单又稳定。这就是为什么所有深度学习框架都提供"softmax + 交叉熵"合一的函数。

### 为什么分类不用均方误差

为什么不用 `(p_y − 1)²` 这样的均方误差（MSE）当分类损失？看梯度。如果对 sigmoid 的输出用 MSE（第 5 章的迷你神经元），`dL/dz = 2(p − y) · p(1 − p)`。当模型**非常自信地犯错**时（y = 1 而 p ≈ 0），`p(1 − p) ≈ 0`，梯度几乎消失——模型错得越离谱，越学不动！而交叉熵的梯度是 `p − y ≈ −1`，错得越离谱，纠正越有力。第 5 章自己动手第 4 题让你推导过这个结果。

## 6.13 横向对照：分类与相关任务的损失函数

| 损失 | 公式（单样本） | 特点 | 用在哪里 |
|---|---|---|---|
| 交叉熵 | `−log p_y` | 最大似然；梯度 `p − y`；对自信的错误惩罚重 | 几乎所有分类、语言模型、VLM |
| 二元交叉熵 | `−[y log p + (1−y) log(1−p)]` | 每个输出独立判断"是/否" | 多标签分类；像素级掩码（第 34 章 Q-Mask 的 CE 项） |
| 标签平滑交叉熵 | 目标改为 `(1−ε)y + ε/K` | 防止过度自信 | 图像分类、机器翻译 |
| Focal loss | `−(1 − p_y)^γ log p_y` | 降低"简单样本"的权重 | 类别极不均衡的检测（第 21 章） |
| 均方误差 | `\|p − y\|²` | 自信的错误梯度消失 | 回归（第 7 章）；不适合分类 |
| Dice 损失 | `1 − 2\|A∩B\| / (\|A\| + \|B\|)` | 只看前景的重合，不受大量背景影响 | 分割；Q-Mask（第 34 章），与第 2 章"墨迹只占 14.6%"的观察相关 |
| 对比损失（InfoNCE） | 一批里配对样本的交叉熵 | 把"找到配对"当作 B 类分类 | CLIP（第 20 章） |

它们大多数是交叉熵的变体。理解了交叉熵，就理解了一大半。

## 6.14 本章小结

- Σ 求和、Π 连乘，`ln Π = Σ ln`；期望是加权平均，方差衡量散开程度；样本均值的误差按 `1/√n` 缩小；
- 熵 `H(p) = −Σ p log p`：平均的意外程度，均匀分布最大（`ln K`）；
- softmax 把 logits 变成概率；平移不变（只有差有意义），温度控制尖锐程度；**减最大值**防溢出；需要对数概率时直接用 log-softmax；
- 交叉熵 `−log p_y`：每差 10 倍损失加 2.3；**初始损失应约为 ln K**（62 类：4.13）；
- `H(p, q) = H(p) + KL(p || q)`；KL ≥ 0、不对称；最小化交叉熵就是让模型分布接近真实分布，下界是数据的熵；
- 交叉熵 = 负对数似然；最大似然估计在简单情形下就是频率；
- 交叉熵对 logits 的梯度 = `p − y`；
- 困惑度 `e^H`：模型平均在多少个选项之间犹豫。

## 参考答案

1. `softmax(z + c) = e^c e^z / (e^c Σ e^z) = softmax(z)`，分子分母的 `e^c` 约掉；取 c = −max(z)，结果不变，但最大的指数是 `e^0 = 1`，不会溢出。
2. `ln 10 = 2.30`，训练前模型约等于均匀猜测，说明初始化正常；训练后 `e^{−0.05} ≈ 0.95`，模型平均给正确类约 95% 的概率（几何平均意义上），学得很好。
3. 交叉熵的下界是数据本身的熵：如果同样的输入可能对应不同的标签（模糊、标注不一致），模型无法让每个样本都得到概率 1。当标签几乎是输入的确定函数（如清晰的 OCR 数据）时，熵接近 0，损失可以接近 0。
4. 等价：最大化似然 ⟺ 最大化对数似然 ⟺ 最小化负对数似然的平均，而后者就是交叉熵损失。
5. `e⁰ = 1, 1, e^{ln 2} = 2`，总和 4，softmax = (0.25, 0.25, 0.5)。交叉熵 `−ln 0.5 = 0.693`。
6. `−(ln 0.5 + ln 0.25 + ln 0.5 + ln 1)/4 = (0.693 + 1.386 + 0.693 + 0)/4 = 0.693`。困惑度 `e^{0.693} = 2`。
7. `−(0.5 log₂ 0.5 + 2 × 0.25 log₂ 0.25) = 0.5 + 1 = 1.5` bit。
8. `√(0.8 × 0.2 / 400) = √0.0004 = 0.02`，即 2%。要降到 1%：`0.16 / n = 0.0001`，n = 1600。
9. 三个问题：(a) softmax 沿 `axis=0`（样本维）而不是 `axis=1`（类别维）；(b) 没有减最大值，可能溢出；(c) `p[labels]` 取的是整行而不是每个样本正确类那一个元素，应该是 `p[np.arange(N), labels]`。正确写法：`-log_softmax(logits)[np.arange(N), labels].mean()`。
10. `log_softmax(logits)[np.arange(T), targets].sum()`。
11. 加上 1e-3 之后，概率之和不再是 1（变成 1 + K × 0.001），不是一个合法的分布，算出的交叉熵会偏低。正确的平滑要重新归一化，例如 `q = (p_train + α/K) / (1 + α)`（演示第 7 部分），或 `(p_train + 1e-3) / (p_train + 1e-3).sum()`。
