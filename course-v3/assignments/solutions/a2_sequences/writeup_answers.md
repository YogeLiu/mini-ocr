## ctc_by_hand

路径用 0 表示 ∅、1 表示 a：

| 路径 | 折叠后 | 概率 |
|---|---|---|
| 000 | "" | 0.4·0.6·0.3 = 0.072 |
| 001 | a | 0.4·0.6·0.7 = 0.168 |
| 010 | a | 0.4·0.4·0.3 = 0.048 |
| 011 | a | 0.4·0.4·0.7 = 0.112 |
| 100 | a | 0.6·0.6·0.3 = 0.108 |
| 101 | aa | 0.6·0.6·0.7 = 0.252 |
| 110 | a | 0.6·0.4·0.3 = 0.072 |
| 111 | a | 0.6·0.4·0.7 = 0.168 |

P("") = 0.072，P("a") = 0.676，P("aa") = 0.252，合计 1。参考实现的 `ctc_loss` 给出 exp(−loss) = 0.676（"a"）和 0.252（"aa"），与表一致。

2. 贪心：每步取最大是 a、∅、a，即路径 101，折叠成 "aa"（这条路径的概率 0.252）。概率最大的标签是 "a"（0.676），由 6 条路径合起来。贪心只看单条最可能的路径，前缀束搜索把同一个标签的所有路径加起来，所以束搜索给出 "a"。

3. 标签 "a" 的扩展序列是 ∅ a ∅（位置 s = 0, 1, 2）：

| | s=0 (∅) | s=1 (a) | s=2 (∅) |
|---|---|---|---|
| t=1 | 0.4 | 0.6 | 0 |
| t=2 | 0.4·0.6 = 0.24 | (0.4 + 0.6)·0.4 = 0.40 | 0.6·0.6 = 0.36 |
| t=3 | 0.24·0.3 = 0.072 | (0.24 + 0.40)·0.7 = 0.448 | (0.40 + 0.36)·0.3 = 0.228 |

P("a") = α₃(1) + α₃(2) = 0.448 + 0.228 = 0.676。

## gpt_accounting

默认配置：V = 1024，d = 256，L = 4，h = 4，d_ff = 64·⌈(8/3)·256/64⌉ = 704，上下文 T = 256。

1. 参数量：

| 部分 | 计算 | 参数量 |
|---|---|---|
| 嵌入 tok | 1024 × 256 | 262,144 |
| 每层：两个 RMSNorm | 2 × 256 | 512 |
| 每层：qkv | 256 × 768 | 196,608 |
| 每层：o | 256 × 256 | 65,536 |
| 每层：SwiGLU（gate、up、down） | 3 × 256 × 704 | 540,672 |
| 每层合计 | | 803,328 |
| 4 层 | | 3,213,312 |
| 最后的 RMSNorm | | 256 |
| **总数** | | **3,475,712** |

输出层与嵌入共享同一个矩阵，不另算（参考实现的 `sum(p.numel() for p in model.parameters())` 给出 3,475,712，共享的参数只出现一次）。嵌入约占 7.5%。

2. 每个 token 的前向：
   - 权重部分：参与矩阵乘法的权重有 4 × (4·256² + 3·256·704) + 1024·256 = 3,473,408 个（输出层虽然与嵌入共享，但它要做一次矩阵乘法；嵌入是查表，不算），每个 2 次浮点运算，共 6,946,816；
   - 注意力部分：每层 QKᵀ 和 AV 各 2·T·d = 131,072，两项共 262,144，4 层 1,048,576；
   - 合计约 800 万（7,995,392）。训练约为前向的 3 倍（约 2400 万）：反向要对输入和权重各求一次梯度，每次的计算量与前向相当。
3. KV cache：每个 token 每层存 k、v 各 d 个数，共 2·L·d = 2048 个数。256 个 token：524,288 个数，float32 是 2,097,152 字节（2 MB），bfloat16 是 1 MB。参数在 float32 下是 13,902,848 字节（约 13.9 MB），所以这个小模型的缓存远小于参数。大模型、长上下文、大 batch 时，情况会反过来（第 17 章）。

## rope_relative

在一个二维平面里，把 RoPE 看成旋转矩阵 R(φ)。q 在位置 m 变成 R(mθ)q，k 在位置 n 变成 R(nθ)k，点积为

(R(mθ)q)ᵀ (R(nθ)k) = qᵀ R(mθ)ᵀ R(nθ) k = qᵀ R(−mθ) R(nθ) k = qᵀ R((n − m)θ) k。

旋转矩阵是正交的（Rᵀ = R⁻¹ = R(−φ)），两个旋转相乘等于角度相加，所以结果只取决于 n − m。每一对维度各自如此，整个点积是各平面的和，也只取决于 n − m。测试 `test_rope_relative` 用 m − n = 3 的三组位置验证了这一点。
