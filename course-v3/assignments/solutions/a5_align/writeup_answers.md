## kl_by_hand

1. KL(p ‖ q) = Σ p log(p/q) = 0.5 ln 2 + 0.3 ln 1.2 + 0.15 ln 0.6 + 0.05 ln 0.2 = **0.2442**。

2. log r = log q − log p：

| 样本 | p | log r | k1 | k2 | k3 |
|---|---|---|---|---|---|
| 0 | 0.5 | −0.6931 | 0.6931 | 0.2402 | 0.1931 |
| 1 | 0.3 | −0.1823 | 0.1823 | 0.0166 | 0.0157 |
| 2 | 0.15 | 0.5108 | **−0.5108** | 0.1305 | 0.1558 |
| 3 | 0.05 | 1.6094 | **−1.6094** | 1.2951 | 2.3906 |

p < q 的样本（2、3）k1 为负。

3.

| 估计量 | 期望 | 偏差 | 方差 |
|---|---|---|---|
| k1 | 0.2442 | 0 | 0.3592 |
| k2 | 0.2094 | −0.0348 | 0.0715 |
| k3 | 0.2442 | 0 | 0.2485 |

k1、k3 无偏（E_p[r] = Σ q = 1，所以 E[k3] = E[r − 1] + E[k1] = E[k1]）；k2 低估了 0.0348（约 14%）。k3 的方差比 k1 小（0.2485 < 0.3592）：k3 = k1 + (r − 1)，加上的 r − 1 期望为 0、和 −log r 负相关，起到控制变量的作用。k2 方差最小，但有偏；两个分布接近时 k2 ≈ k3（log r 小时 e^x − 1 − x ≈ x²/2）。

4. 差别很小。每步最大概率 0.99 时，采到的几乎总是那个 token，π 和 π_ref 在它上的概率都接近 1，log r 接近 0，三个估计量都 ≈ (log r)²/2 量级的小数；只有偶尔采到低概率 token 时才有差别。真正需要关心估计量的，是策略还有不少熵（训练早期、或温度较高）的时候。

## dpo_derivation

1. 目标 J(π) = Σ π(y)R(y) − β Σ π(y) log(π(y)/π_ref(y))，约束 Σ π = 1。对 π(y) 求导令其为 0：R(y) − β(log(π(y)/π_ref(y)) + 1) − λ = 0，得 π(y) ∝ π_ref(y) exp(R(y)/β)，归一化得 π* = π_ref·exp(R/β)/Z，Z = Σ π_ref(y) exp(R(y)/β)。另一种写法：J(π) = −β·KL(π ‖ π*) + β log Z，KL ≥ 0，等号在 π = π* 时成立。

2. 取对数：R(y) = β log(π*(y)/π_ref(y)) + β log Z。Bradley–Terry：P(y_w ≻ y_l) = σ(R(y_w) − R(y_l))，两个 β log Z 相减抵消（Z 只依赖提示，不依赖回答）。所以 P = σ(β log(π*(y_w)/π_ref(y_w)) − β log(π*(y_l)/π_ref(y_l)))，用待训练的 π 代替 π*，最大化似然就是 DPO 损失。意义：不需要算 Z（对所有可能回答求和，算不了），也不需要单独训练奖励模型、不需要在训练中采样。

3. 记 h = r_w − r_l，L = −log σ(h)。∂L/∂pol_w = −β·(1 − σ(h)) = −β·σ(−h) = −β·σ(r_l − r_w)。模型还把 rejected 排得比 chosen 高（h < 0）时系数接近 β；已经排对、margin 很大时接近 0。和 SFT 相比：SFT 对每条数据都用同样的力度推高 chosen，不管模型是否已经学会；DPO 自动把力气集中在"还没排对"的对上，已经排好的对几乎不再推——这也是它不会无限推高 chosen、但也不保证 chosen 概率上升的原因（似然位移）。

4. 零。pol 和 ref 都是 token 对数概率之和，共同前缀上的 token 在 chosen 和 rejected 里贡献完全相同的 log π − log π_ref，相减为 0；梯度也互相抵消。只有不同的那几个 token（substitute 换掉的颜色和形状，或 add 接上的那一段）以及它们之后的 token 提供信号。这正是"只差几个词"的偏好对数据效率高的原因：信号集中在幻觉的位置上。

## gc_by_hand

1. 梯度系数 β·σ(−β·margin)，β = 0.1：

| margin | −5 | 0 | 0.7 | 5 | 50 |
|---|---|---|---|---|---|
| 梯度系数 | 0.06225 | 0.05 | 0.04825 | 0.03775 | 0.00067 |

margin 从 −5 到 5 变化不大（β 小，σ 的输入只在 ±0.5 内）；要到 margin ≈ 50 才几乎停止。β 越小，DPO 越"耐心"，会把 margin 推得很大，离参考模型越远。

2. 均值 0.375，无偏标准差 √((3·0.625² + 5·0.375²)/7) = 0.5175。组内标准化：对的 (1 − 0.375)/0.5175 = **1.2076**，错的 −0.375/0.5175 = **−0.7246**。留一：对的 1 − 2/7 = **0.7143**，错的 0 − 3/7 = **−0.4286**。留一 = (G/(G − 1))·(r − 均值) = (8/7)(r − 0.375)，组内标准化则是 (r − 均值)/标准差：同一组内两者成比例，但比例因子随组变化——标准化让每组的优势尺度相同，留一保留了组间奖励差异的大小。全是 1：两种优势都是 0，这组没有梯度（白算了）。

3. Σ 掩码 = 4：

| 方式 | 长度 3 的回答每个 token | 长度 1 的回答的 token |
|---|---|---|
| sample | 1/6 | 1/2 |
| token | 1/4 | 1/4 |
| constant（max_len = 4） | 1/8 | 1/8 |

sample 方式下长回答的每个 token 权重更小：优势为正时长回答被推得更少，优势为负时长回答被罚得更少——错的回答越长越"便宜"，回答长度会被推长（DAPO、Dr. GRPO 指出的长度偏差）。token 和 constant 每个 token 权重相同，constant 还和批里实际的 token 数无关。
