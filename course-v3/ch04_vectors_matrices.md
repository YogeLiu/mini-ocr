# 第 4 章　向量、矩阵与形状

## 本章在全景图中的位置

神经网络里 90% 以上的计算是**矩阵乘法**。一个线性层是矩阵乘法；注意力（第 15 章）是两次矩阵乘法；VLM 的连接器（第 22 章）把视觉向量变成语言模型的"词"，还是矩阵乘法；第 2 章的区域平均缩放、第 20 章 CLIP 的相似度、第 28 章的 LoRA，全都是矩阵乘法。

本章从"向量是什么"讲起，到手算矩阵乘法、理解它的几何意义、数参数和运算量，最后用 `einsum` 统一地表达各种乘法。学完以后，你应该能看着任何一个模型的结构图，说出每一步的**形状**。

## 学习目标

1. 能计算向量的点积、长度、距离和余弦相似度，并解释它们的几何意义；
2. 能手算矩阵乘法，能根据形状判断两个矩阵能否相乘、结果是什么形状；
3. 能把线性层 `y = xW + b` 应用于一批数据，并数出一个多层网络的参数个数和运算量；
4. 能读写批量矩阵乘法和 `einsum` 表达式；
5. 能推导并实现"只用矩阵乘法的两两距离"，说出它为什么比广播省内存。

## 4.1 标量、向量、矩阵、张量

| 名字 | 维数 | 例子 | NumPy 形状 |
|---|---|---|---|
| 标量（scalar） | 0 | 一个数：学习率 0.001 | `()` |
| 向量（vector） | 1 | 一张拉平的 16×16 字符图：256 个数 | `(256,)` |
| 矩阵（matrix） | 2 | 一批 8 张拉平的图；一个线性层的权重 | `(8, 256)` |
| 张量（tensor） | 3 或更多 | 一批彩色图 | `(8, 3, 64, 64)` |

"张量"在深度学习里就是"多维数组"的意思，和第 1 章的 NumPy 数组是同一个东西。本书写数学公式时：

- 小写粗体或普通小写表示向量：`a`、`x`；
- 大写表示矩阵：`A`、`W`；
- `a_i` 表示向量的第 i 个分量，`A_ij` 或 `A[i, j]` 表示矩阵第 i 行第 j 列的元素；
- 和代码一样，**下标从 0 开始**。

## 4.2 向量

### 向量是一串数，也是一个箭头

向量 `a = (3, 4)` 可以看成平面上从原点指向点 (3, 4) 的箭头。256 维的向量没法画出来，但所有的运算规则和二维完全一样。所以理解向量运算的方法是：**在二维里画图，在高维里用公式**。

### 加法与数乘

```
a + b = (a₀ + b₀, a₁ + b₁, ...)       逐分量相加：两个箭头首尾相接
c · a = (c·a₀, c·a₁, ...)              每个分量乘以 c：箭头伸缩 c 倍
```

两张图相加就是逐像素相加；一张图乘以 0.5 就是变暗一半。第 2 章说"缩放是线性的"，指的就是 `缩放(a + b) = 缩放(a) + 缩放(b)`、`缩放(c·a) = c·缩放(a)`。

### 点积

两个向量的**点积**（dot product，也叫内积）是对应分量相乘再相加：

```
a · b = a₀b₀ + a₁b₁ + ... = Σ_i a_i b_i
```

**手算**：`(1, 2, 3) · (4, 5, 6) = 4 + 10 + 18 = 32`。

点积的结果是一个**数**。它衡量两个向量"有多同向"：

- 同向时最大，垂直时为 0，反向时为负；
- 对于"墨迹 = 1、背景 = 0"的字符图（第 2 章的反色），点积就是"两张图**都**有墨迹的像素有多少"。

### 长度与距离

向量的**长度**（也叫范数，norm，记作 `|a|` 或 `‖a‖`）由勾股定理推广而来：

```
|a| = √(a₀² + a₁² + ...) = √(a · a)
```

`|(3, 4)| = √(9 + 16) = 5`。两个向量之间的**距离**是它们差的长度：`|a − b|`。第 2 章的模板分类器比较的就是距离的平方 `|a − b|²`。

### 余弦相似度

点积有一个缺点：它受向量长度影响。一个笔画粗的 "A" 墨迹多、长度大，和任何图的点积都偏大。要只比较**方向**，就除以两者的长度：

```
cos θ = (a · b) / (|a| |b|)
```

结果在 −1 到 1 之间，`θ` 是两个向量的夹角。这叫**余弦相似度**（cosine similarity）。

**这个公式从哪里来？** 在二维里，设 `a` 和 `b` 的夹角为 θ。由余弦定理，三角形三边满足 `|a − b|² = |a|² + |b|² − 2|a||b| cos θ`。另一方面，把 `|a − b|²` 按定义展开：

```
|a − b|² = (a − b)·(a − b) = a·a − 2a·b + b·b = |a|² − 2a·b + |b|²
```

两式对比，`a · b = |a||b| cos θ`。这个关系在任何维数下都成立，高维里我们就**用它来定义夹角**。

演示第 1 部分（`python -m labs.ch04.linalg_tour`）：取两张 "A" 和一张 "B"，归一化到 16×16、反色后拉平成 256 维向量：

```
归一化到 16×16 的字符图拉平成向量，形状 (256,)
长度 |A1| = 10.07   |A2| = 7.21   |B| = 8.84
点积 A1·A2 = 67.01   A1·B = 53.98
距离 |A1-A2| = 4.41   |A1-B| = 8.47
余弦 cos(A1,A2) = 0.923   cos(A1,B) = 0.606
```

- 两张 "A" 的长度差别很大（10.07 和 7.21）：一张笔画粗、一张笔画细（第 2 章渲染时 30% 概率加粗）；
- 但它们的余弦是 0.923，非常接近 1——方向几乎一样；"A" 和 "B" 的余弦只有 0.606；
- 距离也能区分它们（4.41 vs 8.47），但距离同时受粗细影响。

### 练习 4.2：余弦相似度矩阵

我们常要算**两组**向量之间的所有余弦。先把每个向量除以自己的长度，变成长度为 1 的**单位向量**，这时点积就等于余弦；再把所有点积用一次矩阵乘法算出来（4.4 节）：

```python
def cosine_similarity(A, B, eps=1e-12):
    A = np.asarray(A, dtype=np.float64)
    B = np.asarray(B, dtype=np.float64)
    An = A / (np.linalg.norm(A, axis=1, keepdims=True) + eps)   # (N, D) / (N, 1)：每一行除以自己的长度
    Bn = B / (np.linalg.norm(B, axis=1, keepdims=True) + eps)
    return An @ Bn.T                                            # (N, D) @ (D, M) = (N, M)
```

`np.linalg.norm(A, axis=1, keepdims=True)` 求每一行的长度，形状 `(N, 1)`，广播除法让每一行除以它自己的长度。`eps` 是一个很小的数，防止全 0 的向量除以 0 得到 `nan`（测试 `test_cosine_similarity` 专门检查了零向量）。

## 4.3 矩阵

### 矩阵是一张数表，也是一批向量

形状 `(n, m)` 的矩阵有 n 行、m 列。它可以看成：

- **n 个行向量**，每个长度 m：比如 8 张图，每张 256 维，就是 `(8, 256)` 的矩阵；
- **m 个列向量**，每个长度 n。

### 转置

**转置**（transpose）把行和列互换：`Aᵀ[i, j] = A[j, i]`，形状 `(n, m)` 变成 `(m, n)`。NumPy 里是 `A.T`。第 1 章"深入一步"讲过，转置只是交换步长，不复制数据。

## 4.4 矩阵乘法

### 定义

矩阵 `A`（形状 `(n, k)`）乘以矩阵 `B`（形状 `(k, m)`），得到 `C = AB`（形状 `(n, m)`）：

```
C[i, j] = Σ_t A[i, t] · B[t, j] = （A 的第 i 行）·（B 的第 j 列）
```

**C 的每个元素，是 A 的一行和 B 的一列的点积。**

### 手算

```
A = [[1, 2],        B = [[ 7,  8,  9],
     [3, 4],             [10, 11, 12]]
     [5, 6]]
```

A 是 `(3, 2)`，B 是 `(2, 3)`，内维都是 2，可以相乘，结果 `(3, 3)`。

```
C[0,0] = (1, 2)·(7, 10)  = 1·7 + 2·10  = 27
C[0,1] = (1, 2)·(8, 11)  = 8 + 22      = 30
C[0,2] = (1, 2)·(9, 12)  = 9 + 24      = 33
C[1,0] = (3, 4)·(7, 10)  = 21 + 40     = 61
C[1,1] = (3, 4)·(8, 11)  = 24 + 44     = 68
...
```

**请在纸上把 9 个元素全部算完**，再和演示第 3 部分对照：

```
A (3,2) @ B (2,3) =
 [[ 27  30  33]
 [ 61  68  75]
 [ 95 106 117]]
```

### 形状规则

```
(n, k) @ (k, m) = (n, m)
     └──┘
   内维必须相等，相乘后消失
```

记住这条规则，你就能在不看任何数字的情况下检查一整个模型的形状是否正确。NumPy 里矩阵乘法写作 `A @ B`（或 `np.matmul(A, B)`、`np.dot(A, B)`）。注意 `A * B` 是**逐元素**相乘，完全是另一回事。

### 练习 4.1：用循环实现

```python
def matmul_loops(A, B):
    n, k = A.shape
    k2, m = B.shape
    if k != k2:
        raise ValueError(f"内维不一致：A 是 {A.shape}，B 是 {B.shape}")
    C = np.zeros((n, m), dtype=np.result_type(A, B, np.float64))
    for i in range(n):              # 对 C 的每一行
        for j in range(m):          # 对 C 的每一列
            s = 0.0
            for t in range(k):      # 第 i 行与第 j 列的点积
                s += A[i, t] * B[t, j]
            C[i, j] = s
    return C
```

三重循环，总共 `n × m × k` 次乘法和加法。`np.result_type(A, B, np.float64)` 取能容纳 A、B 和 float64 的类型，保证结果是小数。

```
64×64 @ 64×64：循环 29.7 ms，NumPy 4.0 µs，快 7496 倍，最大差 8.9e-15
```

NumPy 快了七千多倍。它调用的是高度优化的线性代数库（BLAS），利用了 CPU 的缓存、向量指令和多核。**永远不要在实际代码里自己写矩阵乘法的循环**——这个练习只是为了让你确切地知道 `@` 在算什么。

### 矩阵乘法的性质

| 性质 | 是否成立 | 说明 |
|---|---|---|
| 交换律 `AB = BA` | **不成立** | 形状可能都对不上：`(3,2)@(2,3)` 是 `(3,3)`，`(2,3)@(3,2)` 是 `(2,2)` |
| 结合律 `(AB)C = A(BC)` | 成立 | 但两种算法的**运算量**可能差很多（4.7 节） |
| 分配律 `A(B + C) = AB + AC` | 成立 | |
| 转置 `(AB)ᵀ = BᵀAᵀ` | 成立 | 注意顺序反过来了 |
| 单位矩阵 `IA = AI = A` | 成立 | `I` 是对角线为 1、其余为 0 的方阵，`np.eye(n)` |

**验证转置规则**：`(AB)ᵀ[i, j] = (AB)[j, i] = Σ_t A[j, t] B[t, i] = Σ_t Bᵀ[i, t] Aᵀ[t, j] = (BᵀAᵀ)[i, j]`。

### 矩阵乘向量

向量可以看成只有一列的矩阵。`(n, k)` 的矩阵乘 `(k,)` 的向量得到 `(n,)` 的向量：每个分量是矩阵的一行与向量的点积。第 2 章的区域平均缩放就是这样（演示第 6 部分最后）：

```
第 2 章的区域平均缩放也是矩阵：_area_matrix(6, 4) =
 [[0.667 0.333 0.    0.    0.    0.   ]
 [0.    0.333 0.667 0.    0.    0.   ]
 [0.    0.    0.    0.667 0.333 0.   ]
 [0.    0.    0.    0.    0.333 0.667]]
M @ [10,20,30,40,50,60] = [13.33 26.67 43.33 56.67]
```

和第 2 章手算的结果完全一样。

## 4.5 矩阵是一种变换

`y = Mx` 把向量 `x` 变成向量 `y`。从几何上看，矩阵就是一种**线性变换**：它能缩放、旋转、翻转、拉伸空间，但直线还是直线、原点还是原点。

演示第 6 部分对一个矩形的四个角做变换（每个角是一个 `(x, y)`，四个角排成 `(4, 2)` 的矩阵，所以写成 `box @ M.T`——每一行乘以 `Mᵀ`，等价于对每个点做 `M @ 点`）：

```
缩放矩阵 diag(0.5, 2):
 [[0.5 0. ]
 [0.  2. ]]
四个角变成
 [[ 5. 20.]
 [15. 20.]
 [15. 40.]
 [ 5. 40.]]
```

对角矩阵 `diag(0.5, 2)` 把 x 缩小一半、y 放大一倍。第 2 章 letterbox 后换算框坐标的 `x' = x × scale` 就是一个缩放变换（加上 pad 是一个平移，平移不是线性变换，所以要单独加）。

**旋转矩阵**：

```
R(θ) = [[cos θ, −sin θ],
        [sin θ,  cos θ]]
```

为什么是这个样子？把 `(1, 0)` 逆时针转 θ，得到 `(cos θ, sin θ)`，这是 R 的第一列；把 `(0, 1)` 转 θ，得到 `(−sin θ, cos θ)`，这是第二列。**一个矩阵的每一列，就是它把每个坐标轴方向变成了什么。** 理解了这一句，就理解了矩阵作为变换的全部。

```
绕中心旋转 30°：
 [[13.84  5.67]
 [31.16 15.67]
 [26.16 24.33]
 [ 8.84 14.33]]
旋转矩阵是正交的：R.T @ R =
 [[1. 0.]
 [0. 1.]]
```

绕中心旋转：先减去中心、旋转、再加回中心。`RᵀR = I` 说明旋转矩阵是**正交矩阵**：它不改变长度和夹角，`Rᵀ` 就是它的逆（转回去）。注意图像坐标的 y 轴向下，所以数学上的"逆时针"在图上看起来是顺时针。第 12 章的数据增强会用到小角度的旋转。

## 4.6 线性层

### 一个样本

神经网络最基本的部件是**线性层**（linear layer，也叫全连接层、dense layer）：

```
y = x W + b
x: (d_in,)   W: (d_in, d_out)   b: (d_out,)   y: (d_out,)
```

`W` 叫**权重**（weight），`b` 叫**偏置**（bias），它们就是第 0 章说的"旋钮"。输出的第 j 个分量 `y_j = Σ_i x_i W[i, j] + b_j`，是输入的一个**加权和**。

**用字符识别来理解**：输入 `x` 是一张 32×32 的图，拉平成 1024 维；输出 `y` 是 62 维，每一维是一个字符的"分数"。`W` 的第 j 列（1024 个数）可以看成第 j 个字符的"模板"：`y_j = x · W[:, j] + b_j`，图和模板越"同向"，分数越高。这和第 2 章的模板分类器思路一样，区别在于：**模板不再是求平均得到的，而是训练出来的**（第 7、10 章）。

### 一批样本

把 B 个样本排成 `(B, d_in)` 的矩阵 X，一次矩阵乘法算出所有样本的输出：

```
Y = X W + b
(B, d_in) @ (d_in, d_out) = (B, d_out)，再加上 (d_out,) 的 b（广播到每一行）
```

演示第 4 部分：

```
x (8, 1024) @ W (1024, 62) + b (62,) -> (8, 62)
第 0 张图得分最高的类: 8   每张图的预测: [ 8 59 34 56 26 26 34 34]
预告第 22 章：2 张图 × 196 个视觉向量 (2,196,768) @ 投影矩阵 (768,1024) -> (2, 196, 1024)
```

权重是随机的，所以预测也是随机的——还没训练。第二行说明 `@` 对更多维的输入也适用：**只对最后一维做矩阵乘法，前面的维度都保留**。VLM 的投影层就是这样：每个视觉向量（768 维）独立地乘以同一个投影矩阵，变成语言模型的维度（1024 维）。我们的 `linear` 函数一行就支持任意多的前置维度：

```python
def linear(x, W, b):
    return x @ W + b          # x (..., d_in) @ W (d_in, d_out) + b (d_out,) -> (..., d_out)
```

> **关于约定**：PyTorch 的 `nn.Linear` 把权重存成 `(d_out, d_in)`，计算 `x @ W.T + b`（第 9 章）。数学书里常写 `y = Wx + b`，`W` 是 `(d_out, d_in)`、`x` 是列向量。三种写法本质相同，只是转置的位置不同。**读别人的代码时，先确认权重的形状约定。**

### 为什么光有线性层不够

两个线性层叠起来：`(xW₁ + b₁)W₂ + b₂ = x(W₁W₂) + (b₁W₂ + b₂)`，还是一个线性层（权重 `W₁W₂`、偏置 `b₁W₂ + b₂`）。所以无论叠多少层线性层，表达能力都和一层一样。神经网络在线性层之间插入**非线性函数**（激活函数，第 7、10 章），才能表达复杂的规律。

## 4.7 数参数、数运算量

### 参数个数（练习 4.4）

一个 `d_in → d_out` 的线性层有 `d_in × d_out` 个权重和 `d_out` 个偏置。一个多层网络的参数就是各层之和：

```python
def mlp_param_count(sizes):
    return sum(a * b + b for a, b in zip(sizes[:-1], sizes[1:]))
```

`zip(sizes[:-1], sizes[1:])` 把相邻的两层配对：`[1024, 256, 62]` 配成 `(1024, 256)` 和 `(256, 62)`。

**手算** `[1024, 256, 62]`：`1024 × 256 + 256 = 262,400`；`256 × 62 + 62 = 15,934`；合计 278,334。

```
MLP [1024, 62]:    63,550 个参数 = 0.25 MB（float32）
MLP [1024, 256, 62]:   278,334 个参数 = 1.11 MB（float32）
MLP [1024, 512, 512, 62]:   819,262 个参数 = 3.28 MB（float32）
```

一个 0.8B（8 亿）参数的 VLM 用 float32 存需要 3.2 GB，用 bf16（2 字节）需要 1.6 GB（第 0 章自测题 7）。训练时还要存梯度和优化器状态，通常是参数的好几倍（第 28 章）。**先数参数，再估显存，是训练任何模型之前的第一步。**

### 运算量

`(n, k) @ (k, m)` 有 `n × m` 个输出元素，每个需要 k 次乘法和 k − 1 次加法，约 `2nkm` 次浮点运算（FLOP）：

```
一批 256 张图过第一层 (1024→256)：134 M 次浮点运算
```

`2 × 256 × 1024 × 256 ≈ 1.34 × 10⁸`。RTX 5080 每秒能做几十万亿次（几十 TFLOPS）浮点运算，这一层一微秒级别就算完了。第 18、28 章会用"运算量 ÷ 硬件速度"估计训练时间，再和实测比较。

**结合律与运算量**：计算 `ABx`，其中 A、B 是 `(1000, 1000)`、x 是 `(1000,)`。`(AB)x` 先算矩阵乘矩阵（2×10⁹ 次），再乘向量；`A(Bx)` 先算矩阵乘向量（2×10⁶ 次），再乘向量（2×10⁶ 次）。结果完全相同，运算量差了 500 倍。第 28 章的 LoRA 正是利用这一点：`x(W + BA)` 写成 `xW + (xB)A`，永远不需要把 `BA` 这个大矩阵乘出来。

## 4.8 批量矩阵乘法与 einsum

### 批量矩阵乘法

`@` 作用于三维以上的数组时，**最后两维做矩阵乘法，前面的维度当作"批"**：

```
(B, n, k) @ (B, k, m) = (B, n, m)        B 组矩阵各自相乘
```

第 15 章的注意力里，每个样本（以及每个"头"）都有自己的 Q 和 K 矩阵，要算 `Q Kᵀ`：

```
Q (4,10,16) @ Kᵀ (4,16,12) -> (4, 10, 12)   einsum 'bqd,bkd->bqk' -> (4, 10, 12)  相同: True
```

`K.transpose(0, 2, 1)` 只交换最后两维（第 0 维是批，不动）。

### einsum

**爱因斯坦求和约定**（einsum）用字母给每一维起名，一个表达式说清楚"哪些维相乘、哪些维求和"：

规则：
1. 输入中每个数组的每一维用一个字母标记；
2. **同一个字母出现在多个输入中**：这些维度对齐（逐元素相乘）；
3. **某个字母没有出现在输出中**：沿这一维求和；
4. 输出的字母顺序决定结果的维度顺序。

| 表达式 | 含义 | 等价写法 |
|---|---|---|
| `"i,i->"` | 点积 | `a @ b` |
| `"i,j->ij"` | 外积 | `a[:, None] * b[None, :]` |
| `"ij,jk->ik"` | 矩阵乘法 | `A @ B` |
| `"ij->ji"` | 转置 | `A.T` |
| `"ii->"` | 迹（对角线之和） | `np.trace(A)` |
| `"bqd,bkd->bqk"` | 批量的 `Q Kᵀ` | `Q @ K.transpose(0, 2, 1)` |
| `"ih,hwc,jw->ijc"` | 对彩色图每个通道做 `Ay @ img @ Axᵀ` | 第 2 章的 `resize_area` |

**读 `"bqd,bkd->bqk"`**：`b` 出现在两个输入和输出中——批维，对齐保留；`q` 只在 Q 中、`k` 只在 K 中，都在输出中——保留；`d` 在两个输入中都有、但不在输出中——**对齐相乘再求和**。所以 `out[b, q, k] = Σ_d Q[b, q, d] · K[b, k, d]`，正是每对 (q, k) 的点积。

einsum 的好处是**意图明确**：维度的名字本身就是文档。缺点是写错一个字母不会报错（只要形状对得上）。用它时，同样要写出每一维的含义。

## 4.9 只用矩阵乘法的两两距离（练习 4.3）

第 1 章的 `pairwise_sq_dists` 用广播，需要一个 `(N, M, D)` 的中间数组。利用 4.2 节推导余弦公式时的展开式：

```
|a − b|² = |a|² − 2 a·b + |b|²
```

对所有 (i, j) 同时写出来：

```
D[i, j] = |A[i]|² − 2 (A Bᵀ)[i, j] + |B[j]|²
           (N, 1)      (N, M)          (1, M)       → 广播成 (N, M)
```

中间最大的数组只有 `(N, M)`，`A Bᵀ` 交给高度优化的矩阵乘法：

```python
def pairwise_sq_dists_mm(A, B):
    A = np.asarray(A, dtype=np.float64)
    B = np.asarray(B, dtype=np.float64)
    aa = (A ** 2).sum(1, keepdims=True)          # (N, 1)
    bb = (B ** 2).sum(1, keepdims=True).T        # (1, M)
    return np.maximum(aa - 2 * A @ B.T + bb, 0.0)
```

演示第 8 部分（N = 2000，M = 500，D = 256）：

```
广播：中间数组 2.05 GB，用时 1414 ms
矩阵乘法：中间数组 8 MB，用时 8 ms；最大差 2.8e-13
```

快了 170 多倍，内存少了 250 倍。

**为什么要 `np.maximum(…, 0)`？** 数学上距离平方不可能是负数，但当 `a` 和 `b` 非常接近时，`|a|² + |b|²` 和 `2a·b` 是两个几乎相等的大数，相减会损失精度（叫**灾难性抵消**，catastrophic cancellation，第 11 章），可能得到 `−1e-14` 这样的结果。如果后面要开平方，负数会变成 `nan`。截到 0 是一个便宜而安全的处理。

## 4.13 深入一步

### 矩阵乘法的四种看法

同一个 `C = AB`，可以从四个角度理解，每种在后面都有用：

1. **点积视角**：`C[i, j]` = A 的第 i 行 · B 的第 j 列。用于手算；对应注意力分数"每个 query 和每个 key 的相似度"；
2. **列视角**：C 的第 j 列 = A 乘以 B 的第 j 列 = **A 的各列按 `B[:, j]` 加权求和**。说明 C 的每一列都是 A 的列的组合；
3. **行视角**：C 的第 i 行 = A 的第 i 行乘以 B = **B 的各行按 `A[i, :]` 加权求和**。线性层里，输出就是权重矩阵各行的加权组合；注意力的输出也是 V 的各行按注意力权重的加权和（第 15 章）；
4. **外积之和视角**：`C = Σ_t A[:, t] ⊗ B[t, :]`，k 个"列 × 行"的外积（每个都是一个 `(n, m)` 的矩阵）相加。如果 k 很小（比如 r = 8），C 就是 8 个简单矩阵之和，它的"秩"至多是 8——这正是 LoRA 中"低秩"的含义。

**验证第 4 种**：`(Σ_t A[:, t] ⊗ B[t, :])[i, j] = Σ_t A[i, t] B[t, j]`，和定义一致。

### 为什么 NumPy 的矩阵乘法那么快

循环版本慢，不只是因为 Python 慢。即使用 C 语言写三重循环，也比优化过的 BLAS 慢几十倍。原因是**内存访问**：CPU 做一次乘法只需要不到一纳秒，但从内存读一个数可能要一百纳秒。优化的实现把矩阵切成小块（block/tile），让每一小块在 CPU 缓存里反复使用；再用 SIMD 指令一次算 8 或 16 个乘法；再用多个核并行。GPU 上的思路一样，只是规模更大。运算量 `2nkm`，数据量只有 `nk + km + nm`：n 越大，"每读一个数能做的运算"越多，硬件越能发挥实力。这就是演示里 64×64 已经快 7000 倍、而选做题 7 中大矩阵的效率会更高的原因。第 18 章会用这个思路解释"为什么批越大，每个样本越便宜"。

### 余弦相似度与欧氏距离的关系

对**单位向量**（长度为 1）：`|a − b|² = |a|² + |b|² − 2a·b = 2 − 2 cos θ`。所以对单位向量，"余弦越大"和"距离越小"是**完全等价**的排序。这就是为什么 CLIP 先把向量归一化：归一化之后，点积、余弦、距离给出同样的"谁和谁最像"，可以随便选一种最方便计算的。

## 4.14 横向对照：怎样衡量两个向量"像不像"

| 度量 | 公式 | 受长度影响 | 范围 | 用在哪里 |
|---|---|---|---|---|
| 点积 | `a · b` | 是 | 任意实数 | 注意力分数（第 15 章）；线性层 |
| 余弦相似度 | `a·b / (\|a\|\|b\|)` | 否 | [−1, 1] | CLIP/SigLIP 的图文匹配（第 20 章）；检索 |
| 欧氏距离 | `\|a − b\|` | 是 | ≥ 0 | 模板分类器（第 2 章）；聚类 |
| 距离平方 | `\|a − b\|²` | 是 | ≥ 0 | 均方误差损失（第 7 章）；省掉开方 |
| 曼哈顿距离 | `Σ\|a_i − b_i\|` | 是 | ≥ 0 | 对少数大的差异不那么敏感 |

选择的依据是：**哪些差异你认为不重要**。如果笔画粗细不重要，用余弦；如果整体亮度也有意义，用距离。和第 2 章的结论一样，度量的选择就是一种"预处理"，它决定了什么信息被保留、什么被忽略。

## 4.15 本章小结

- 向量：加法、数乘、点积、长度、距离；`a·b = |a||b|cos θ`；余弦相似度只看方向；
- 矩阵乘法：`C[i,j]` = 行 · 列；`(n,k) @ (k,m) = (n,m)`；不满足交换律，满足结合律，`(AB)ᵀ = BᵀAᵀ`；
- 矩阵是线性变换，每一列是一个坐标轴的去向；旋转矩阵是正交的；
- 线性层 `y = xW + b`，对一批数据一次算完；`@` 只作用于最后一维（批量时最后两维）；多层线性层叠加仍是线性的，需要激活函数；
- 参数：每层 `d_in × d_out + d_out`；运算量：`2nkm`；结合律的顺序影响运算量；
- einsum 用字母说清楚每一维：共有的字母对齐，输出中没有的字母求和；
- 两两距离用 `|a|² − 2a·b + |b|²` 只需矩阵乘法，比广播省内存、快得多，要防灾难性抵消。
