## ch00_intro

主审核记录：完整报告已读并核对最小反例：采纳CH00-01字符CER边界碰撞、CH00-02扫描规则层次不清、CH00-03声明分组作用域丢失。主审核独立复算bf/rm反例，mathtext差异分别0.53846和0.89189；未声称完整TeX复现。导论建立的任务定义、三种面板和冻结/升级协议是后续章节的重要输入。

### 主线与约定

本章先定义图片到 LaTeX 的忠实转写任务，再以 16 对手写样例区分写法差异和真实识别错误。规范化管线为分词、逐 token 规则、语法树解析、规范序列化；它忽略部分间距和尺寸差异，但不合并 `a+b` 与 `b+a`。解析失败仍返回 token 规则处理后的序列以便计算距离。

EM 默认指规范化完全匹配。CER 默认使用规范化后的字符，语料级聚合为总编辑距离除以总参考长度；CER_token 使用手写 LaTeX 分词，不等于 BPE。可编译率以 mathtext 可解析率近似；渲染一致率只在双方可解析时计算，同时报告覆盖样本数、渲染器、字体、dpi 和容忍度。OCR 主面板、文本后纠错面板及第四部分的 OCR 精简面板具有不同指标范围。

验证集用于选型、看错例和开发协议；测试集只在选型冻结后按预登记候选各评一次，不反哺开发，错例到最终报告冻结后解封。相同规范键整组划分，但这不保证覆盖所有等价写法；需要近重复和来源信息补充。新评测规则必须升级版本，所有候选同口径重算。

## ch01_tensors

主审核记录：完整报告已核对。核心广播、stride、view与拆头推导未确认P1/P2；两条P3收窄绝对化建议合理，需保持同设备和先clone的实践建议。输出为轴语义、内存布局与单位计数接口，供后续attention、cache和图像章节使用。

### 主线与约定

本章建立 shape、dtype、device 的基础词汇。广播按右对齐、左补 1、逐维相等或含 1 判定，强调长度匹配不保证语义维度正确。两两平方距离的直接广播需要 NMD 中间张量，矩阵展开减少中间量但有消减误差，clamp 只能防负数，不能恢复精度。

矩阵乘只在矩阵维上收缩，批量维广播。以 storage_offset 加下标乘 stride 描述寻址；view 需要目标形状与 stride 兼容，非连续本身并不禁止 view；reshape 必要时复制。多头先拆特征维再换轴，不能用形状相同作为内容正确的证据。einops 用显式维名表达同样的操作。

后续全书的张量词汇为 B 批大小、T 序列长、V 词表大小、D 隐藏维、C 通道、H/W 像素高宽。one-hot 乘权重等于索引查表；语言模型 logits 为 BTV。图片常见 HWC uint8，卷积批量采用 BCHW float；逻辑轴顺序与实际内存布局必须区分。

## ch02_backprop

主审核记录：完整报告已读，链式法则、逆拓扑累加和有限差分主线未确认核心推导错误。采纳CH02-01为跨网络推广时的条件缺失：当前固定输入的第一层教学例仍成立。CH02-02为可重复反向的例外澄清；CH02-03仅属助手输入鲁棒性建议，等长前提已写明，不将其升级成正文正常调用或历史梯度结果错误。记录每样本与每token平均、共享梯度与激活保存的后续接口。

### 主线与约定

本章把参数敏感度解释为局部导数，计算图表示前向依赖。单链导数相乘，复用变量的多路贡献相加；逆拓扑顺序确保节点先收到所有下游贡献，再向输入传播。反向模式适合标量输出、多参数输入，而前向模式适合输入少、输出多。

Value 保存 data、grad、父节点和反向闭包；加乘幂、tanh、ReLU 提供局部规则。重复反向时清除中间节点草稿梯度，叶子梯度累积；训练每步重建前向图，参数更新前应清零。梯度累积的样本平均必须按小批样本数占比加权。

有限差分用中心差分，光滑点截断误差 O(h²)，舍入项约 epsilon/h，float64 步长 1e-5 左右；折点附近和接近零的梯度须另判。相对误差应报告定义并检查最大值。PyTorch 区分 requires_grad、叶子 grad、retain_grad、retain_graph、no_grad 与 detach；None 梯度和零梯度在优化器行为上不同。最后用 hinge loss 和手写 MLP 训练 moons，并以 PyTorch 对拍。

## ch03_softmax_ce

主审核记录：完整报告已读，采纳CH03-01：恒定频率预测达到H(频率)不意味着所有达到该标量loss的模型都忽略输入，两样本反例严格成立。保留lnV诊断、小logits前提、p-y仅对logits有界、有效token归约与teacher forcing的接口区分。where对非有限上游梯度的边界仅记为外推风险，不指控本章已承诺修复所有反向NaN。

### 主线与约定

本章从 logits 到 softmax 概率、负对数似然，再推导交叉熵的 `p-y` 梯度。softmax 只依赖分数差；稳定实现先减最大值，直接求 log-softmax；低精度输入的中间结果提升到 fp32。交叉熵是条件概率模型的平均 NLL；总体交叉熵分解为条件熵与 KL，文中已区分总体下界、有限验证估计和训练记忆。

序列张量约定是 logits `(B,T,V)`，类别在最后一维；手写 CE 按最后维 gather，而 PyTorch CE 类别在第1维。`ignore_index=-100`；默认均值分母为有效 token 数。按 token 均值和先逐序列均值再平均是不同权重。全忽略 batch 的 mean 是 NaN。分类器使用补一列1的 X 合并偏置，`dW=Xᵀ(P-Y)/N+2reg W`；中心差分用于梯度检查，默认 float64、h≈1e-5。初始化近均匀预测时 loss≈ln C，困惑度 exp(loss)。末尾把序列 CE 连接到 OCR teacher forcing，并明确 token loss 与全序列 EM 不等价。

## ch04_training

主审核记录：完整报告已读。采纳CH04-01：原子替换提供可见性保证，不能无fsync等条件承诺断电持久性；CH04-02为无害clone的解释错误，不指控现有检查点代码失效。记录0基调度、无动量SGD等价条件、Adam参数状态、按何种单位累积、RNG及数据采样状态。AdamW、初始化和可复现性的已给限定不重复列错。

### 主线与约定

章节用螺旋 MLP 将前向、清梯度、反向、全局裁剪、设置当前步学习率、更新及记录串成循环。SGD 使用 `v=μv+g;θ-=ηv`，并区分把学习率放进速度的另一种约定。二次正定例子的稳定界是 `0<η<2/λmax`，heavy ball 对应 `η<2(1+μ)/λmax`，没有把这些作为所有非凸网络的全局定理。

Adam 维护一阶/二阶 EMA，按参数分别计步，None 梯度跳过更新；有条件地推导偏差修正、首步近似sign及小梯度受epsilon影响。AdamW把衰减放在Adam更新前。无动量SGD的L2与本章按学习率缩放的衰减等价，Adam则不等价。调度使用0基步数，warmup含s+1，cosine在total_steps以后固定min_lr。裁剪返回裁剪前全局范数。初始化明确区分二阶矩与方差、Xavier论文公式与本章等宽特例。

Dropout采用inverted dropout，train/eval与梯度开关分开。检查点保存模型、优化器配置与状态、已完成步数和全局/显式Generator状态；数据使用有放回随机采样，因此不另存DataLoader游标。逐位续训承诺限定完全相同运算序列；真实DataLoader不展开。小批量过拟合仅检查可学习性，正文已展示随机错标签也能背下来，不能据此证明标签正确。

## ch10_rope

主审核记录：完整报告已读。RoPE相对点积、配对、PI和base公式未确认错误；CH10-01采纳为按token报告缺少受影响目标分桶的P3建议，64.2%短公式不等于其余目标权重可忽略，统计为24940/119750约20.83%。不据此声称模型已通过强外推，也不把已主动说明的off-by-one与非单调远程行为重复列错。

### 主线与约定

从无位置无mask置换等变引出位置；明确causal mask含隐式位置，单层NoPE最后位置对历史排列不敏感，但多层不能据此类推。绝对位置加法经Q/K投影产生四项，原始sin/cos自身点积的相对性质不普遍保留。

RoPE二维定义R(tθ)x；共同平移点积为qᵀR((n−m)θ)k，固定q/k才只依赖相对距离。高维每个二维平面使用θ_i=base^(−2i/dh)。本书采用前后半配对(i,i+dh/2)，实现`x*cos+rotate_half(x)*sin`、角表两半cat；相邻配对与之经固定通道置换等价，不能直接替换已有权重。对拍应有独立公式，单测相对不变抓不到约定混用。

标准RoPE只转q/k，放在拆头及Q/K norm以后、cache写入以前。若也转v，输出会整体随绝对平移旋转；556行明确提示可加输出逆旋转恢复相对形式，所以“只转q/k”是本文设计而非所有架构的不可能性定理。角度及三角函数fp32，应用时转激活dtype。cache新位置必须接历史长度。

base增大不改最快频率1，慢频率降低；PI用位置除s，NTK-aware静态base'=base*s^(dh/(dh−2))，dh>2。数学定义可延长不保证模型质量；实际训练角度、分辨率、重训练均有条件。远程衰减解释已承认非单调、内容依赖、通用范数界不衰减。LaTeX三模型实验单层600步单种子，rope与none几乎同分，learned落后不可当普遍架构结论。

## ch24_rl_basics

主审核记录：完整报告及24.8原文已读。采纳CH24-01：不可导评分不能排他推出只能在线RL，评分可用于候选筛选、偏好构造或蒸馏监督。策略梯度、基线、KL估计值/反向梯度区别和PPO裁剪推导未确认算错。记录序列logprob求和、含自己基线偏差及采样分布条件，等待全部章节完成后与DPO/GRPO比较学习路径。

### 主线与约定

toy GPT固定8token、首尾$奖励诱发全$输出，未证明KL能阻止投机。项目OCR面板不适用于无标准答案符号任务；test只一次。TRL对应明确版本、token/sequence ratio与grpo/dapo不同聚合路径。

## c_quantization

主审核记录：完整报告已读，线性量化误差界、GPTQ补偿及AWQ缩放公式未新增确认P1/P2。代码已处理全零scale，不报遗漏；int4教学误差不等NF4、浮点存整数不省空间、校准小矩阵不代表真实模型均已声明。4bit合并风险需与第20章高精度合并再量化的路径区分，保留条件澄清。
