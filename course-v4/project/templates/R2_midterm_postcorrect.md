## 3. 每种方法的配置

| 方法 | 必须写清的字段 | 内容 |
|---|---|---|
| 提示基线 | 提示常量名、调用方式（chat 模板、`enable_thinking`）、示例来源和数量、解码、生成上限 | |
| SFT | 训练集条数、接受 / 拒收数、受监督 token 总数；监督方式、提示监督 token 数；步数、batch × 累积、lr、weight decay、裁剪、精度、种子；选步规则和选中的步 | |
| LoRA | r、alpha、目标模块、可训练参数（公式和实测）；和 SFT 的同一把尺子怎样对齐（20.12.1 节） | |
| TRL LoRA | 框架和版本；loss 路径和对拍结果；数据路径；第一批的监督 token 数；可训练参数名字；checkpoint 选择；`reload-verified` 结果 | |
| DPO | 偏好对来源和数量、min_gap、质量统计（chosen 匹配率、长度）；LoRA 设置、β 扫描范围、步数、lr；选择规则，范围是否看了 val 后扩展 | |
| GRPO | 奖励的每一档和静态探针表；验证器漏报（标准答案能否拿满分）；起点、G、每步提示数、步数、β、ε、`loss_type`（写明 TRL 版本和默认值）、`scale_rewards`；有效组比例、reward、KL、长度曲线；投机统计；和继续 SFT 的算力差 | |
