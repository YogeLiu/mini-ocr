## graph_reasoning

L = 9 + 9 + 3 = 21。dL/dx = 2·2x + 1 = 4x + 1 = 13。

把图写开：a = u + u，L = a + x。从后往前：

1. L 把梯度 1 交给 a 和 x：a.grad = 1，x.grad = 1；
2. a 走两条路径都到 u：u.grad = 1 + 1 = 2；
3. u = x²，局部导数 2x = 6：x.grad = 1 + 2 × 6 = 13。

不同路径的贡献必须相加（第 2 章 2.5 节）。写成 `=`，后到的路径会覆盖先到的：u.grad 变成 1，x.grad 变成 6 或 1，取决于处理顺序。结果错了，也不报错。

连续两次 `backward()`：叶子累加，x.grad = 26。中间节点在第二次反向前先归零，所以 u.grad 重新算出 2，还是 2。如果不归零，旧草稿会再传播一次，x 的梯度会超过 26（2.7.7 节）。

## ce_derivation

单个样本的 ln p_y = z_y − LSE(z)，其中 LSE(z) = ln Σ_j e^{z_j}。对 z_c 求导：

```
∂(−ln p_y)/∂z_c = −y_c + e^{z_c}/Σ_j e^{z_j} = p_c − y_c
```

N 个样本取平均，所以 dS = ∂L/∂S = (P − Y)/N（3.6.7 节）。

S = XW，S_ic = Σ_d X_id W_dc。W_dc 出现在所有样本的 S_ic 里，路径相加得 (Xᵀ dS)_dc。加上正则：

```
dW = Xᵀ (P − Y)/N + 2·reg·W
```

形状：(D, N) @ (N, C) = (D, C)，和 W 相同（3.9.2 节）。

减去最大值 m 不改变结果：e^{z_i − m}/Σ_j e^{z_j − m} 的分子分母都多了因子 e^{−m}，互相抵消。减完以后每项 ≤ 1，分母 ≥ 1，既不上溢，也不会 0/0（3.3.4 节）。

不能先 softmax 再 log：z = [0, −200] 时，p_1 约 1.4 × 10⁻⁸⁷，在 fp32 里下溢成 0，log 得到 −inf。ln p_1 本身约是 −200，是个普通的数。直接用 (z_i − m) − ln Σ_j e^{z_j − m} 计算，就不会经过那个下溢的概率（3.3.5 节）。

## mlp_accounting

两层 MLP：w1 有 1024h 个，b1 有 h 个，w2 有 24h 个，b2 有 24 个。

```
(1024 + 1)h + (h + 1)·24 = 1049h + 24
```

线性模型：1024 × 24 + 24 = 24600。

用测试里的小例子核对：D = 2、H = 3、C = 2 时，(2 + 1)·3 + (3 + 1)·2 = 17；线性模型 2 × 2 + 2 = 6。

初始化：

- 隐藏层后面接 ReLU，可以用 Kaiming，方差 2/D（第 4 章 4.8.2 节）；
- 偏置取 0；
- 输出层的初始化学习者要自己声明，并说明理由。接口只要求权重随机且非零；
- 权重不能全取 0。w1、b1 全零时隐藏层输入全是 0，ReLU 在零点导数取 0，w1 和 b1 没有梯度；隐藏输出是 0，w2 也没有梯度。只有 b2 能学。

ReLU 在零处导数约定为 0。

具体的 h 待校准，答案中的代入由学习者按自己的配置完成，并与代码数出的结果对照。

## adamw_resume

Adam + L2：g' = g + λθ，λθ 一起进入 m 和 v，再被 √v̂ 除。实际衰减强度被这个参数自己的梯度历史扭曲了。

AdamW：先 θ ← θ(1 − ηλ)，m 和 v 只用数据梯度更新，每个参数都乘同一个因子（第 4 章 4.5.3 节）。

检查点漏存（4.10.2 节）：

| 漏了什么 | 后果 |
|---|---|
| 优化器的 m、v、计数 | 更新变了，续训第一步相当于 Adam 的第 1 步 |
| 优化器的非默认配置 | 悄悄换成另一个算法（4.10.3 节） |
| 取批或增广的随机状态 | 数据轨迹变了 |
| 步数 | 学习率用错，可能重新预热 |

逐位一致只在同一环境里讨论：续训前后要执行完全相同的浮点运算序列。换设备、算子实现或软件版本都可能破坏它，这时退一步，比较曲线在统计上是否一致（4.10.4 节）。

## leakage_protocol

同一来源的图是近重复（第 5 章 5.2.4 节）。按图划分时，验证集和测试集的样本会在训练集里有近亲，分数虚高（5.3 节）。所以要按来源分组划分。

同样的原因，同一来源的图不是独立样本。按图做 bootstrap 会夸大有效样本数，区间偏窄。所以 A1 按来源抽样，组内图片一起进入。

近重复检测的检出不等于真的重复。在池子里找最近邻有多重比较问题，会产生误报（5.5.4 节）。合成数据的来源标记是真相，分组后的检出率可以当误报参照。

test 不理想时（0.10.1 节、5.8.3 节）：

- 可以：如实报告预先登记的候选各一次的汇总数字和区间；在验证集上继续分析和改进；
- 不可以：看 test 的错例；根据 test 改参数、选模型、改预处理、重划验证集，然后再报原来那份 test；
- 如果已经受了 test 的影响：在报告里写明，再补一份新的留出集，以后用新的那份报告。
