# 第四部分自测答案

题目在 `book/part4_vlm/self_test.md`。下面的数都是数学结论，已用 CPU 上的 Python 或 PyTorch 核对。

## 第 1 题

(1) HWC：(64, 256, 3)。CHW：(3, 64, 256)。元素 3 × 64 × 256 = 49,152 个。uint8 49,152 字节，fp32 196,608 字节。（27.1 节）

(2) 128/255 = 0.50196，(0.50196 − 0.5)/0.5 = 0.00392（27.2.2 节）。再做一次：(0.00392 − 0.5)/0.5 = −0.9922。

(3) scale = 224/256 = 0.875。新高 round(56) = 56，新宽 224。上留白 (224 − 56)//2 = 84。公式占 56/224 = 25%。（27.4.2 节）

(4) 高 × 3.5，宽 × 0.875。拉伸把字压扁或拉高，不浪费画布。letterbox 字形不变，但内容只占一小条，小字的有效像素更少。（27.4.1 节）

## 第 2 题

(1) 补 padding 后长 H + 2p。起点 m·s 要满足 m·s + k ≤ H + 2p，m ≤ (H + 2p − k)/s，m 从 0 取整数，共 ⌊(H + 2p − k)/s⌋ + 1 个（28.3.2 节）。64 → ⌊63/2⌋ + 1 = 32。256 → 128。65 → ⌊64/2⌋ + 1 = 33。

(2) (3 × 3 × 16 + 1) × 32 = 145 × 32 = 4640。

(3) r_l = r_{l−1} + (k − 1)j_{l−1}，j_l = j_{l−1}s_l（28.6.3 节）。

| 层 | r | j |
|---|---|---|
| 输入 | 1 | 1 |
| conv3 s=1 | 3 | 1 |
| conv3 s=2 | 5 | 2 |
| conv3 s=1 | 9 | 2 |
| conv3 s=2 | 13 | 4 |

(4) j = 4：相邻单元在输入上隔 4 个像素。一两个像素宽的分式线落在格子之间，信息被下采样损伤，靠感受野大也补不回位置精度。（28.7 节）

## 第 3 题

(1) Y[i, j] = Σ W[p, q] X[i + p, j + q] + b。

Y = [[1 + 0 − 0 + 2 + 1, 2 + 0 − 1 + 6 + 1], [0 + 0 − 2 + 0 + 1, 1 + 0 − 0 + 2 + 1]] = [[4, 8], [−1, 4]]。

(2) dY 全是 1（28.5.2 节）。db = Σ_ij dY[i, j]。dW[p, q] = Σ_ij dY[i, j] X[i + p, j + q]。dX[a, b] = Σ dY[i, j] W[p, q]，对所有满足 a = i + p、b = j + q 的组合求和。

(3) db = 4。dW[0, 0] = 1 + 2 + 0 + 1 = 4。dW[0, 1] = 2 + 0 + 1 + 3 = 6。dW[1, 0] = 0 + 1 + 2 + 0 = 3。dW[1, 1] = 1 + 3 + 0 + 1 = 5。

dX[1, 1]：(i, j, p, q) = (0, 0, 1, 1) 给 2；(0, 1, 1, 0) 给 −1；(1, 0, 0, 1) 给 0；(1, 1, 0, 0) 给 1。和为 2。（autograd 核对。）

## 第 4 题

(1) μ = 5。σ² = (9 + 1 + 1 + 9)/4 = 5。输出 (x − 5)/√5 = [−1.3416, −0.4472, 0.4472, 1.3416]。

(2) running_mean = 0.9 × 0 + 0.1 × 5 = 0.5。无偏方差 = 5 × 4/3 = 6.6667。running_var = 0.9 × 1 + 0.1 × 6.6667 = 1.5667。（28.8.2 节；`nn.BatchNorm2d` 核对。）

(3) eval 用 running_mean、running_var，同一张图和谁一批都一样。语言模型不用它：一个样本的输出会受同批其他样本影响；统计量里混进时间维还会偷看未来（9.3.6 节）。

## 第 12 题

(2) 一个只拿 0.2 的答案，推力和拿 1.0 的完全正确答案一样大。

(3) 和 2.2，μ = 0.275。偏差平方和 0.935，σ = √(0.935/8) = 0.3419。

## 第 13 题

(1) 只有 −Σq_i ln p_i 依赖 z。softmax 的输入是 z/T，交叉熵对它的梯度是 p − q，链式法则多一个 1/T：(p_j − q_j)/T。乘 T² 得 T(p_j − q_j)。（35.3.3 节）

(2) p = [1/3, 1/3, 1/3]（两个温度都一样）。

| T | q | T(p − q) |
|---|---|---|
| 1 | [0.8668, 0.1173, 0.0159] | [−0.5335, 0.2160, 0.3175] |
| 2 | [0.6652, 0.2447, 0.0900] | [−0.6638, 0.1772, 0.4866] |

（autograd 核对 T = 2 这一行。）

(3) (p − q)/T = [−0.1660, 0.0443, 0.1217]。高温下 p − q 约按 1/T 缩小，再乘 1/T，共约 1/T²。（35.3.3 节）

(4) 两个假设都不成立：第 i 维不代表同一个字符串（坐标不对齐），第 t 个位置不代表同一段文本（位置不对齐）。文本是两边共享的接口，所以教师出文本，学生重新切分后做交叉熵。（35.4.3 节）

(5) p(教师写法) = 0.3。w < 0.5，贪心写参考的写法。局限：真实贪心逐 token 取最大，写出的句子不一定是整句众数；学生容量有限，图片之间还会互相泛化。（35.6.3 节）
