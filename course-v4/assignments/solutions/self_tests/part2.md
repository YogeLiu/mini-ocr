## 第 1 题

(1) 初始：`a b c` × 5，`a b d` × 3，`b c d` × 2。

| 轮 | 相邻对的加权次数 | 合并 |
|---|---|---|
| 1 | ab 8，bc 7，bd 3，cd 2 | a + b → X |
| 2 | Xc 5，Xd 3，bc 2，cd 2 | X + c → Y |
| 3 | Xd 3，bc 2，cd 2 | X + d → Z |

ab = 5 + 3；bc = 5 + 2。（算法见 6.5.1、6.5.3 节）

(2) 初始 30。第一次后：2×5 + 2×3 + 3×2 = 22。第二次后：1×5 + 2×3 + 3×2 = 17。第三次后：5 + 3 + 6 = 14。

(3) `a b c d` → 按规则 1：`ab c d` → 按规则 2：`abc d`。规则 3 用不上。结果两个 token：`abc`、`d`。

(4) 规则 2 的输入 X 只有规则 1 执行后才存在。乱序应用得到的切法和训练时不同，相同的文本可能切成不同的 token，模型见到的就不是训练时的分布。（6.6.2 节）

## 第 2 题

(1) 输入 `BOS x ^ 2`，目标 `x ^ 2 EOS`（7.2.2 节）。P = P(x | BOS) · P(^ | BOS x) · P(2 | BOS x ^) · P(EOS | BOS x ^ 2)。

(2) 甲：3.2/ln 2 = 4.6166 bits/token，÷ 2.5 = 1.8466 bits/byte。乙：4.0/ln 2 = 5.7708 bits/token，÷ 3.5 = 1.6488 bits/byte。乙更好，尽管它的 loss 更高：token 更大，每个 token 难预测，总量却更少（6.10.1 节）。

(3) e^{3.2} = 24.53。8 bits/byte（6.10.2 节）。

## 第 3 题

(1) dh = 256/8 = 32。（8.8.3 节）

| 步骤 | 形状 |
|---|---|
| q = xW_Q | (4, 16, 256) |
| `view(B, T, h, dh)` | (4, 16, 8, 32) |
| `transpose(1, 2)` | (4, 8, 16, 32) |
| 分数、权重 | (4, 8, 16, 16) |
| 每头输出 | (4, 8, 16, 32) |
| `transpose(1, 2)` | (4, 16, 8, 32) |
| `reshape(B, T, d)` | (4, 16, 256) |
| 乘 W_O | (4, 16, 256) |

(2) 4 × 8 × 16 × 16 = 8192 个，fp32 共 32768 字节。

(3) 先 view，切的是每个 token 的 d 维本身。先 transpose 再 reshape，切口横跨 d 和 T 两维，数据错乱而且不报错。transpose 后内存不连续，把 (h, dh) 合并无法用现有 stride 表示，`view` 报错；`reshape` 或 `contiguous()` 会复制出连续的数据。（8.8.3 节）

(4) 每项 q_ik_i 均值 0，方差 E[q_i²]E[k_i²] = 1。d 项独立，方差相加：Var(q·k) = d，标准差 √d。除以 √d 后方差回到 1，softmax 不会因为 d 大而饱和。（8.6.1 节）

(5) 分数：q·k₀/√2 = 0.7071，q·k₁/√2 = 0。e^{0.7071} = 2.0281。权重 2.0281/3.0281 = 0.6698，1/3.0281 = 0.3302。输出 2 × 0.6698 + 4 × 0.3302 = 2.6605。

## 第 10 题

(1) 字节数 = 2 · L · n_kv_head · dh · T · B · 每数字节数。2 是 k 和 v；n_kv_head · dh 是每个 k（或 v）的数；L 层；T · B 是总位置数。（15.5.1 节）

(2) 每层每 token 2 × 4 × 64 × 2 = 1024 字节，12 层 12,288 字节（12 KiB）。12,288 × 2048 × 16 = 402,653,184 字节 = 384 MiB。

(3) 不用 GQA：n_kv_head = 8，768 MiB（15.6.1 节）。fp32：每数 4 字节，也是 768 MiB。

(4) 112 KiB × 2048 × 8 = 1.75 GiB。验算：15.5.3 节 T = 4096、B = 1 是 448 MiB，这里 T 减半、B 乘 8，448/2 × 8 = 1792 MiB。Qwen3 显式给 head_dim = 128，n_head · head_dim = 2048，不等于 hidden_size = 1024，所以不能用 hidden_size/n_head（15.5.3 节）。

(5) 第 t 步只需要新 token 自己的 q，和所有历史的 k、v。历史 q 再也用不到。缓存放在 `repeat_kv` 之前，否则 GQA 省不下内存（15.2 节、15.6.1 节）。

## 第 13 题

(1) 𝓛 = (Σ_{G₁} ℓ)/N_tot + (Σ_{G₂} ℓ)/N_tot。每个小批的 sum 损失除以整批 token 总数 N_tot = 20，不除以本小批的 token 数。（16.9.2 节）

(2) 小批 token 数 12 和 8。

| 方式 | 样本 0（长 3） | 样本 1（长 9） | 样本 2（长 6） | 样本 3（长 2） |
|---|---|---|---|---|
| token | 1/20 = 0.05 | 0.05 | 0.05 | 0.05 |
| micro_mean | 1/12 × 1/2 = 0.0417 | 0.0417 | 1/8 × 1/2 = 0.0625 | 0.0625 |
| sample | 1/3 × 1/4 = 0.0833 | 1/9 × 1/4 = 0.0278 | 1/6 × 1/4 = 0.0417 | 1/2 × 1/4 = 0.125 |

(3) 0.125/0.05 = 2.5 倍。

(4) `micro_mean` 让权重取决于怎样分组，只有两组 token 数相同才等于整批。`sample` 优化的是另一个目标：每条样本权重相同，它算得没错，只是目标不同。（16.9.2、16.9.3 节）

## 第 14 题

(1) 只看 A ∪ B。π 随机，最前者 x* 等可能是并集里任何元素。x* ∈ A ∩ B 时，它同时是 A、B 的最前者，两个 h 相等。x* 只在一边时，另一边的最前者严格靠后，不相等。所以“相等”等价于 x* ∈ A ∩ B，概率 |A ∩ B|/|A ∪ B| = J。（12.4.4 节）

(2) P = 1 − (1 − s^r)^b。s = 0.8：s⁵ = 0.32768，P = 0.99964。s = 0.4：s⁵ = 0.01024，P = 0.18605。（12.5.3 节）

(3) t ≈ (1/b)^{1/r} = (1/20)^{0.2} = 0.5493。减少漏报：增大 b 或减小 r，转折点左移。代价是候选对变多，比较更费时，误报也多。

## 第 15 题

(1)

```python
def forward(self, x):                                   # (B, T, d)
    B, T, d = x.shape
    dh = d // self.h
    q = self.q(x).view(B, T, self.h, dh).transpose(1, 2)  # (B, h, T, dh)
    k = self.k(x).view(B, T, self.h, dh).transpose(1, 2)  # (B, h, T, dh)
    v = self.v(x).view(B, T, self.h, dh).transpose(1, 2)  # (B, h, T, dh)
    s = q @ k.transpose(-2, -1) / dh ** 0.5               # (B, h, T, T)
    mask = torch.tril(torch.ones(T, T, dtype=torch.bool, device=x.device))
    s = s.masked_fill(~mask, float("-inf"))               # 上三角置 -inf
    w = s.softmax(-1)                                     # (B, h, T, T)
    y = w @ v                                             # (B, h, T, dh)
    y = y.transpose(1, 2).reshape(B, T, d)                # (B, T, d)
    return self.o(y)                                      # (B, T, d)
```

评分看三点：除以 √dh，mask 在 softmax 之前，合并用 `reshape`（8.5、8.7、8.8 节）。

(2) 随机输入 `x`，复制一份，只改最后一个 token，比较两次输出的前 T − 1 个位置，差应该只有浮点误差；最后一个位置应该变。也可以对输出的第 t 个位置反向，检查 `x` 上 t 之后的梯度全为 0。
