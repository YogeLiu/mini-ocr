## 第 2 题

(3) −ln p：0.2231、0.6931、1.3863、0.1054。和 2.4079，除以 4 得 0.6020。

(4) 再移一次：每个位置预测后面第二个 token，训练目标错位，loss 很难下降（只能移一次，19.3.3 节）。EOS 没有监督：模型学不会停（19.5 节）。提示算进 labels：模型被要求背诵提示，提示 token 也占了分母，稀释了答案的权重（19.4.2 节）。

## 第 3 题

(1) 定义见 18.2 节。EM_norm = (36 + 18)/100 = 0.54。改坏率 = (40 − 36)/40 = 4/40 = 0.10。fix_rate = 18/60 = 0.30。

(2) 照抄：EM_norm = 40/100 = 0.40，改坏率 0/40 = 0，fix_rate 0/60 = 0。这个模型 EM_norm 高 0.14，但有 4 条改坏。要用配对区间判断差别是否可信，还要看改坏和 fix_rate 的取舍（22.3 节）。

(3) SE = √(0.54 × 0.46/100) = 0.0498。半宽 1.96 × 0.0498 = 0.0977。区间 [0.442, 0.638]。（22.1.2 节）

(4) 语料级：(5 + 4)/(10 + 40) = 0.18。逐条平均：(0.5 + 0.1)/2 = 0.30。预测比参考长很多时编辑距离可以超过参考长度，所以 CER 可以大于 1（31.6.3、33.7.3 节）。

(5) EM_norm、CER、改坏、fix_rate（0.9.3 节）。parse_rate 只说语法，不说对错，连标准答案的可解析率也到不了 1，只作诊断，要和标准答案的可解析率一起读（18.2.1 节）。

## 第 4 题

(1) ā = (300 + 20)/500 = 0.64。b̄ = (300 + 40)/500 = 0.68。d̄ = 0.04。

(2) 不一致 60 题。Var(d) = 60/500 − 0.04² = 0.1184。SE = √(0.1184/500) = 0.01539。区间 0.04 ± 0.0302 = [0.0098, 0.0702]。（22.3.3 节）

(3) SE = √((0.64 × 0.36 + 0.68 × 0.32)/500) = √(0.448/500) = 0.02993。区间 0.04 ± 0.0587 = [−0.0187, 0.0987]。

(4) 配对区间不含 0，B 更好；独立区间含 0，分不出来。两个模型对同一批题的对错正相关，Cov(a, b) = 0.6 − 0.64 × 0.68 = 0.1648 > 0。配对的方差少了 2Cov，共同难度被抵消。（22.3.1、22.3.3 节）

## 第 5 题

(2) 各评一次时，选择已经在 val 上定了，test 只报告，不从 test 里挑（0.10.1 节）。偏差来自按 test 分数做决定，不来自评测的次数（22.7.1 节）。

## 第 6 题

(1) y = W₀x + (α/r)BAx。A：[r, in]。B：[out, r]。秩不超过 r。（20.2.1、20.2.2 节）

(2) s = α/r = 2。W₀x = [3, 1, 4]。h = Ax = 3 − 1 = 2。Bh = 0，y = [3, 1, 4]。g = [1, 2, 0]。∂L/∂B = s·g·hᵀ = 2 × 2 × [1, 2, 0]ᵀ = [[4], [8], [0]]。∂L/∂A = s(Bᵀg)xᵀ = [[0, 0]]。（20.3.2 节）

(3) Bh = [2, −2, 0]，乘 s 得 [4, −4, 0]。y = [7, −3, 4]。Bᵀg = 1 − 2 = −1。∂L/∂A = 2 × (−1) × [3, 1] = [[−6, −2]]。

(4) BA = [[1, −1], [−1, 1], [0, 0]]。W′ = W₀ + 2BA = [[3, −2], [−2, 3], [1, 1]]。W′x = [9 − 2, −6 + 3, 3 + 1] = [7, −3, 4]。相同。（20.6 节）

(5) ∂L/∂A 含 Bᵀ，为 0；∂L/∂B 含 Ax，为 0。两个梯度都是 0，旁路永远不动（20.3.2 节）。

(6) 每层 8 × 3072 + 8 × 2048 = 24,576 + 16,384 = 40,960。× 28 = 1,146,880。α 没有影响，它只是缩放系数（20.7.1 节）。

## 第 8 题

(1) 分子分母同除 exp r₁：P = 1/(1 + exp(−(r₁ − r₂))) = σ(r₁ − r₂)。（23.3.2 节）

(2) 令 Z = Σπ_ref exp(r/β)，π* = π_ref exp(r/β)/Z。J = Σπ[r − β log(π/π_ref)] = −βΣπ log(π/(π_ref exp(r/β))) = −βΣπ log(π/(Zπ*)) = −βKL(π‖π*) + β log Z。β log Z 和 π 无关，KL ≥ 0，所以 π = π* 时 J 最大。（23.4.2 节）

(3) 权重：0.6，0.4 × e² = 2.9556。Z = 3.5556。π* = [0.1687, 0.8313]。β 变大时靠近 π_ref。（23.4.3 节）

(4) r = β log(π*/π_ref) + β log Z。代入 r_w − r_l，两个 β log Z(x) 一正一负抵消。（23.5.1、23.5.2 节）

(5) r̂_w = 0.1 × (−4 + 6) = 0.2。r̂_l = 0.1 × (−7 + 6.5) = −0.05。margin u = 0.25。σ(u) = 0.5622，loss = −ln 0.5622 = 0.5759。导数 = −βσ(−u) = −0.1 × 0.4378 = −0.0438。（23.5.4、23.5.5 节）

## 第 9 题

(2) E[b∇log π] = bΣπ∇log π = bΣ∇π = b∇Σπ = b∇1 = 0。（24.3.3 节）

## 第 10 题

(1) KL = 0.5 ln(0.5/0.8) + 0.5 ln(0.5/0.2) = 0.2231。

(2) ρ = [1.6, 0.4]，log ρ = [0.4700, −0.9163]。

| 样本 | k1 = −log ρ | k2 = ½(log ρ)² | k3 = ρ − 1 − log ρ |
|---|---|---|---|
| 1 | −0.4700 | 0.1105 | 0.1300 |
| 2 | 0.9163 | 0.4198 | 0.3163 |
| 期望 | 0.2231 | 0.2651 | 0.2231 |

(3) k1、k3 无偏（24.5.3 节）。E_p[ρ − 1] = Σp(q/p) − 1 = Σq − 1 = 0。

(4) log ρ ≤ ρ − 1，所以 k3 ≥ 0。负的 KL 往往是 k1 的单样本或小批次值，不一定是 bug（24.5.3 节）。

## 第 12 题

(1) μ = 0.5。偏差 [0.5, 0, −0.5, 0]。方差 0.5/4 = 0.125。σ = 0.3536。Â = [1.4142, 0, −1.4142, 0]。（25.2.3 节。带 ε_num = 10⁻⁴ 时是 ±1.4138。）

(2) loss = −(1/4)ΣÂ = 0，组内优势之和为 0。梯度不是 0：每个 token 的梯度是 −Â_i/(L_i N)（25.3.3 节）。

(3) N = 4，ΣL = 10，N·L_max = 20。权重见 25.7.2 节。

| 回答 | Â | L | `grpo` 1/(4L) | `dapo` 1/10 | `dr_grpo` 1/20 |
|---|---|---|---|---|---|
| 1 | 1.4142 | 2 | −0.1768 | −0.1414 | −0.0707 |
| 3 | −1.4142 | 1 | +0.3536 | +0.1414 | +0.0707 |

(4) `grpo` 里两条回答的优势绝对值相同，每个 token 的力度却和长度成反比：第 3 条（长 1）是第 1 条（长 2）的 2 倍。好回答越短被推得越用力；坏回答越长被罚得越轻。`dapo` 和 `dr_grpo` 去掉了 1/L_i。（25.7.3 节）

(5) 有效概率 = 1 − p^G − (1 − p)^G。G = 4：1 − 0.2401 − 0.0081 = 75.18%。G = 8：1 − 0.0576 − 0.0001 = 94.23%。p ≥ 0.5 之后，模型越强，有效组越少（25.6.4 节）。
