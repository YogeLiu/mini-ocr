# 第一部分自测答案

题目在 `book/part1_foundations/self_test.md`。下面的数都是数学结论，已用 CPU 上的 Python 或 PyTorch 核对。

## 第 1 题

(1) `A[:, None, :] - B[None, :, :]`。`diff` 形状 (N, M, D) = (2000, 500, 128)。（1.3.3 节）

(2) 2000 × 500 × 128 × 4 = 512,000,000 字节，除以 2²⁰ 得 488.28 MiB。（算法同 1.3.4 节）

(3) 量级是 N·D + M·D + N·M 个元素：256,000 + 64,000 + 1,000,000 = 1,320,000 个。乘 4 字节得 5,280,000 字节，约 5.04 MiB。（1.3.4 节）

(4) 从右对齐（1.2.3 节）。(3, 1, 5) 和 (4, 1)：最后一维 5 对 1，得 5；中间 1 对 4，得 4；最左 3。结果 (3, 4, 5)。(2, 3) 和 (3, 2)：最后一维 3 对 2，都不是 1，冲突，不能广播。

## 第 2 题

(1) `x.stride()` = (15, 5, 1)。`y.shape` = (5, 2, 3)。permute 把 stride 一起重排：`y.stride()` = (1, 15, 5)。（1.5.3 节）

(2) 偏移量 0。位置 = 4×1 + 1×15 + 2×5 = 29，值是 29。它就是 `x[1, 2, 4]`：1×15 + 2×5 + 4×1 = 29。

(3) `y` 不连续。`view` 不移动数据，新形状要能用现有 stride 表示，这里做不到，报错。`reshape` 必要时复制一份连续的数据，能成功。（1.6.2 节，8.8.3 节）

## 第 3 题

(1) a → (×) ← b，得 u；u、a → (+)，得 v；v → (²)，得 L。u = −6，v = −4，L = 16。

(2) ∂L/∂v = 2v = −8。∂L/∂u = −8 × 1 = −8。∂L/∂b = −8 × a = −16。a 有两条路：经乘法 −8 × b = 24，经加法 −8 × 1 = −8，相加得 ∂L/∂a = 16。（2.5.2 节）

(3) ∂L/∂a = 2a(b + 1)² = 2 × 2 × 4 = 16。∂L/∂b = 2a²(b + 1) = 2 × 4 × (−2) = −16。一致。

(4) 多元链式法则要把每条路径的贡献相加，所以用 `+=`（2.5.4 节）。写成 `=`，后处理的那条边会覆盖前一条：最后处理乘法边得 24，最后处理加法边得 −8。两个都不是 16。

## 第 4 题

(1) z = 0.5 × 2 − 0.5 = 0.5。h = 0.5。y = 3 × 0.5 + 1 = 2.5。L = ½ × 1.5² = 1.125。

(2) ∂L/∂y = y − t = 1.5。∂L/∂b₂ = 1.5。∂L/∂w₂ = 1.5 × h = 0.75。∂L/∂h = 1.5 × w₂ = 4.5。relu 打开，∂h/∂z = 1，所以 ∂L/∂z = 4.5。∂L/∂w₁ = 4.5 × x = 9。∂L/∂b₁ = 4.5。

(3) w₁ = 0.5 − 0.9 = −0.4。b₁ = −0.5 − 0.45 = −0.95。w₂ = 3 − 0.075 = 2.925。b₂ = 1 − 0.15 = 0.85。新的 z = −0.4 × 2 − 0.95 = −1.75，h = 0，y = 0.85，L = ½ × 0.15² = 0.01125。

(4) 都是 0。z < 0 时 relu 关闭，局部导数是 0，梯度传不回去（2.6.6 节）。这一步 loss 变小了，但这个单元在这个输入上已经关闭。

## 第 5 题

(1) f(x ± h) = f ± h f′ + (h²/2) f″ ± (h³/6) f‴ + …。

前向差分：[f(x + h) − f(x)]/h = f′ + (h/2) f″ + …，误差主项 (h/2) f″，O(h)。

中心差分：相减后偶数次项消掉，[f(x + h) − f(x − h)]/(2h) = f′ + (h²/6) f‴ + …，误差主项 (h²/6) f‴，O(h²)。（2.8.3 节）

(2) f′(1) = 4，f″(1) = 12，f‴(1) = 24。中心：(1.4641 − 0.6561)/0.2 = 4.04，误差 0.04，主项 (0.01/6) × 24 = 0.04，相等（下一项含 f⁽⁵⁾ = 0）。前向：(1.4641 − 1)/0.1 = 4.641，误差 0.641，主项 0.05 × 12 = 0.6，差的 0.041 来自更高阶项。

(3) h 变小，截断误差降，舍入误差 ε|f|/h 升。令两项相当：h³ ~ ε，所以最佳步长约 ε^(1/3)，不再往小。（2.8.4 节）

## 第 6 题

(1) e^z = 2.7183、1、0.3679，和 4.0862。p = [0.6652, 0.2447, 0.0900]。L = −ln 0.2447 = 1.4076。

(2) 对 z_k 求导：第一项 −z_c 给 −y_k；第二项 ln Σ e^{zⱼ} 给 e^{z_k}/Σ e^{zⱼ} = p_k。所以 ∂L/∂z_k = p_k − y_k（3.6.2 节）。代入：[0.6652, −0.7553, 0.0900]。

(3) 和为 0。Σp_k = 1，Σy_k = 1，所以 Σ(p_k − y_k) = 0。

(4) z′ = z − 0.5 × 梯度 = [0.6674, 0.3776, −1.0450]。p′ = [0.5184, 0.3880, 0.0935]。L′ = −ln 0.3880 = 0.9467。

(5) p 不变，softmax 只看差。e^{1001} 超出 fp32 范围，得 inf，p 变成 nan。稳定算法：先减最大值，或者用 log-softmax：ln p_c = z_c − LSE(z)，LSE 里先减去最大值（3.3.4、3.3.5 节）。

## 第 7 题

(1) −ln 0.5 = 0.6931，−ln 0.25 = 1.3863，−ln 0.125 = 2.0794。和 4.1589，除以有效数 3，得 1.3863。

(2) 除以 6 得 0.6931。loss 被稀释了，数值还取决于 batch 里 padding 的多少，和样本本身无关（3.7.2 节）。不报错，所以危险。

(3) ln 512 = 6.2383。ln 24 = 3.1781（5.6.2 节写作约 3.18）。

(4) 15 远高于 6.2383。最后一层 logits 太大，多半是初始化尺度太大（3.8.3 节）。

## 第 8 题

(1) m = 0.1 × 2 = 0.2。v = 0.001 × 4 = 0.004。m̂ = 0.2/0.1 = 2。v̂ = 0.004/0.001 = 4。步长 0.1 × 2/2 = 0.1。θ = 0.9。

(2) m = 0.9 × 0.2 + 0.1 × (−1) = 0.08。v = 0.999 × 0.004 + 0.001 × 1 = 0.004996。m̂ = 0.08/(1 − 0.81) = 0.4211。v̂ = 0.004996/(1 − 0.998001) = 2.4992，√v̂ = 1.5809。步长 0.1 × 0.4211/1.5809 = 0.02663。θ = 0.9 − 0.02663 = 0.8734。（`torch.optim.Adam` 核对：0.87337。）

(3) m 还记着上一步的正梯度，m̂ 仍为正，所以 θ 继续减小。

(4) 展开 m_t = (1 − β₁)(g_t + β₁g_{t−1} + … + β₁^{t−1}g₁)。取期望，等比求和：E[m_t] = (1 − β₁)·(1 − β₁ᵗ)/(1 − β₁)·E[g] = (1 − β₁ᵗ)E[g]。m 从 0 开始，被初值拉低了一个因子，偏差修正除掉它（4.4.3 节）。

## 第 9 题

(1) θ ← θ − η(g + λθ) = (1 − ηλ)θ − ηg，和权重衰减的写法相同。（4.5.2 节）

(2) g′ = λθ = 0.03。m̂ = 0.03，√v̂ = 0.03，比值 1，θ = 3 − 0.1 = 2.9。λ = 0.0001 时比值还是 1，θ 还是 2.9。

(3) (1 − 0.1 × 0.01) × 3 = 2.997。数据梯度为 0，更新方向是 0。

(4) Adam + L2 里 λθ 被 √v̂ 除掉，第一步衰减和 λ 无关。AdamW 的衰减直接乘在 θ 上，和 λ 成正比，不经过 m、v。（4.5.3 节）

## 第 13 题

规则见 0.10.1 节。

(1) 不违反。val 用来做决定。

(2) 不违反。

(3) 违反两处：开发期看了 test 错例，还依据 test 改了设置。补救：在报告里写明，补一份新的、从来没看过的测试集，以后用新的那份报告。

## 第 14 题

(1) 同一张原图的增广版本散落在几个集合里，这是泄漏。先按原图（或更粗的来源）分组划分，再只在训练集里增广（5.10、5.4 节）。

(2) 四个格子的均值：0.8、0、0、0.4。平均值 0.3。哈希 [1, 0, 0, 1]。变换后格子是 0.6、0.2、0.2、0.4，平均值 0.35，哈希还是 [1, 0, 0, 1]，不变（5.5.2 节）。

(3) 甲：欠拟合，训练得不够。加大学习率或多训（5.6.2 节）。乙：过拟合。加数据、加增广、加正则，或者早停（5.6.3 节）。
