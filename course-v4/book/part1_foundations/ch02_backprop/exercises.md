```python
def backward(self):
    topo, visited = [], set()

    def build(v):
        if v not in visited:
            visited.add(v)
            for p in v._prev:
                build(p)
            topo.append(v)
    build(self)
    self.grad = 1.0
    for v in topo:
        v._backward()
```

```python
def numerical_grad(f, xs, h=1e-5):
    grads = []
    for i in range(len(xs)):
        old = xs[i]
        xs[i] = old + h
        fp = f(xs)
        xs[i] = old - h
        fm = f(xs)
        grads.append((fp - fm) / (2 * h))
    return grads
```

## 答案与提示

### 概念题要点

- **C1.** 导数只描述输入在当前点附近**很小**的变化引起的输出变化。离开这个小邻域，曲线的弯曲就不能忽略。例子：2.6.5 节学习率 0.1 时，按梯度预测损失会下降，实际损失从 1 升到 4.884；2.1.1 节 w 加 0.1 时，实际变化 −0.76，按导数估计是 −0.8。
- **C2.** 局部导数是节点输出对它直接输入的导数，只看这一个运算：∂d/∂a = b = −3，∂d/∂b = a = 2。上游梯度是 L 对这个节点**输出**的导数：∂L/∂d = 8。节点 a 的梯度 ∂L/∂a = 上游梯度 × 局部导数 = 8 × (−3) = −24。
- **C3.** 反向模式从唯一的输出 L 出发走一遍，每个运算只计算一次局部导数并乘一次，总代价和前向是同一个量级，不需要对每个参数各走一遍。前向模式走一遍得到所有输出对一个输入的导数，适合输入少、输出多；反向模式走一遍得到一个输出对所有输入的导数，适合输入多、输出少。训练时输入是全部参数（极多），输出只有损失（一个），所以用反向模式。
- **C4.** x 变化 Δx 时，它的每一次使用都同步变化 Δx，每条路径各引起一份输出变化，总变化是各份之和，所以导数是各路径贡献之和（2.5.2 节）。例子：一个输入进入多个神经元；一个参数被一批样本共用；残差连接；权重共享；注意力里 x 生成 q、k、v。
- **C5.** 一个节点可能被多条路径用到，每条路径的梯度都要加进来，`=` 会让后一条覆盖前一条。因为是累加，所以 `.grad` 必须有一个干净的起点 0，否则会和以前的梯度混在一起，所以每步要清零。PyTorch 选择累加，是为了支持把一大批样本拆成几小批分别 backward、梯度自动相加（梯度累积，第 16 章）。
- **C6.** 一个节点调用 `_backward` 时，它的梯度必须已经收齐，也就是所有用到它的节点都已经处理过。拓扑逆序保证这一点。按正序调用时，节点在梯度还没传到时就往下传了，传下去的是 0 或不完整的梯度；正文 2.7.6 节的例子里 a、b、c 的梯度全是 0。
- **C7.** 帮助理解：梯度从输出往回传，每经过一个工位按局部敏感度相乘，每个工位只需要知道本地信息。不准确的三处：梯度加起来不等于 100%（可以很大、为 0、为负）；梯度衡量的是对微小变化的敏感度，不是对结果的功劳（饱和或 relu 关掉时梯度为 0，但不代表无关）；负的梯度是有用的信息，表示增大它会让损失减小。
- **C8.** 中心差分左右各取一点，泰勒展开里的偶数次项相减后抵消，误差从 O(h) 降到 O(h²)（2.8.3 节）。h 太小时，f(x + h) 和 f(x − h) 非常接近，相减损失有效数字，舍入误差约 ε|f|/h，随 h 减小而增大（2.8.4 节）。最佳 h 在 ε^(1/3) 附近，float64 约 1e-5 到 1e-6。
- **C9.** 梯度本身的大小可以相差很多个数量级，同样的绝对误差对大梯度可以忽略，对小梯度可能是错了好几倍。相对误差和梯度的尺度无关。当两个梯度都非常接近 0（比如都小于 1e-8）时，相对误差的分母太小，正常的舍入误差也会让相对误差接近 1，这时要看绝对误差（2.8.7 节）。
- **C10.** ∂L/∂W = Xᵀ (∂L/∂Y)，形状 (n, B) @ (B, m) = (n, m)；∂L/∂X = (∂L/∂Y) Wᵀ，形状 (B, m) @ (m, n) = (B, n)。形状只有这样拼才对得上。注意 ∂L/∂W 里对 B 那一维求了和：W 被 B 个样本共用，梯度要相加（2.5 节）。
- **C11.** (a) 报错 `element 0 of tensors does not require grad and does not have a grad_fn`：x 没有 requires_grad，图里没有需要梯度的东西。(b) `y.grad` 是 None（并有警告）：y 不是叶子，默认不保存梯度；`x.grad` 是 3。(c) 报错，同 (a)：no_grad 里算出的 y 没有 grad_fn。(d) 6：每次重新前向建了新图，所以不会报"第二次反向"的错；叶子的梯度累加，3 + 3 = 6。
- **C12.** 不清零时，第 t 步用于更新的是前 t 步梯度之和。早期梯度方向比较一致，累加相当于加大了步子，所以进展更快；但旧梯度永远不衰减，在那次实验里梯度范数越积越大，最后冲过头而发散。（这是那次实验的现象，不是必然：历史梯度可以相互抵消，范数不一定单调增大，见 2.9.6 节的反例。）教训：要看完整的训练曲线，并且先确认代码正确，再判断改动的效果。相同点：都把历史梯度加进当前的更新；不同点：动量让旧梯度按比例（如 0.9）逐步衰减，而不清零时旧梯度权重永远是 1。

### 手算题答案

- **H1.** u = 2x = 1，y = tanh(1) = 0.7616。dy/du = 1 − 0.7616² = 0.4200，du/dx = 2，dy/dx = 0.8400。验证：tanh(1.002) = 0.76243，变化约 0.00084，和 0.8400 × 0.001 = 0.00084 一致。
- **H2.** (a) u = 2，v = 4，f = 16。(b) ∂f/∂v = 2v = 8；∂f/∂u = 8；∂f/∂x = 8 × y = 16；y 有两条路径：经过乘法贡献 8 × x = 8，直接经过加法贡献 8 × 1 = 8，∂f/∂y = 16。(c) f = y²(x + 1)²，∂f/∂x = 2y²(x + 1) = 16，∂f/∂y = 2y(x + 1)² = 16。
- **H3.** (a) z1 = 1.5、z2 = 1 不变；a1 = tanh(1.5) = 0.9051，a2 = tanh(1) = 0.7616，ŷ = 0.9051 − 0.7616 + 0.5 = 0.6436（四舍五入），L = (0.6436 − 2)² = 1.8399。(b) ∂L/∂ŷ = 2(ŷ − y) = −2.7129；∂L/∂a1 = −2.7129 × v1 = −2.7129，∂L/∂z1 = −2.7129 × (1 − 0.9051²) = −0.4902；∂L/∂a2 = −2.7129 × v2 = 2.7129，∂L/∂z2 = 2.7129 × (1 − 0.7616²) = 1.1393。(c) ∂L/∂w11 = −0.4902 × 2 = −0.9805；∂L/∂w21 = 1.1393 × 2 = 2.2787；∂L/∂v1 = −2.7129 × 0.9051 = −2.4556；∂L/∂x1 = −0.4902 × 1 + 1.1393 × 0.5 = 0.0794。（这些数由测试 `test_tanh_variant_answers` 核对。）(d) 神经元 1：z1 = 1.5 更大，tanh 更饱和，局部导数 0.1807 比神经元 2 的 0.4200 小得多，所以它的参数梯度被缩小得更多。relu 版本里两个局部导数都是 1。
- **H4.** (a) ŷ = 1.5，e = 0.5，L = 0.25，∂L/∂w = 2e·x = 3，∂L/∂b = 2e = 1。(b) 第二个样本 ŷ = −0.5，e = −1.5，L₂ = 2.25，∂L₂/∂w = 2 × (−1.5) × (−1) = 3，∂L₂/∂b = −3。平均：L = 1.25，∂L/∂w = (3 + 3)/2 = 3，∂L/∂b = (1 − 3)/2 = −1。(c) 平均损失的梯度 = 各样本梯度之和再除以样本数。这是"同一个参数被用了多次，梯度相加"的直接体现。
- **H5.** (a) 前向：(1.331 − 1)/0.1 = 3.31，误差 0.31；中心：(1.331 − 0.729)/0.2 = 3.01，误差 0.01。(b) f″(1) = 6，(h/2)·f″ = 0.3，接近 0.31（差的 0.01 来自下一项 (h²/6)·f‴）；f‴ = 6，(h²/6)·f‴ = 0.01，和实际误差完全相同（x³ 的四阶以上导数为 0，所以没有更高阶的误差项）。
- **H6.** (a) 1e-7/0.5000001 ≈ 2e-7，正常（光滑函数可能还希望更小一点，但已经在"可以接受"的边界）。(b) 0.4/2.0 = 0.2，很可能是错的。(c) 2e-9/3e-9 ≈ 0.67，但两个梯度都在 1e-8 以下，应改看绝对误差 2e-9，很可能正常。(d) 0.0003/120.0003 ≈ 2.5e-6，在 1e-4～1e-7 之间：如果网络里有 relu 等折点可以接受，全是光滑函数时偏高，应该查一查（先确认用的是 float64）。
- **H7.** 每个 f 值的舍入误差约 ε|f| ≈ 1.2e-7 × 0.232 ≈ 2.8e-8；中心差分把差除以 2h = 2e-6，误差约 2.8e-8 / 2e-6 ≈ 1.4e-2（两次舍入误差可能相加，量级不变）；相对误差约 1.4e-2 / 0.562 ≈ 2.5e-2。表里 float32、h = 1e-6 的实测相对误差是 2.0e-2，量级一致。
- **H8.** (a) 6 个节点（a、b、c、d、e、L），3 个叶子。用 `**2` 时指数 2 是普通的数，不生成节点。(b) 例如 a → b → d → c → e → L，或 c → b → a → d → e → L；只要 d 在 a、b 之后，e 在 d、c 之后，L 在 e 之后即可。(c) 9 个：叶子 w1、x1、w2、x2、b（5 个），乘法 w1·x1、w2·x2（2 个），加法 (w1·x1 + w2·x2)、(… + b)（2 个）。如果像 `Neuron` 那样从 b 开始累加，加法节点是 (b + w1·x1) 和 (… + w2·x2)，个数相同。

### 编程题提示

- **2.1** 参考正文 2.7.3 节。局部导数是"对方的值"：`other.data`、`self.data`。
- **2.2** 幂：`k * self.data ** (k - 1)`；k = 0 时导数是 0，要单独处理，否则 x = 0 时会算 0 ** −1 而报错。tanh：前向时把 `t = math.tanh(self.data)` 存下来，反向用 `1 - t * t`。relu：`(1.0 if self.data > 0 else 0.0)`。每个都要乘 `out.grad`，都要用 `+=`。
- **2.3** 参考正文 2.7.5 节。容易漏的两点：`visited` 集合（否则被多次使用的节点会在 topo 里出现多次，梯度被重复传递）；中间节点清零但叶子不清零（测试 `test_backward_twice_accumulates_only_leaves` 检查）。
- **2.4** 参考正文 2.8.8 节。先 `xs = [float(x) for x in xs]` 复制一份；每一维试完要还原。
- **2.5** `Layer.__call__` 返回 `[n(x) for n in self.neurons]`；`MLP` 最后一层用 `"none"`；`parameters()` 用列表推导把所有神经元的参数串起来。
- **2.6** `sigmoid = (1 + (x * 0.5).tanh()) * 0.5`。节点数：4 个运算节点（乘 0.5、tanh、加 1、乘 0.5），加上 3 个常数叶子：两个 0.5 各自生成一个 `Value(0.5)`（数值相同也不会自动共用一个节点），1 生成一个 `Value(1)`。一次 sigmoid 新建 7 个节点，连同输入 x 一共 8 个，用 `graph_nodes` 数一数核对。
- **2.7** exp 的导数是 `out.data`（e^x 本身），log 的导数是 `1 / self.data`。x = 1000 时 `math.exp` 会抛出 `OverflowError`。
- **2.8** 见题目里的提示。注意一个节点可能被压栈多次（从不同的下游节点到达），弹出时要检查是否已经在 `visited` 里。

### 调试题答案

- **D1.** 用 `=` 代替 `+=`。不报错；同一个变量被用了多次时梯度偏小（x·x 的梯度变成 x 而不是 2x）。改成 `+=`。测试：`x = Value(3.0); (x * x).backward(); assert x.grad == 6`。
- **D2.** 按拓扑正序调用 `_backward`，应该用 `reversed(topo)`。不报错；梯度是 0 或不完整（2.7.6 节）。另外也漏了"中间节点清零"，在同一张图上第二次 backward 时会出错。测试：L = (a·b + c)² 的三个梯度应为 −24、16、8。
- **D3.** tanh 的局部导数应该是 1 − tanh²(x)，代码用了 1 − x²。不报错，梯度错（x 较大时甚至变号）。改成用前向算出的 t：`(1 - t * t)`。测试：数值梯度检查（2.8.6 节实测这个 bug 的最大相对误差 7.3e-01）；或直接检查 `Value(0.8).tanh()` 反向后的梯度等于 1 − tanh²(0.8)。
- **D4.** 没有清零梯度。不报错；梯度不断累加，训练曲线异常（2.9.6 节那次实验是先快后发散）。在 `loss.backward()` 之前加 `zero_grad(m.parameters())`。测试：参数不变时对同一批数据连续两次前向和反向，检查 `.grad` 是否相同（不清零时第二次正好翻倍）。梯度范数的走向只能作旁证：历史梯度可以相互抵消，范数不一定单调增大。
- **D5.** `p = p - 0.5 * p.grad` 只是让循环变量 p 指向一个新的 Value，模型的参数没有变（而且还新建了计算图节点）。不报错；损失不变。改成 `p.data -= 0.5 * p.grad`。测试：更新前后比较某个参数的 `.data`。
- **D6.** 每一维试完没有把 `xs[i]` 还原成 `old`，也没有先复制 `xs`。不报错；第 i 维之后的所有导数都是在一个偏移了 −h 的点上算的（误差和 h 成正比，结果可能"看起来差不多对"），而且调用者传进来的列表被改了。改成先复制、试完还原。测试：调用前后比较 `xs`；对一个已知导数的函数检查精度（`test_numerical_grad_and_rel_error`）。
- **D7.** 前向放在了 `torch.no_grad()` 里，logits 没有 `grad_fn`，loss 也没有。报错 `element 0 of tensors does not require grad and does not have a grad_fn`（第 7 部分演示过同一个错误）。训练时前向不能放进 no_grad；`model.eval()` 也应换成 `model.train()`（第 5 章讲 dropout 时会解释两者的区别）。测试：`assert loss.requires_grad`。
