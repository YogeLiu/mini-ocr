# 第一部分闭卷自测：深度学习基础

**怎样做：** 闭卷，不看书、不看代码、不问人。手写推导和计算，可以用科学计算器。保留到小数点后四位。

**通过线：** 待校准。第一次做完后，根据自己的结果确定，并写进复盘。每个小问记 1 分，满分 52 分。答错的小问回到对应小节重读。

**答案：** 做完再对照。答案不在学习者版里，由助教批改。

**第 1 题（第 1 章 1.2、1.3 节）广播和它的内存代价**

`A` 形状 (N, D)，`B` 形状 (M, D)，N = 2000，M = 500，D = 128，dtype 是 float32。

(1) 要算所有 a、b 对的差，`A`、`B` 分别该怎样插 `None`？差 `diff` 是什么形状？

(2) `diff` 占多少字节？换算成 MiB。

(3) 改用 ‖a − b‖² = ‖a‖² − 2a·b + ‖b‖²。不计 A、B 本身，额外的元素数量级是多少？折合多少 MiB？

(4) 判断下面两对形状能否广播，能的写结果，不能的写第几维冲突：(3, 1, 5) 和 (4, 1)；(2, 3) 和 (3, 2)。

**第 2 题（第 1 章 1.5、1.6 节）stride**

**第 3 题（第 2 章 2.4、2.5 节）同一个变量走两条路**

(2) 从 L 往回走，算出 ∂L/∂v、∂L/∂u、∂L/∂b、∂L/∂a。

(4) 自动求导引擎的 `_backward` 里，为什么累加梯度要写 `+=`？写成 `=` 时，这道题的 ∂L/∂a 会算成多少？（先处理 a 的哪条边，分两种情况答。）

**第 13 题（第 0 章 0.10.1 节，第 5 章 5.1、5.8 节）评测协议**

判断下面每种做法是否违反协议。违反的写应该怎样补救。

(1) 在 val 上比较三个学习率，选出最好的。

(2) 选型冻结后，预先登记的两个候选各评一次 test，只报告数字和区间。

(5) 16 个候选都评 test，把 test 上最高的分数写进报告。这个分数为什么偏高？选择集变小、候选变多，偏高得更多还是更少？
