## 2. 实验一：组内越像，泄漏越严重吗

**问题：** `make_dataset` 的 `jitter` 参数控制同一来源内部的抖动大小。`jitter=0` 时，同一来源的图只差噪声；`jitter=3` 时，组内的旋转可以差 ±6°、平移 ±2 像素。随机划分造成的虚高（验证 − 全新来源）会怎样随 `jitter` 变化？

**预测：** 写下 `jitter = 0、1、3` 三种情况下你预测的虚高，以及理由。

**运行：** 在 Python 里：

```python
import book.part1_foundations.ch05_generalization.tour as T
from miniocr.data.symbols import make_dataset, random_split

for j in (0.0, 1.0, 3.0):
    d = make_dataset(100, 4, seed=0, jitter=j)
    ext = make_dataset(10, 8, seed=123, group_offset=10**6, jitter=j)
    X, y = T.tensors(d); Xe, ye = T.tensors(ext)
    tr, va = random_split(len(X), (0.8, 0.2), seed=0)
    net, _ = T.fit(X[tr], y[tr], steps=3000, seed=0)
    print(j, T.evaluate(net, X[va], y[va])[1], T.evaluate(net, Xe, ye)[1])
```

想更可靠，就每个 `jitter` 跑 3 个种子（`random_split` 和 `fit` 都换种子）。

**观察：** 验证准确率、全新来源准确率、二者的差。

**思考：** 真实数据里，"同一篇论文截了两次的公式"对应多大的 `jitter`？"同一个人手写的两个 α"呢？

## 3. 实验二：泄漏的验证集会不会让你选错方案

**问题：** 正文 5.3.6 节提出一个待验证的推论：用泄漏的验证集比较两个方案，可能得出和诚实验证集相反的结论。我们来检验它。

**预测：** 在**随机划分**和**分组划分**的验证集上，分别比较"无增广"和"有增广"（`aug=True`）。两种验证集给出的结论（谁更好）会一致吗？

**运行：** 用 `T.fit(..., aug=False)` 和 `T.fit(..., aug=True)`，3000 步，每种组合 3 个种子，在各自的验证集上评测。再把所有模型都在全新来源上评一次，作为"真相"。

**观察：** 填一张 2 × 2 的表（划分方式 × 是否增广），每格写 3 个种子的平均和范围；再加一列全新来源的分数。

**记录：** 两种验证集的结论是否一致？哪一种和"真相"一致？如果都一致，这个推论在本设置下就没有得到支持，如实写下来。这不是失败，这是一个结果。

## 4. 实验三：划分本身的随机性

**问题：** 正文 5.8.1 节发现，同一批模型在验证集和测试集上的平均分差了 3.8 个百分点（本项目观察，第 7 部分）。这是因为两份留出集抽到的来源不同。如果固定模型的种子，只换**划分的种子**，验证准确率会变多少？

**预测：** 和第 6 部分"换模型种子"的标准差（约 0.011）相比，换划分种子的标准差是更大、更小，还是差不多？

**运行：** 固定 `fit(..., seed=0)`，把 `group_split(d["groups"], (0.8, 0.1, 0.1), seed=s)` 的 `s` 从 0 换到 7，每次训练 1500 步，记录验证准确率。

**观察：** 8 个验证准确率的平均、标准差和极差。

**思考：** 如果划分带来的波动比种子带来的还大，你在报告里应当怎样描述结果？（提示：报告里要写清"划分固定为种子几"，比较方案时必须用同一个划分。）

## 5. 实验四：不用卷积行不行

**问题：** 正文的分类器用了卷积。换成一个两层 MLP（`32·32 → 256 → 24`，中间加 ReLU），在分组划分下表现如何？

**预测：** MLP 的参数量是多少（自己算）？它的验证准确率会接近 CNN（第 5 部分 D 的 0.803），还是接近线性模型（A2 的 0.360）？

**运行：** 在 `tour.py` 里仿照 `Linear` 写一个 `MLP` 类，在 `fit` 里加一个 `model="mlp"` 的分支，用完整训练集训练 3000 步，`eval_every=100`。

**观察：** 学习曲线的形状（欠拟合还是过拟合），最终验证准确率，以及参数量。

**思考：** 加上在线增广后，MLP 和 CNN 各提升了多少？谁受益更多？第 28 章会解释原因，现在先记下你的猜测。

## 6. 实验五：早停的依据

**问题：** 正文 5.6.4 节看到，配置 D 的验证 loss 在第 500 步最低，验证准确率却一直涨到 0.803 以上（本项目观察，第 5 部分）。按验证 loss 早停和按验证准确率早停，最终在测试集上差多少？

**预测：** 写下你预测的差距。

**运行：** 改写 `fit`：每 100 步评一次验证集，分别记下"验证 loss 最低时"和"验证准确率最高时"的模型参数（用 `copy.deepcopy(net.state_dict())`）。训练结束后，把这两个模型**各在测试集上评一次**。

**观察：** 两个模型的停止步数、验证准确率和测试准确率。

**注意协议：** 这里用测试集只是为了**报告**两种早停规则的结果，选择规则时不能依据它。如果你据此决定"以后都按准确率早停"，那这个决定就是依据测试集做出的。正确的做法是：在验证集上比较，或者再划出一份数据专门用来比较早停规则。在记录表里写明你是怎么处理的。

## 7. 故障演练：先增广、再按样本随机划分

**场景：** 你的同学手里只有每类 25 个来源、每个来源 1 张图的"原图"。他觉得数据太少，于是先把每张原图用 `augment` 做 8 种随机增广，得到 8 倍的数据，然后**随机**按 8:2 划分训练集和验证集。训练出来的验证准确率接近 100%，他很高兴。

**请按下面的步骤排查**，每一步写下你看到了什么：

1. 用 `make_dataset(25, 1, seed=0)` 生成原图，自己写一段代码，对每张原图用不同的 `scale`、`angle`、`shift` 做 8 次增广（注意：这些增广版本应该共享原图的组编号）。
2. 按同学的做法随机划分、训练，记下验证准确率。
3. 用 `cross_duplicates` 或 `nearest_pixel_distance` 检查验证集里有多少样本在训练集有近重复。
4. 改成先按原图做 `group_split`，再只在训练集内部增广，重新训练，记下验证准确率。
5. 用全新来源的数据评一次两个模型，看哪个验证分数更诚实。

**要总结的教训：** 增广出来的样本和原图是同一组，不能拆到不同集合。先生成样本再按来源分组划分也可以，本章就是这样做的。用增广扩充训练数据时，最稳妥的做法是先按原图或来源划分，再只在训练集内部增广；验证集和测试集一般不增广，或者只做和上线时一致的预处理（正文 5.10 节）。
