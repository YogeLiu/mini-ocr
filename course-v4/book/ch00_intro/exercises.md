## 答案与提示

### 概念题要点

- **C1.** 输入一张公式图片，输出一段 LaTeX。难点：二维结构（上下标、分式、矩阵要翻译成一维符号）；形近符号（1/l、α/a、积/枳）；长序列（一个花括号错，后面结构全乱）；同一公式有多种正确写法。
- **C2.** `x^2` 与 `x^{2}`；`\dfrac{1}{2}` 与 `\frac12`；`\le` 与 `\leq`；`\left(…\right)` 与 `(…)`。只差一个字符而含义不同：`x^{2}` 与 `x_{2}`。
- **C3.** 太松：把不等价的写法合并，错的被判对，分数偏高；太紧：没合并等价的写法，对的被判错，分数偏低。太紧的问题会在错例表里露出来（看到"明明是对的"），太松的错误不会出现在错例表里，永远发现不了。
- **C4.** 我们评的是"有没有照着图写对"，不是"数学上是否相等"。图上写 `a+b`，输出 `b+a` 就是识别错了。
- **C5.** 花括号有时是可选的写法（`x^{2}`），有时决定结构（`x^{ab}` 和 `x^ab` 不同，后者只有 a 是上标）。本章先解析成语法树，按"原子"理解 `^` 的参数，再统一写回，所以只去掉多余的花括号。
- **C6.** 长处：简单好解释、严格。盲区：只有 0 和 1，分不出轻重。场景：长公式原来错一大片，改进后只错一个符号，EM 仍是 0。
- **C7.** 参考答案固定，各模型分母相同才可比。用预测长度时，输出越长分母越大，复读、胡乱生成的模型被高估。
- **C8.** 语料级 = Σ距离 / Σ参考长度，长样本权重大，含义是"每个参考单位平均改几次"；逐样本平均每个样本权重相同，短样本的错误被放大，含义是"平均每个样本错了百分之几"。CER 惯例是语料级。
- **C9.** 长命令多的公式差别最大（`\alpha`、`\begin{pmatrix}` 等）。按字符依赖规范化、和别人更容易对比；按 token 更接近"错了几个符号"，但依赖分词规则。两者各有偏差，OCR 主任务面板都报并写清版本；第三部分的文本后纠错面板和第 31–35 章的 OCR 精简版只报按字符的 CER（正文 0.9.3 节）。
- **C10.** 它专门抓"输出不合法、排版不出来"这类故障，这是编辑距离看不出来的（`x^{2` 距离只有 1）。但它不看参考答案，永远输出 `x` 的模型可编译率是 100%，所以必须和别的指标一起报。
- **C11.** 假阴性：合法 LaTeX 被判不能解析（`\frac12`、`\le`、`\tfrac`、`\begin{pmatrix}`）；假阳性：mathtext 接受而 LaTeX 会报错的写法（本章没有系统测过，待验证）。选型至少测：支持的命令和环境（矩阵、中文）、速度、跨机器的一致性，以及和真正 LaTeX 的一致程度。
- **C12.** 排出来一样但写法不同、规范化规则没覆盖的情况，例如 P7 撇号。diff 对整体错位极敏感：一个括号变高，后面所有符号都挪了位置（P5 的 diff 0.919 比真错的 P8 0.617 还高）；而加号变减号只差一小段（P12 只有 0.018）。
- **C13.** 解析不了不代表不一致，P3、P4 其实是对的。记作不一致会让一致率偏低（演示集上从 0.2500 变成 0.1875）。应分开报告"一致率（在能判断的样本上）"和"能判断的样本数"。
- **C14.** 验证集反复用来做决定；选型冻结后，预先登记的候选可在测试集上各评一次，只报数字（和置信区间），不据此改任何设置。开发期间不看测试集错例，最终报告定稿后才可解封做错例分析（正文 0.10.1 节）。反复"看测试集—改设置"等于在测试集上调参，结果系统性偏乐观。如果已经发生，在报告里写明，并补一份新的留出测试集。
- **C15.** 规范化结果相同的样本（同一公式的不同图片、规范化器能统一的不同写法）会落在同一个集合，防止模型"背下"测试公式造成的泄漏。它不能保证同一公式的**所有**写法都在一起：规范化器没覆盖的等价写法会跨集合，例如 P7 的 `f'(x)` 进 test、`f^{\prime}(x)` 进 validation（第 10 部分）。所以冻结划分前要补上等价写法和图片重复检查，给每组明确的分组编号，按分组编号划分。它也不能防止"几乎相同"的公式（只差一个下标）跨集合，需要另做近重复检查（R1、第 22 章）。
- **C16.** 它们不是模型的错误，而是评测本身的问题。写法差异：根据验证集错例考虑给规范化器加规则（升级版本号、用新版重算所有候选，最终测试另行安排；已冻结的结果不改，不和新版数字混比，见正文 0.10.5 节）；标注错误：在验证集里修正参考答案并记录，不在测试集里找。

### 手算题答案

- **H1.** (a) `\sqrt [ 3 ] { x ^ 2 + 1 }`，11 个。(b) `\sqrt [ 3 ] { x ^ { 2 } + 1 }`，13 个。
- **H2.** (a) `[ \frac { a } { b } ] _ { n } ^ { 2 }`：`\left`、`\right` 删掉，`\dfrac` 换成 `\frac`，上下标的底是右方括号，先下标后上标。(b) `x ^ { a } b`。(c) `x ^ { a b }`。(b)、(c) 不相等：(b) 里只有 a 在上标里，(c) 里 a、b 都在上标里，含义不同。
- **H3.** (a)

  ```
         ε   x   2   }
     ε   0   1   2   3
     x   1   0   1   2
     ^   2   1   1   2
     {   3   2   2   2
     2   4   3   2   3
     }   5   4   3   2
  ```

  (b) 编辑距离 2。一组最少操作：`x` 相同；删除 `^`；删除 `{`；`2` 相同；`}` 相同。
- **H4.** 按 token：`[\alpha, ^, {, 2, }]` 对 `[a, ^, {, 2, }]`，距离 1。按字符：`\beta` 对 `\theta`，距离 2（插入 t、把 b 换成 h）。按 token 的结果更符合"认错了一个符号"。注意按字符时，`\beta` → `\theta` 只要 2 步，`\alpha` → `a` 却要 5 步，同样是认错一个符号，按字符的代价取决于命令名长得像不像。
- **H5.** (a) `a + b`：3 个 token、3 个字符；`\frac { x } { y }`：7 个 token、11 个字符；`S _ { \text { 三 角 形 } }`：10 个 token、14 个字符。(b) 编辑距离分别是 1、0、1（按 token 和按字符都一样）。CER_token = 2 / 20 = 0.1000；CER = 2 / 28 = 0.0714。(c) 逐样本：1/3、0、1/10，平均 = (0.3333 + 0 + 0.1000) / 3 = 0.1444，比语料级的 0.1000 高，因为短样本 `a+b` 的一次错误被放大了。
- **H6.** 参考规范化后 `a ^ { 2 }` 有 5 个 token，预测 15 个，要删 10 个，单样本错误率 10 / 5 = 2.0000。分子（要改的次数）没有上限，分母是参考长度，预测比参考长得多时就会大于 1。
- **H7.** (a) A 裁剪后是 3 × 3 的 `[[#,#,.],[.,#,.],[.,#,#]]`；B 的墨迹在第 1–3 行、第 1–3 列，裁剪后完全相同。diff = 0.0。(b) C 和 E 裁剪后都是 1 × 3 的 `[# # #]`，diff = 0.0。(c) F 裁剪后宽 5 `[# . . . #]`，G 裁剪后宽 4 `[# . . #]`，补齐成 `[# . . # .]`；异或在第 3、4 列，2 个；或在第 0、3、4 列，3 个；diff = 2/3 = 0.6667。
  (b) 说明裁剪丢掉了"整体在画布上的绝对位置"：一横在上和一横在下被看成一样。比较整个公式时这不要紧，因为公式内部各符号的**相对**位置仍然保留（上标仍然比底高）；要紧的是不要把公式的不同部分分开裁剪再比较。
- **H8.** 前两张的规范化参考答案相同，哈希相同，必定在同一个集合。第 2 张写成 `x^2` 也一样，规范化后都是 `x ^ { 2 }`。
