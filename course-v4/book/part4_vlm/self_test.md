# 第四部分闭卷自测：视觉与 VLM

**怎样做：** 闭卷，不看书、不看代码、不问人。手写推导和计算，可以用科学计算器。保留到小数点后四位。1 MiB = 2²⁰ 字节，1 GiB = 2³⁰ 字节。

**通过线：** 待校准。第一次做完后，根据自己的结果确定，并写进复盘。每个小问记 1 分，满分 56 分。答错的小问回到对应小节重读。

**答案：** 做完再对照。答案不在学习者版里，由助教批改。
