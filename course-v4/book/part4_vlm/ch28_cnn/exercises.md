## 答案与提示

**28.1** 局部连接：每个输出只看一小块邻域，不用给 1024 个像素都配权重，也不容易记住"某个像素位置 → 某一类"。权重共享：同一个核在所有位置使用，图案换了位置也能被同一组权重认出来。它省的是参数，计算没省：核在每个位置都要算一遍。

**28.2** 核是学出来的。如果最优的核是 K，互相关会学到 K 的翻转版，两者表达能力完全一样，损失和梯度也一一对应。

**28.3** 权重 (F, C, k, k)，偏置 (F,)，参数量 F·C·k² + F。一个输出通道代表一种特征，它应该能综合所有输入通道的信息（比如 RGB 三个通道一起才能判断颜色边缘），所以要在每个输入通道上各有一片权重，结果相加。

**28.4** 同一组权重被批里每张图都用了一次，所以 dW 是 N 份贡献之和。同一个输入像素被 F 个核都读了一次，所以 dX 是 F 份贡献之和。

**28.5** 2×2、步长 2 时窗口不重叠，每个输入像素只被写一次，`=` 和 `+=` 结果相同，梯度检查发现不了。3×3、步长 1 时窗口重叠，`=` 会用最后一个窗口的值覆盖前面的，重叠处梯度偏小，梯度检查立刻失败。所以测试必须包含窗口重叠的几何。

**28.6** 理论感受野：这块之外的像素改了也不影响输出。有效感受野：这块里实际影响大的区域，通常集中在中心，比理论值小。10×10 是最后一张特征图上单个位置的感受野；后面的 Flatten + 全连接层把 8×8 个位置全连起来，分类输出依赖全部 32×32 像素。

**28.7** 不矛盾。整图 MSE 被大片白纸平均掉了；前景指标只看笔画像素。OCR 关心的是笔画，所以要看前景指标，并最终看识别率。

**28.8** 最大池化保住了"块里有墨迹"，但丢了"墨迹在块里的哪儿、有几条"。例如很小字号的 `=`，两条横线中间只隔一行空白时，空白那一行会被相邻的墨迹"吃掉"（纵向截面 `[1, 0, 1, 0]` 经 2×2 最大池化得 `[1, 1]`，两条线来自不同窗口），取最大后变成一条粗线，和 `-` 分不开；上下标的小圆点也会和旁边的笔画并成一团。

**28.9** 训练用当前批的均值和有偏方差，同时更新 running 统计；推理用 running_mean、running_var。推理时如果用当前批，同一张图的结果会随同批其他图变化，批大小为 1 时统计量完全由这一张图决定，结果不可复现。

**28.10** 批依赖：语言模型的一条样本不应受同批其他样本影响，时间维上的统计还可能偷看未来（第 9 章 9.3.6 节）。批大小：大模型训练每卡的批往往很小，BN 的统计量噪声大；LayerNorm 只看单个样本，和批大小无关，训练与推理行为一致。

**28.11** 不矛盾。两个结果测的是不同条件：清晰图上，CNN 的局部特征更有效；模糊图上，它依赖的细节先被抹掉。提醒：模型选择要在接近部署条件的数据上评；小符号的识别不能只看清晰图上的总体准确率。

**28.12** 证明了：在这份受控合成数据、这个配置下，CNN 比 MLP 高约 13 个百分点；三个种子一致；测试区间不重叠。没证明：CNN 在所有任务上都更好；参数量不完全相等、计算量相差更大，不是严格的等量对照；结论不能直接搬到真实公式 OCR；下采样结论只适用于在清晰图上训练、无增广的设定。

**28.13** (a) 24；(b) ⌊27/2⌋ + 1 = 14；(c) ⌊4/2⌋ + 1 = 3；(d) ⌊55/2⌋ + 1 = 28，28 个窗口覆盖第 0–55 行，第 56 行（最后一行）被扔掉；(e) 有效核 2·2 + 1 = 5，输出 5；(f) 14。(f) 就是"切成 16×16 的不重叠 patch"，224 的图得到 14×14 个 patch，正是下一章 ViT 的 patch 嵌入。（全部为数学结论，可用 `output_size` 核对。）

**28.14** Y[0,0] = 1·1 + 1·(−1) + 1 = 1；Y[0,1] = 0·1 + 0·(−1) + 1 = 1；Y[1,0] = 3·1 + 2·(−1) + 1 = 2；Y[1,1] = 1·1 + 1·(−1) + 1 = 1。Y = `[[1, 1], [2, 1]]`。

**28.15** db = 1 + 1 + 0 + 2 = 4。dW[p, q] = Σ dY[i, j]·X[i+p, j+q]：dW = `[[3, 2], [8, 3]]`（例如 dW[1,0] = 1·3 + 1·1 + 0·0 + 2·2 = 8）。dX：把 1·W 撒到左上，1·W 撒到右上，0·W 撒到左下，2·W 撒到右下，相加得

```text
1  1  0
0  1 -1
0  0 -2
```

dX[1,1] 在四个窗口里：(0,0) 窗口系数 W[1,1] = −1，贡献 1·(−1)；(0,1) 窗口系数 W[1,0] = 0，贡献 0；(1,0) 窗口系数 W[0,1] = 0，贡献 0；(1,1) 窗口系数 W[0,0] = 1，贡献 2·1。合计 −1 + 0 + 0 + 2 = 1。（数学结论；`conv_backward` CPU 复跑一致。）

**28.16** (a) 3 → 5 → 7，跳距 1。(b) 第一层 r = 3、j = 2；第二层 r = 3 + 2·2 = 7、j = 4；第三层 r = 7 + 2·4 = 15、j = 4。(b) 的前两层带步长，跳距增大，后面每层的 (k − 1)·j 都按放大后的跳距累加。

**28.17** (a) 四个值 0, 2, 2, 4，μ = 2，σ² = (4 + 0 + 0 + 4)/4 = 2，输出 [−1.414, 0]、[0, 1.414]。(b) running_mean = 0.1·2 = 0.2；无偏方差 8/3 ≈ 2.667，running_var = 0.9 + 0.1·2.667 ≈ 1.167。(c) 图 0：μ = 1、σ² = 1，输出 [−1, 1]；图 1：μ = 3、σ² = 1，输出 [−1, 1]。（数学结论；`ManualBatchNorm2d` CPU 复跑一致。）

**28.18** (a) 1/2³ = 0.125。(b) 落在同一个块里：1.0；跨边界：两边各 0.5。做 2 次（相当于 4×4 块平均）：两行落在同一个 4×4 块的行范围内时得 2·4/16 = 0.5（例如第 4、5 行，或第 5、6 行）；跨在 4×4 块边界上时（例如第 3、4 行）两边各 0.25。可用 `F.avg_pool2d` 复跑核对。结论：线越细、下采样越多，结果越依赖线落在哪里。

**28.19** (a) 24·48·9 + 48 = 10,416；(b) 1024·72 + 72 = 73,800；(c) 73,752 / 84,408 ≈ 87.4%。和第 5 章一样，绝大多数参数在最后的全连接层。

**练习 28.5** 提示：记 m = N·H·W，σ = √(σ² + ε)，dx̂ = dY·γ。对每个通道，

```text
dX = (1/σ) · ( dx̂ − mean(dx̂) − x̂ · mean(dx̂ · x̂) )
```

两个 mean 都是在该通道的 (N, H, W) 上求。直觉：减去 mean(dx̂) 是因为均值依赖每个输入；减去 x̂·mean(dx̂·x̂) 是因为方差依赖每个输入。

**28.20** 前三组都可能失败：(1, 0, 2×3) 和 (1, 1, 3×3) 窗口重叠；(2, 1, 2×3) 宽度方向核宽 3、步长 2，相邻窗口重叠一列。(3, 0, 1×1) 窗口不重叠，会通过。dw 和 db 用的是各自的 `+=`，不受影响，所以失败只会出现在 dx 的对拍上。

**28.21** padding = 0 时 `0:-0` 等于 `0:0`，返回形状为 0 的空数组。之后和期望形状比较时报形状不匹配，或者 `assert_allclose` 报 shape 错误。改成 `padding:padding+H`。

**28.22** 把 `jump *= stride` 写在了 `field += (effective - 1) * jump` 前面，池化层的扩张用了更新后的跳距：3 → 5 → 9 → 13。

**28.23** `no_grad` 只关梯度，不切换模式；BN 仍在训练模式，用当前批的统计，所以批组成不同结果不同。副作用：running_mean、running_var 被验证数据持续改写。修复：推理前 `model.eval()`。

**28.24** 先查是不是用了 float32。float32 下中心差分的舍入误差就可能到 1e-3 量级。改成 float64 再看；同时检查 ε 是否过大或过小（第 2 章 2.8 节），以及接近 0 的梯度是否让相对误差虚高。

**28.25** 整图 MSE 被白纸平均掉了，0.001 的差别可能对应大量细笔画的消失。应该补前景对比度、前景阈值召回（28.7.3 节），最好再测识别率。

**28.26** 本章证据是：在清晰图上训练的 CNN 对 4 倍下采样很敏感，甚至不如 MLP；这说明训练与部署条件不一致和信息丢失是重要因素；但本章只比较了固定宽度的 CNN 和 MLP，没有做更大 CNN 的容量消融，所以不能排除模型容量的影响（待验证）。先做两件事：检查部署链路能不能不缩小（或缩小得少一些）；如果必须缩小，在训练时加入同样的下采样增广（练习 28.6），在验证集上比较。

**28.27** 补过 padding 的长度 H + 2p；窗口起点 0, s, 2s, …，第 m 个起点要满足 m·s + k ≤ H + 2p，m 从 0 到 ⌊(H + 2p − k)/s⌋，共 ⌊(H + 2p − k)/s⌋ + 1 个。向下取整表示末尾放不下一个完整窗口的部分被丢弃。

**28.28** 见正文 28.2.3 节和 28.5.2 节。db 对 n、i、j 求和（偏置在每个样本、每个位置都用了）；dW 对 n、i、j 求和（同一个核在每个样本、每个位置都用了）；dX 对 f 和所有覆盖该像素的 (i, j) 求和（每个核、每个覆盖它的窗口都读了它）。

**28.29** r_l = r_{l−1} + (k_l − 1)·j_{l−1}，j_l = j_{l−1}·s_l。列表见正文 28.6.4 节：32/3/1 → 16/4/2 → 16/8/2 → 8/10/4（输出边长/感受野/跳距）。

**28.30** 见正文 28.8.2 节公式和 28.8.4 节表格。要点：BN 每个通道在 (N, H, W) 上统计，训练用批统计并更新 running（momentum 为新值权重、running_var 无偏），推理用 running；LN 每个样本在 (C, H, W) 上统计，无批依赖、无状态、训练推理一致。
