## 答案与提示

**24.1** 状态：输入的 LaTeX（提示）加上已经生成的 token。动作：下一个 token。策略：语言模型 $\pi_\theta(y_t\mid x,y_{<t})$。回合：从提示开始生成一整条改正后的 LaTeX，直到 EOS 或长度上限。奖励：渲染比较得到的相似度，在回合末给一次，中间 token 没有单独的分数（24.1.2 节）。

**24.2** 一，采样是离散的，从 softmax 里抽出 token 这一步不可导；二，打分器（渲染、比较）是外部程序，没有梯度。即使奖励张量带梯度，它也不连向模型参数。策略梯度定理只对**概率**求导：$\nabla J=\mathbb E[R\nabla\log\pi]$，奖励只作为一个数乘在前面（24.2.3 节）。

**24.3** 不改期望：(a)(b)(e)(f)。(c) 有偏：$\mathbb E[(R_i-R_i)s]=0$，梯度恒为零。(d) 缩放：期望是 $\frac{B-1}{B}\nabla J$，方向对、长度变短（24.3.8 节）。(g) 有偏：基线依赖当前动作，24.3.3 节"把 $b$ 提出来"那一步不成立；例如 (g) 如果恰好等于 $r(a)$，梯度期望变成零。

**24.4** 不能。这个问题太简单，2000 步足够让三种方法都收敛。基线的作用是降低梯度方差，直接证据是固定策略下的方差测量（lab 第 2 部分：方差迹 0.0363 → 0.0120，本项目观察），或训练早期的跨种子标准差（第 50 步 0.0250 → 0.0127，本项目观察，24.3.7 节）。同时要检查期望没变。

**24.5** 不一定。k1 的单样本值可正可负，小批次均值为负很常见，尤其当真 KL 很小时（near 情形 k1 的单批标准差是真 KL 的 5 倍多，本项目观察）。k3 逐样本非负（$\log\rho\le\rho-1$），所以如果 k3 出现负数（超出浮点误差），一定是实现错了公式，例如没有按 $(\rho-1)-\log\rho$ 计算（漏项、符号写反）。注意：如果 log_ratio 不是同一个 token 的两个对数概率之差，KL 估计的含义就错了，但 k3 仍然非负，因为对任何有限实数 $z$ 都有 $e^z-1-z\ge0$——这类错误要靠精确枚举或对拍来抓，看符号抓不到。

**24.6** 只用 $\mathrm{clip}(r)A$ 时，越界区间是平的，梯度为零，于是"好动作的概率被压低（$A>0,r<0.8$）"和"坏动作的概率被抬高（$A<0,r>1.2$）"这两种走错方向的情况也拉不回来。取 $\min$ 后，这两种情况选中未裁剪的 $rA$，梯度照常。例：$A=-1$，$r=1.5$，$\min(-1.5,-1.2)=-1.5$，导数 −1（lab 第 4 部分）。$\min$ 让目标成为未裁剪目标的悲观下界。

**24.7** $\lambda=0$：$\hat A_t=\delta_t=r_t+\gamma V(s_{t+1})-V(s_t)$，方差小，但完全依赖 $V$ 的准确性，有偏。$\lambda=1$、$\gamma=1$：$\hat A_t=R-V(s_t)$，$V$ 只当基线，无偏，方差大。GRPO 用同一提示的多次采样的组内均值估计 $V(x)$，相当于"多次采样估基线"，不用学一个网络（24.4.4 节）。

**24.8** 区间说明：在这个受控任务的 test 提示上，按"首尾是 `$`"这个定义的成功率，有 95% 把握不低于 0.985。没说明的：模型有没有读提示、输出有没有内容。`$` 占比 0.9995（本项目观察）说明它几乎只输出 `$`。要说"学会了任务"，需要一个检查内容的指标（例如和标准答案的匹配），以及事先定义好的漏洞探针，并抽查原始输出。

**24.9** (a) $b=0$：$\hat g=2\times(e_2-\pi)=2\times[-0.25,0.75,-0.5]=[-0.5,1.5,-1]$。$b=2.75$：$\hat g=-0.75\times[-0.25,0.75,-0.5]=[0.1875,-0.5625,0.375]$。
(b) $b=0$：$\theta=[-0.05,0.15,\ln2-0.1]$，$\pi\approx[0.2425,0.2962,0.4613]$，$J\approx2.6802$。$b=2.75$：$\theta=[0.01875,-0.05625,\ln2+0.0375]$，$\pi\approx[0.2522,0.2339,0.5139]$，$J\approx2.7756$。
(c) 加基线的变好了（2.75 → 2.7756），无基线的变差了（→ 2.6802）。无基线时 $R=2>0$，第 2 个臂被推高，而它的概率是从最好的第 3 个臂那里"抢"来的（第 3 个臂 logit 降 0.1）。第 2 个臂低于平均 2.75，本该被压低（数学结论，CPU float64 复算）。

**24.10** $V(b)=\mathbb E[R^2\|s\|^2]-2b\,\mathbb E[R\|s\|^2]+b^2\,\mathbb E[\|s\|^2]-\|\nabla J\|^2=4.09375-2.8125\,b+0.625\,b^2-0.6171875$。$b=2$：$4.09375-5.625+2.5-0.6171875=0.3516$。四行：$b=0$ 3.4766；$b=2$ 0.3516；$b=2.25$ 0.3125；$b=2.75$ 0.4688。$V'(b)=-2.8125+1.25b=0$ 得 $b=2.25$（数学结论）。注意 $b=2$ 也比 $b=\mathbb E[R]=2.75$ 好。

**24.11** (a) $\bar R=\frac1BR_i+\frac1B\sum_{j\ne i}R_j$。$\mathbb E[R_is_i]=\nabla J$；$j\ne i$ 时 $R_j$ 与 $a_i$ 独立，$\mathbb E[R_js_i]=\mathbb E[R_j]\,\mathbb E[s_i]=0$。所以 $\mathbb E[(R_i-\bar R)s_i]=(1-\frac1B)\nabla J$。
(b) $0.75\times[-0.4375,-0.1875,0.625]=[-0.3281,-0.1406,0.4688]$（数学结论，精确枚举 81 种组合复核）。
(c) 用除自己以外的 $B-1$ 个样本的均值（leave-one-out），或者把整个梯度乘 $\frac{B}{B-1}$。

**24.12** (a) $0.5\ln\frac{0.5}{0.8}+0.5\ln\frac{0.5}{0.2}=0.5\times(-0.4700)+0.5\times0.9163=0.2231$。
