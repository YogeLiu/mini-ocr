## 答案与提示

### 概念题要点

**10.1** (a) 等变是"输出跟着输入一起换位置"：打乱后第 j 个位置的输出，等于原来被换到这里的那个 token 的输出。各位置的输出一般各不相同。(b) 因果 mask 让不同位置可见的 token 数不同，模型可以从中推出位置（例如均匀注意力给出 1/(t+1) 的权重），所以 NoPE GPT 有隐式位置信息。

**10.2** 表长之外没有定义（第 2 部分表长 4、请求位置 4 抛 `IndexError`；第 9 部分 learned 无法评测 128 的窗口）；每个位置单独学，不自动泛化到相邻位置；占参数（第 9 部分多 4096 个参数）。

**10.3** qₘ·kₙ = (xₘ + pₘ)W_q·(xₙ + pₙ)W_k 展开成内容×内容、内容×位置、位置×内容、位置×位置四项。中间两项把内容和绝对位置混在一起；最后一项中间夹着任意矩阵 W_q W_kᵀ，一般不再只依赖 n − m。

**10.4** 正弦编码把一个随位置转动的向量**加**到内容上；RoPE 把内容向量本身**转**过与位置成正比的角度。

**10.5** R(α)ᵀ = R(−α)，以及 R(α)R(β) = R(α + β)。

**10.6** 只有一个频率时，大约每 2π 个位置角度就近似重复一次（整数位置不会严格重合，但相隔约一圈的位置角度很接近），难以区分；而且所有平面提供的信息完全相同。几何级数的频率让快平面分辨近处、慢平面分辨远处，像钟上的秒针和时针。

**10.7** (a) 前后两半：(i, i + dh/2)；相邻两维：(2i, 2i + 1)。(b) 两者只差一个固定的维度置换，都满足相对位置性质、都保持长度；模型训练时用哪种都能学。(c) 两种约定各自都满足平移不变，所以测试都通过。要用独立写成的参考公式逐元素对拍（如 `test_matches_independent_2d_rotation`），或和官方实现对拍 logits。

**10.8** 位置只在打分 qₘ·kₙ 时见面，旋转角在这里抵消成 n − m；v 不参与打分，转了 v 没有东西和它抵消。输出 Σ wₘₙ R(nθ)vₙ 会随整体平移 s 多转 R(sθ)，依赖绝对位置（第 6 部分最大差 2.5195）。

**10.9** (a) θ₀ = 1 不变；其他 θᵢ 都变小，i 越大变得越多。(b) 好处：慢平面波长变长，长距离上角度不易重复，同样长度内转过的角度更小。代价：慢平面上相邻位置几乎转不出差别，分辨率下降。(c) base 只改变角度怎样随位置变化；模型能否利用更长的上文、质量能否保持，都要实测，不能由角度范围推出。

**10.10** 指旋转后点积的某个上界随距离增大而（平均地）变小，是一种趋势，不是对任意 q、k 的单调保证。曲线反弹不矛盾：全 1 向量的分数是振荡核，本来就不单调。

**10.11** 位置插值把所有位置除以 s，所有平面的角度都压缩 s 倍，最快平面相邻差从 1 弧度变成 1/s 弧度。增大 base 不动最快平面（θ₀ = 1），越慢的平面压缩得越多；按 NTK 公式取值时，最慢平面恰好压缩 s 倍。只有位置插值能让所有平面都回到原来的连续角度范围；增大 base 时最快平面完全不压缩，sL 处的相位仍超过训练边界，其他中间平面也只压缩了一部分。

**10.12** (a) 单层时最后位置的注意力输出是 Σⱼ wⱼ vⱼ，wⱼ = softmax(qₜ·kⱼ)，qₜ 只来自最后一个 token，kⱼ、vⱼ 只来自第 j 个 token 本身（没有位置信息）。求和与 softmax 都与 j 的排列顺序无关，所以打乱历史不改变输出；残差和前馈网络只作用在最后一个位置自己身上，也不引入顺序。(b) 单层 NoPE 只能利用"出现过哪些 token"和当前 token，两者打平很可能说明这个 1 层、600 步的模型还没学会利用顺序；而且只有一个种子。单层 RoPE 原则上已能区分历史的不同排列；要弄清差距为何很小，可以换种子、加深模型或延长训练再比较。

### 手算题答案

**10.1** (a) q₀k₀ + q₁k₁ = 5，q₁k₀ − q₀k₁ = 1 − 6 = −5，分数 = 5cos α − 5sin α，α = (n − m)π/2。
- (1, 2)：α = π/2，分数 = −5。
- (3, 4)：α = π/2，分数 = −5（距离相同，分数相同）。
- (2, 1)：α = −π/2，分数 = 5·0 − 5·(−1) = 5。
- (5, 5)：α = 0，分数 = 5（就是原始点积）。

(b) q 转 π/2：(2, 1) → (−1, 2)；k 转 π：(1, 3) → (−1, −3)；点积 = (−1)(−1) + 2·(−3) = 1 − 6 = −5。

**10.2** θᵢ = 100^(−i/4)：1.0000、0.3162、0.1000、0.0316；波长：6.2832、19.8692、62.8319、198.6918。第 0 对不变（θ₀ = 1）；第 3 对变化最大（从 0.001 变成 0.0316，波长从 6283.1853 缩到 198.6918）。

**10.3** (a) `inv` = 100^(−[0, 2]/4) = [1, 0.1]，形状 (2,)；cat 前 `ang` = [[0, 0], [1, 0.1]]，形状 (2, 2)；cat 后 [[0, 0, 0, 0], [1, 0.1, 1, 0.1]]，形状 (2, 4)。

### 编程题提示

**10.1** `torch.arange(0, dh, 2)` 的步长 2 就是指数里的"2i"；别忘了 `torch.cat([ang, ang], -1)`；`rotate_half` 用 `chunk(2, -1)`。先让 `test_rotate_half_values_and_square` 和 `test_frequency_exponent_and_repeated_halves` 通过，再看 `test_matches_independent_2d_rotation`。

**10.2** 用 `x[..., 0::2]`、`x[..., 1::2]` 取出每对的两维，算完用 `torch.stack((a', b'), -1).flatten(-2)` 交错拼回。角度表形状 (T, dh/2)，不要复制。第 3 步：分别对两种实现做"共同平移"测试，两者都通过，但二者直接比较不相等。

**10.3** 闭式和 `apply_rope` 版本应在 fp32 舍入内一致。base = 100 时慢平面转得更快，曲线下降更快。用 `scores.argmin()` 找最小值位置，再看它后面的值是否回升。

**10.4** 插值版本：`ang = (torch.arange(T) / scale)[:, None] * inv[None]`。NTK 检查：比较 `ntk_base**(-(dh-2)/dh)` 与 `base**(-(dh-2)/dh) / s`。

**10.5** 输出 yₘ' = R(−mθ) Σₙ wₘₙ R(nθ) vₙ = Σₙ wₘₙ R((n − m)θ) vₙ，wₘₙ 也只依赖 n − m，所以整体只依赖相对位置。实现时对注意力输出再调用一次 `apply_rope`，用 `-sin` 代替 `sin` 即可转回（cos 是偶函数，sin 是奇函数）。

**10.6** `pairs = max(1, int(dh//2 * partial))` = 2，`keep = arange(dh) % (dh//2) < pairs`，所以第 0、1、4、5 维旋转（平面 (0,4)、(1,5)），第 2、3、6、7 维保持不变，与测试一致。不旋转的平面 cos = 1、sin = 0，贡献就是原始的 qᵢ·kᵢ，与位置无关。

### 调试题答案

**10.1** (a) [x2, −x1] 等于 −rotate_half(x)，所以 x·cos + [x2, −x1]·sin = x·cos(−φ) + rotate_half(x)·sin(−φ)，每对转了 −φ，方向反了。(b) 共 9 项失败、22 项通过：`test_rotate_half_values_and_square`（在第一条数值断言处就失败）、`test_matches_independent_2d_rotation` 的 3 个参数、`test_hand_calculated_two_dimensional_example`、`test_conventions_equivalent_after_permutation`（和 tour 里独立写的相邻实现比较），以及 `test_oracle_rejects_common_mistakes` 的 3 个参数（检查正确实现与独立参考一致的那一句先失败）。`test_relative_position` 全部通过：q、k 都转 −φ，点积仍只依赖 n − m。"做两次等于取负"这条性质本身也成立：[x2, −x1] 再做一次得 [−x1, −x2] = −x；只是在测试里它排在数值断言之后，不会被执行到。所以只靠性质测试抓不住它，必须和具体数值对拍。

**10.2** (a) θᵢ = 10000^(−i/8)：1、0.3162、0.1、0.0316。(b) 10000^(−i/dh) = (10000^(1/2))^(−2i/dh)，等价于正确公式取 base = 100。(c) 平移测试发现不了（任何 base 都满足相对位置性质）；`test_frequency_exponent_and_repeated_halves` 会失败，和预训练模型对拍也会失败。

**10.3** `repeat_interleave` 把表排成 [θ₀, θ₀, θ₁, θ₁, θ₂, θ₂, θ₃, θ₃]。第 0 维拿到 θ₀，第 4 维拿到 θ₂。一对的两维用不同角度，算出来的 (a', b') 不是同一个旋转，长度一般会变，相对位置性质也被破坏。最快的检查：范数是否保持（`test_norm_preserved`），以及和独立参考对拍。

**10.4** 循环里没有传 `pos0`，每个新 token 都被当成位置 0，而缓存里的旧 k 带着真实位置，相对距离全错。改成：

```python
for i in range(20):
    logits, _ = model(nxt, caches=caches, pos0=P + i)
```

第一个新 token 的 `pos0` 是 P（历史长度）。确认方法：把 prompt 加上已生成的 token 整段做一次前向，和缓存版本最后一个位置的 logits 对拍，差值应在 fp32 舍入范围内（第 10 部分正确缓存的最大差为 2.98 × 10⁻⁸，本项目观察，CPU）。参考 `test_cache_position_offset`。

**10.5** bf16 只有 8 位有效二进制数字，频率量化、位置乘频率、三角函数都会产生很大的舍入。第 10 部分实测：位置 4096 角度最大误差 1.7896、cos 最大误差 0.7043；位置 8192 角度最大误差 3.5792、cos 最大误差 1.5714（本项目观察，CPU，第 10 部分）。位置信息被打乱。正确做法：角度、cos、sin 全在 fp32 里算，只在 `apply_rope` 里把 cos、sin 的值转成激活的 dtype。

**10.6** v 也被转了，输出依赖绝对位置：同一段内容放在不同位置，输出不同。检查：同一组 q、k、v，起始位置分别为 0 和 50，比较注意力输出。只转 q、k 时最大差约 1.341 × 10⁻⁷；转了 v 时为 2.5195（本项目观察，CPU，第 6 部分）。参考 `test_value_rotation_breaks_shift_invariance`。

**10.7** (a) 两种配对约定混用：权重里本该配对的维度 (i, i + dh/2) 被当成 (2i, 2i + 1) 旋转，频率也错位。第 5 部分里同一对 q、k 的分数从 22.1226 变成 37.6519（本项目观察，CPU，第 5 部分）。(b) 两种约定各自都满足平移不变。(c) 二选一，改一处就够：要么改用前后两半的旋转函数、权重不动；要么保留相邻实现，把每个头 q、k 投影矩阵的输出通道按置换 p 重排。两处都改又会错回去。关键是旋转函数的配对必须和权重训练时的配对一致。v 不旋转，v 的投影不用动。改完和官方实现对拍一小段 logits。
