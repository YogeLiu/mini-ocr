## 一、概念题

**概念 9.1** 用一句话说出注意力和前馈网络在块里各自负责什么。前馈网络在不同位置之间交换信息吗？所有位置用的是同一套前馈权重，还是每个位置一套？

**概念 9.5** 9.2.5 节把残差流比作一块"共享的白板"。用这个比喻回答：

## 答案与提示

### 概念题要点

**9.1** 注意力负责位置之间搬运信息（开会），前馈网络负责每个位置自己加工（回工位思考）。前馈网络不在位置之间交换信息；所有位置共用同一套权重。

**9.2** 有残差时只要 f(x) ≈ 0；没有残差时 f 必须恰好学成恒等函数。前者容易得多：把分支的输出压到 0 就行，测试 `test_block_zero_branches_are_identity` 正是利用这一点。

**9.3** 不能。若 f′(x) = −1，则 1 + f′(x) = 0，乘积为 0。实际中分支导数在初始化时通常较小，I + J 离 I 不远，所以直达通路一般畅通。残差给的是"默认畅通"，不是数学保证。

**9.4** (1) 下一层的 RMSNorm 把 RMS 约 0.1 的输入放大到 1，约放大 10 倍，同时放大反传的梯度；层里的线性层又缩小一些。两者相乘，在这个配置里净效果是每层放大一点。(2) 梯度是很多因子的乘积，大小完全由因子决定；换一种初始化或归一化，同一个无残差网络也可能变成梯度消失。(3) Adam 按每个参数梯度的历史大小做归一化，整体放大可以被抵消；麻烦在于底层参数的梯度要穿过很多个雅可比矩阵，对上面每层的状态都很敏感，方向很难有用。所以只看范数不够，还要看训练曲线。

**9.5** (1) 读 = 经过归一化送进子层，即 `Norm(x)`；写 = 子层输出加回去，即 `x + ...`。(2) 每层都往白板上加东西，而 Pre-Norm 从不归一化白板本身。32 层堆叠从第 1 层的 0.2521 涨到第 32 层的 1.9499（本项目观察，第 2 部分）。

**9.6**

| | LayerNorm | RMSNorm |
|---|---|---|
| 减均值 | 是 | 否 |
| 可学习参数 | γ、β | γ |
| 参数个数 | 2d | d |
| 输出均值一定为 0 | 是（γ = 1、β = 0 时） | 否（[1, 2, 3, 4] 的输出均值是 0.9129） |
| 输出 RMS（忽略 ε） | 1（γ = 1、β = 0 时） | 1（γ = 1 时） |

输出 RMS 为 1 只对仿射变换之前的归一化结果成立（还要排除输入全为常数或全 0 的情形）；可学习的 γ、β 会改变它，例如 γ 全为 2、β = 0 时两者的输出 RMS 都是 2。两者都只沿最后一维 d 统计，每个 token 只和自己比。

**9.7** LayerNorm 有平移不变性：第一步减均值，常数 c 被减掉了。RMSNorm 没有：它不减均值，加 c 会改变均方根和方向。手算 9.2 第 3 问给出了数字。

**9.8** bf16 只有 8 位二进制有效数字，在大数附近格点很稀（10000 附近间距 64），直接算会被舍入到格点上，第 3 部分的误差是 15.3689，转 fp32 后是 0.0002（本项目观察）。fp16 最大 65504，分量超过约 255.9 时平方溢出成 inf，输出悄悄变成全 0。转 fp32 找不回输入存成 bf16 时丢掉的信息，只能让后面的计算更准。

**9.9** Post-Norm：`x = Norm(x + Attn(x))`，`x = Norm(x + MLP(x))`。Pre-Norm：`x = x + Attn(Norm(x))`，`x = x + MLP(Norm(x))`，L 个块后再 `x = Norm(x)`。Pre-Norm 的归一化只在"读"的支路上，残差通路是纯加法；Post-Norm 在残差通路上放了 2L 个归一化，像 2L 个收费站，梯度每过一个都要乘一次归一化的雅可比矩阵。Pre-Norm 的白板越来越大，送进输出层之前要再归一化一次；Post-Norm 每层末尾都归一化过了，不需要。

**9.10** 不对。名字的意思是"注意力之后的那个归一化"，但它位于**前馈网络之前**，仍然是 Pre-Norm。

**9.11** (1) 只在 gate 支路上。(2) 负输入输出一个小的负数，不是 0；最小约 −0.28。(3) 两个线性函数相乘，特征之间可以相乘。

**9.12** (1) 块同时加了残差、两次归一化、前馈网络，还去掉了注意力投影的偏置，参数也多了 36,800 个；不是单变量实验。(2) 不能。配置不同：第 8 章上下文 64、每步 128 个目标、1200 步；本章上下文 16、每步 64 个目标、600 步，训练量只有四分之一。跨章比较不成立，同表内才能比较。

**9.13** (1) 无残差模型比"完全不看上文"的 unigram 还差一点，600 步里基本只学会了哪些 token 常见。(2) 是解释，正文标了"待验证"，没有直接测量输出和输入的相关性。(3) 不能。单个种子、600 步、一个学习率；训练更久、调小学习率、加预热能否走出平台都没有测。

**9.14** (1) 为了和取整后的 SwiGLU 参数量精确相等：2 × 64 × h = 3 × 64 × 192，h = 288 = 192 × 3/2。(2) 不能。单种子、600 步、一层，0.0098 可能是噪声，换种子的波动没有测。用 SwiGLU 主要是因为文献（Shazeer 2020）和主流模型的经验。

**9.15** 一是一个样本的输出会受同批其他样本影响（第 8 部分：另一条样本加 20，这条样本输出最多变 2.0000，本项目观察），这还让训练和推理不一致：默认 BatchNorm 训练时用批统计量，推理时用累计的运行均值和方差；二是如果统计量里混进了时间维，就会偷看未来。

**9.16** Encoder 是 3 × 3 全 1；Decoder 是下三角 `[[1,0,0],[1,1,0],[1,1,1]]`。Encoder-Decoder 的解码块有三个子层：因果自注意力 → 交叉注意力 → 前馈网络，各有自己的归一化和残差。交叉注意力的键和值来自已经全部给定的原文，Decoder 的每个位置看全部原文不涉及"未来"；只有原文有补齐时才需要补齐 mask。

**9.17** (1) Encoder-Decoder：编码器读图，解码器逐 token 写 LaTeX，写的时候用交叉注意力回看图片。(2) 第 31 章把图像编码成一串视觉 token，拼在文本前面当前缀，直接交给本章装好的 Decoder 块，不需要额外的交叉注意力子层。两种接法的对比在 31.3 节。

### 编程题提示

**9.1** 三步：`x.float()`；`xf.pow(2).mean(-1, keepdim=True)` 加 `eps` 后取 `torch.rsqrt`；乘 `self.weight` 后 `.to(x.dtype)`。去掉 `keepdim` 后，(1, 3, 4) 报错，(1, 4, 4) 静默算错。

**9.2** `self.down(F.silu(self.gate(x)) * self.up(x))`。d = 25 时 8 × 25/3 = 66.67，向上取整到 64 的倍数是 128。

**9.3** 两行：`x = x + self.drop(self.attn(self.n1(x), cos, sin, cache))`；`return x + self.drop(self.mlp(self.n2(x)))`。关键是第二行里的 `x` 已经是更新过的。

**9.4** 方差要用总体方差：`((x - mu) ** 2).mean(-1, keepdim=True)`，或 `x.var(-1, unbiased=False, keepdim=True)`。

**9.5** 分支置 0 后：`Block` 输出等于输入；`NoResidualBlock` 输出全 0；`PostNormBlock` 输出 `n2(n1(x))`，即输入被归一化两次，不等于输入。

**9.6** 解码块三行：`x = x + self.self_attn(self.n1(x))`（`causal=True`）；`x = x + self.cross(self.n2(x), kv=enc)`；`return x + self.mlp(self.n3(x))`。因果性只约束 Decoder 自己的位置；Encoder 的每个位置都已给定，Decoder 的每个位置都能看到，所以改 enc 的任何位置都会影响全部输出。第 31 章的前缀接法只要本章的两子层块，图像信息通过自注意力里的视觉 token 进入；交叉注意力接法要三子层。

### 调试题答案

**9.1** (1) 沿第 1 维（时间维）统计，均值和标准差里混进了未来位置的值，过去的输出"知道"了未来；生成时没有未来可看。(2) 改未来位置的输入，检查过去位置的输出是否**精确**不变。第 8 部分里沿时间维的最大变化是 2.4778（本项目观察）。(3) 只沿批量维不会混入未来，但会让同批样本互相影响（最大变化 2.0000，本项目观察）。正确写法永远是 `mean(-1)`。

**9.2** (1) `x.var` 默认用无偏估计，除以 d − 1：方差 5/3 = 1.6667；LayerNorm 要除以 d，方差 1.25。(2) 改成 `x.var(-1, unbiased=False, keepdim=True)`，或直接写 `((x - mu) ** 2).mean(-1, keepdim=True)`。

**9.3** (1) 均方的形状是 (1, 4)，它和 (1, 4, 4) 从最后一维对齐时恰好能广播：第 t 个位置的均方被用在了第 t 个**特征**上，而不是每个 token 除以自己的均方根，所以静默算错。（顺带一提：批量 2、T = d = 4 时，均方形状 (2, 4) 和 (2, 4, 4) 的倒数第二维 2 对 4 对不上，仍会报错；静默出错要求 T = d，并且批量为 1 或恰好也等于 T。）(2) 用 T ≠ d 的输入测试。

**9.4** (1) `self.n2(x)` 读的是块的原始输入，不是加过注意力的 `h`；前馈网络没看到注意力"开完会"的结果。应写 `self.n2(h)`。(2) `test_block_pre_norm_order_and_updated_second_residual`。它用 forward pre-hook 记下 `mlp` 实际收到的张量，和独立算出的 `norm(h)` 对比。(3) 形状完全正确，模型仍能学到东西，loss 照样下降，效果可能只是略差。

**9.5** (1) RMSNorm 里直接在 fp16 求平方：300² = 90000 超过 65504，均方变成 inf，1/√inf = 0，乘出来就是 0，不是 NaN。(2) 先转 fp32 再算，最后转回原 dtype。测试：构造大数值输入（如 [300, 400, 500, 600]），和 fp64 参考值对比。

**9.6** (1) 漏了最后的归一化（final norm）。(2) 打印输出层输入的 RMS。不加时 2 层是 0.3646，8 层是 0.9308，32 层是 1.9499；加上后都是 1.0000（本项目观察，第 8 部分）。(3) `GPT.norm`；GPT-2 里是 `ln_f`。

**9.7** (1) 第一位写成了 `silu(up) * gate`：up = 2，SiLU(2) × (−1) = −1.7616，再乘 W_down 得 [−1.7616, 3.5232]。第二位写成了 `silu(gate * up)`：gate × up = −2，SiLU(−2) = −0.2384，得 [−0.2384, 0.4768]。(2) 形状都对，它们只是另一个可训练的函数，训练照样进行，效果变差。`test_swiglu_fixed_weights_distinguish_gate_and_activation` 用固定权重和独立写出的公式对拍，能抓到。

**9.8** (1) 和 9.2.4 节一致：无残差的 8 层模型停在 5.4778 nat/token，比 unigram 的 5.4230 还差（本项目观察，第 2 部分）。(2) 把分支参数全置 0：正确的块输出精确等于输入；错误的块输出全 0。`-k zero_branches` 会失败。(3) 0.9668（本项目观察，第 8 部分）。输出全 0，所以"输出减输入"就是负的输入，这个差的 RMS 等于输入本身的 RMS。
