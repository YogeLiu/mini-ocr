# 第 9 章实验手册：Transformer 块

## 0. 准备

在 `course-v4/` 下运行：

```bash
CUDA_VISIBLE_DEVICES="" python -m book.part2_lm.ch09_block.tour
CUDA_VISIBLE_DEVICES="" python -m pytest -q book/part2_lm/ch09_block
```

也可以在模块名后指定部分号，例如 `3 5 6`。脚本只用 CPU，两条计算线程。只读本地 LaTeX 缓存，不联网、不安装包、不保存模型权重。缺少缓存时会警告并使用内置样例；样例输出只检查流程，不能当作真实语料成绩。图片保存在 `outputs/book/ch09/`，重跑同名实验会覆盖图片，先保存自己需要的版本。

默认训练配置为维度 64、一个头、上下文 16、批量 64、600 步、随机种子 0。每种对照重新设同一个初始化种子，抽取相同的目标批次。AdamW 的权重衰减为 0.0100，无预热、无梯度裁剪，使用 fp32。第 4 部分默认在共同学习率 0.0030 和 0.0200 下各训练一对 Pre/Post，其他部分为 0.0030。脚本逐模型打印实际参数量和配置。更改层数、步数或窗口会改变耗时；四分钟预算针对默认完整 tour。

### 数据与评测口径

共用工具是 `miniocr/data/latex_lm.py`。它在 `latex-v1` 标准训练集前 20000 条上训练 2000 次合并的 BPE，只加入 BOS 和 EOS；每次重新训练，不使用磁盘缓存。第 7 章原脚本保持不变。第 8 章迁移了滑窗索引与评测循环，旧入口仍可调用；迁移前后的第 11 部分完整重跑，除了计时，输出逐行一致。

每条公式的内容被包成 `BOS … EOS`。`encode_formulas` 可以返回逐条序列，或返回拼接的长 id 流，并一起返回原文 UTF-8 字节数。若使用长流训练，要忽略跨公式的 BOS 目标；BOS 只作条件，不属于输出分布。本章训练采用逐目标窗口，不跨公式。

第 4 部分还直接统计训练目标的 token 频率，重算 unigram 基线：内容 token 与 EOS 计数、排除 BOS，候选平滑参数 `k=(1, 0.1, 0.01, 0.001)` 按验证 nat/token 选最小，与第 7 章 tour 第 4 部分一致。第 7 章参考值为 5.4230 nat/token；本次同口径重算也是 5.4230（k=0.1），bits/byte 为 3.9108。若本地数据不同或降级为样例，脚本以本次重算值比较。

最终验证固定使用 val 的前 2000 条。每个内容 token 和 EOS 都恰好作为一次目标，BOS 输出屏蔽为负无穷。长公式用逐目标滑窗，每次保留最近的 context 个输入；超出上下文只丢旧条件，不丢评测目标。每个窗口的位置从零开始，右侧补齐不会被真实位置的因果注意力读到。

`nat/token = 所有目标的 NLL 总和 / 目标数`；`bits/byte = NLL 总和 / (ln(2) × 原文字节数)`。原文字节不含 BOS/EOS，不按公式等权平均，不拿随机验证批次冒充全量结果。`evaluate_latex` 接收返回 logits 的模型，也兼容 GPT 的 `(logits, loss)`；可传 `window_logits` 回调只投影最后一个真实位置。函数临时切换 eval 模式，结束后恢复原模式。

### 对照边界

第 1 部分沿用第 8 章的 `AttentionLM` 类，但按本章共同配置重新短训。它与 Decoder 块的比较同时改变了残差、归一化、前馈和注意力投影偏置，不是“只加前馈”消融。两者都有学习式位置嵌入。块的 RoPE 设为恒等变换，具体位置编码留给第 10 章。

本章用部件默认初始化，嵌入初始化与第 8 章一致；不采用完整 GPT 的共享嵌入和残差输出缩放初始化，后者留给第 11 章。Pre/Post-Norm 对照使用同一种 RMSNorm、相同参数初值、相同 final norm，仅交换块内归一化的位置。有无残差的对照也保持初始参数相同。GELU/SwiGLU 对照保留相同的嵌入、注意力、归一化和输出层初值，但两个前馈的参数形状不同，不能逐项共享权重。

所有训练结果都是一次种子、有限预算下的观察，不是架构排名。增加步数、改变学习率或初始化，结论可能改变。初始化诊断使用固定输入与固定随机线性读出，没有 final norm；它测量某个读出方向的梯度，不能直接等同于实际语言模型 loss 的梯度。

  归一化维度=时间维（错误）；改未来后过去是否变化=True；过去最大差=2.4778

  归一化维度=只沿batch维（错误）；改未来后过去是否变化=False；过去最大差=0.0000
  只沿 batch 维不会混入未来，但会串样本；改另一条样本后本样本最大差=2.0000

  fp16 直接均方=inf；错误输出=[0.0000, 0.0000, 0.0000, 0.0000]；fp32 内部计算输出=[0.6470, 0.8628, 1.0781, 1.2939]

### 怎样读这些结果

残差提供一条导数为恒等映射的直接通路，但总梯度仍取决于分支导数。无残差网络中，RMSNorm 会重新调整尺度，所以不保证输入梯度随层数单调衰减。应同时查看梯度、训练曲线和验证 loss。接近 unigram 的验证 loss 只能说明这次优化没有学好条件分布，不能单凭它诊断某一层的梯度消失。

Pre-Norm 残差流可以随深度增长，Post-Norm 在块末尾重新归一化，输出 RMS 自然受约束。参数梯度的“底层/顶层”比值还受输入尺度和读出方向影响；比值大不自动代表更容易训练。本次共同学习率 0.003 下，Pre 的验证 nat/token 为 4.4118，Post 为 5.4765，差值为 1.0647；只有 Pre 低于 unigram 5.4230，仍未得到“两者都学好条件分布”的对照。共同学习率 0.02 下，两者都高于 unigram，差值仅 -0.0020，应记录“本次差异不明显”，不能把两者都没学好解释为结构等价。阈值 `|Post-Pre| > 0.1 nat/token` 只用于描述本次差距，不是统计显著性检验。

SwiGLU 的门与 up 支路不同：只有 gate 经过 SiLU，负 gate 不会像 ReLU 一样全部归零。无偏置 GELU-MLP 有两个矩阵，参数量为 `2dh`；SwiGLU 有三个，参数量为 `3df`。理想的 `h=4d, f=8d/3` 参数相等；`ff_dim()` 向上取整到 64 的倍数后，小模型偏差比较明显。本章训练把 GELU 中间维设成 `3f/2`，精确对齐实际前馈参数量，因此它不一定恰好是 `4d`。

归一化沿时间维会读取未来；同时沿 batch 和时间维也会。只沿 batch 维不会混入未来时间，但会让一条样本受同批其他样本影响。脚本分别打印这两类现象。bf16 的参考误差从同一份已经量化的输入计算，转 fp32 只能改善后续运算，不能恢复已经丢失的输入细节。fp16 平方溢出还可能得到全零输出，而不一定立刻出现 NaN。
