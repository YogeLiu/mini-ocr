## 答案与提示

### 概念题要点

**11.1** 残差流的尺度随层数和训练变化；最后归一化把它拉回 RMS ≈ 1，让输出层面对稳定的输入尺度（第 9 章 9.8 节）。初始化时残差流 RMS 很小（第 9 部分是 0.0563），漏掉归一化会让 logits 更接近 0、softmax 更接近均匀，初始 loss 反而更接近 ln V，所以看不出来；只能靠和参考实现对拍（第 9 部分 logits 最大差 2.5197）。

**11.2** RoPE 的 cos、sin 表是由公式算出来的缓冲区，不是可训练参数。学习式位置嵌入要加 T_max·d 一项（GPT-2：1024 × 768 = 786,432）。

**11.3** 输入端按编号取一行（查名片）；输出端拿 h 和每一行做点积（按内容找名片）。输入端只有出现过的 token 那一行有梯度；输出端每一步对全部 V 个类别算 softmax，每一行都有梯度 (pᵢ − yᵢ)·h。共享后稀有 token 那一行每步都能从输出端更新。

**11.4** `parameters()` 按对象去重，共享矩阵只算一次；`state_dict()` 按名字列出，共享矩阵以 `tok.weight`、`head.weight` 两个名字出现两次，多算 V·d。不共享时两者都是 2·V·d + …，相同（前提是没有持久化的缓冲区；本书的 cos、sin 用了 `persistent=False`，不在 `state_dict` 里）。

**11.5** 随机模型对下一个 token 毫无信息，最好的情况是均匀分布，loss = ln V。实际 logits 是小随机数，log-sum-exp 是凸函数，由詹森不等式 E[log Σ exp(z)] ≥ log Σ exp(E[z]) = ln V，且正确类别的 logit 期望为 0，所以期望 loss ≥ ln V，近似多出 σ²/2。这只是假设下的**期望**：单次实测、单个批次可以低于 ln V；共享权重时输出层和隐藏状态并不独立，假设本身也会被打破（例如标签等于输入，或数据里有大量重复 token）。

**11.6** 只有 `o`、`down` 的输出直接加进残差流；其他矩阵的输出要经过注意力或门控，再由这两个矩阵投影回来，缩放最后一层就控制了每个支路"写入"的大小。每个块有两个残差支路，L 个块共 2L 次相加，所以按 2L 缩放；这是本书与 nanoGPT 的约定，GPT-2 报告只写"残差层数 N"。

**11.7** 固定批次是故意让模型背题，只检查"训练链路能否把 loss 往下推"。正常训练每步都是新数据，语言本身有不确定性，loss 有合理下限；远低于预期说明模型看到了答案，要查标签和 mask。

**11.8** 标签未错位时，答案就在当前位置的嵌入里，残差流原样带到输出层，共享权重下几乎是现成的；全可见 mask 时，答案在下一个位置，模型必须学会让注意力精确地看向 t+1，这需要优化，所以下降慢得多。另外，最后一个位置的目标在输入窗口之外，没有答案可抄，只能靠真正的预测去降，所以光靠复制不能保证整体 loss 接近 0。

**11.9** 本书数据端已错开一次，接到内部再错开的模型上 → 位置 t 预测第 t+2 个 token；对 LaTeX 通常 loss 偏高，但方向没有保证（交替序列 a, b, a, b 上第 t+2 个就等于当前 token）。反过来，把"labels = input_ids"式的数据接到本书不错位的 forward 上 → 目标等于输入，loss 低得可疑。后者是 11.8.2 节的故障。

**11.10** `inputs_embeds`。块、最后归一化、输出层都不用改；只要送进来的向量形状是 (B, T, d)，并且总长度不超过 block_size。

### 编程题提示

**11.1** 先写 q、k、v 的 `view(B, T, heads, dh).transpose(1, 2)`；Q/K norm 在 RoPE **之前**；cache 存的是 `repeat_kv` **之前**的 k、v；mask 用 `torch.ones(T, past + T, dtype=torch.bool).tril(past)`，True 表示可见。manual 路径调用第 8 章的 `attention(q, k, v, mask)`。

**11.2** 别忘了 `self.norm`；pos0 的断言写 `pos0 + T <= block_size`；用 `targets.masked_fill(~loss_mask, -100)` 生成新张量；交叉熵前 `.float()`。测试 `test_gpt_reference_rejects_missing_norm_and_residual` 能抓住漏掉的归一化和残差。

**11.3** f 用 `cfg.ff_dim()`，别写成 4d；共享时输出层贡献 0。遇到 `cfg.kv_heads() != cfg.n_head`（GQA）或 `qk_norm=True` 时抛 `ValueError`，不硬算。注意不要直接比较 `n_kv_head`：它的默认值 0 表示"等于 n_head"。

**11.4** 原始 loss 直接用 `model(x, y, loss_mask=y != bos)`；屏蔽 BOS 输出时把 `logits[..., bos]` 设为 −inf，再只在 `y != bos` 的位置算交叉熵。阈值可以参考 σ²/2：本书配置约 0.05，设成 0.2 或 0.5 都能放过正常值、抓住 std 0.2（差约 4.7）。

**11.5** 用 `torch.equal` 或"最大差 == 0"判断，而不是 `allclose`：正确实现的过去 logits 应逐比特相同（第 7 部分恢复后最大差 0.0000）。切点随机选，是为了避免 mask 只在某个固定位置附近出错时漏检。

**11.6** 断言写在数据函数返回之前。共享权重时，标签等于输入会让第 1 步 loss 低于 ln V，原因见手算题 11.8。

**11.7** 不缩放版可以像 `part5` 一样，把缩放版的 `o`、`down` 乘回 √(2L)；除以 √L 的版本则乘 √2。三者共用同一组随机方向，只差尺度。
