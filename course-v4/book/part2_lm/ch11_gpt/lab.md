# 第 11 章实验手册：搭建 GPT 与初始化

## 0. 准备

在 `course-v4/` 下运行：

```bash
CUDA_VISIBLE_DEVICES="" python -m book.part2_lm.ch11_gpt.tour
CUDA_VISIBLE_DEVICES="" python -m pytest -q book/part2_lm/ch11_gpt
```

模块名后可指定部分号，例如 `2 3 4`。脚本只使用 CPU、两条计算线程、fp32；不联网、不安装、不下载模型、不保存权重。所有实验证据输出到终端，保留日志即可复查。缺少本地语料缓存时，共享数据工具会警告并降级为样例；样例成绩不能与本手册的真实语料结果比较。

默认种子为 0，AdamW 学习率 0.0030、权重衰减 0.0100，无预热、无梯度裁剪、dropout 为零。第 1、2、4、9 部分使用本书配置：实际词表大小、上下文 128、4 层、4 头、维度 256、默认 SwiGLU 中间维 704。第 3 部分为便于检查梯度，缩小为 1 层、维度 32；第 5 部分使用维度 64。第 6 部分固定 8×64 的批次，2 层、维度 128，训练恰好 200 步。

第 7 部分三组对照均为 2 层、维度 96、4 头、上下文 16、批量 16、350 步；共同参数初值和抽样随机种子相同。第 8 部分默认 1 层、维度 64、4 头、上下文 32、批量 16、200 步，可用 `--layers`、`--dim`、`--context`、`--batch`、`--steps`、`--lr`、`--init-std`、`--untied` 修改。`--fault-steps` 控制第 7 部分步数。第 7 部分每组训练有 25 秒预算，第 8 部分训练有 45 秒预算；若触发上限会明确打印实际步数，比较时必须核对。默认完整运行未触发任何提前停止，四分钟预算包含数据准备与全量验证。扩展实验可能更慢。

### 数据与评测口径

数据来自 `miniocr/data/latex_lm.py`：`latex-v1` 标准训练集前 20000 条、2000 次 BPE 合并、仅加 BOS/EOS。每次重新训练分词器。本次实际词表为 2258；验证使用 val 前 2000 条，共 119750 个目标、239566 个原文 UTF-8 字节。测试集不参与。

训练随机抽取 `BOS…EOS` 拼接流的 T+1 个 token，输入为前 T 个，目标为后 T 个。忽略 BOS 目标；EOS 计入。这个训练近似允许跨公式上文。`GPT.forward` 不屏蔽 BOS 输出类别，所以训练分母仍包含 V 个类别，初始 loss 对照 `ln V`。第 4 部分额外打印屏蔽 BOS 后的 loss，与 `ln(V−1)` 比较。不要把“忽略 BOS 目标”和“屏蔽 BOS 输出概率”当作同一个操作。

验证严格采用第 7 章口径：逐公式重置，BOS 只作条件且屏蔽输出，内容 token 与 EOS 各计一次，按目标数加权。长公式逐目标滑窗，每个窗口只保留最近的 context 个输入、位置从零开始；不截掉评测目标。窗口右补齐不影响真实位置的因果前向。`last_logits` 只投影最后一个真实位置，已有测试与完整 GPT logits 对拍。

`nat/token = NLL 总和 / 目标数`；`bits/byte = NLL 总和 / (ln(2) × 原文字节数)`。字节数不包含 BOS/EOS。第 4 部分只检查一批 val 的初始 loss，不把它当作全量验证成绩。第 7、8 部分才遍历全部验证目标。

### 对照边界

参数公式只覆盖本章普通 MHA、无 Q/K norm 的配置。GPT-2 按同样的“词嵌入＋位置嵌入＋逐块项＋最后归一化＋输出层”逐项计数，但换成含偏置的注意力、4d GELU MLP、含 β 的 LayerNorm 和学习式位置。输出 head 无偏置且与词嵌入共享，不能重复计数。

本地 Qwen3.5-0.8B 配置含线性注意力、注意力输出门、视觉分支等部件。脚本只读取指定缓存目录中的 `config.json`，打印字段与快照路径，标注“第 32 章再讲”，不加载权重，也不把这些层硬套本章公式。

第 3 部分先复制权重数值到不共享模型，分别求嵌入路径和输出路径的梯度，再验证它们之和等于共享参数的梯度。它展示同一损失的两条反传路径，不声称共享模型和随机初始化的不共享模型训练轨迹相同。

第 4 部分的 1.0、0.2 故障初始化将所有唯一矩阵重采样并取消残差缩放，故同时改变初始标准差与输出缩放。实验一用 `--init-std` 时则始终保留残差缩放，单独比较标准差。零 head 的演示使用独立输出层，避免把共享嵌入一起清空。

第 5 部分缩放与不缩放版共用同一随机方向，后者把两条残差支路输出矩阵乘回 √(2L)。这与重新采样 std=0.02 的分布相同，同时减少对照的随机差异。各层 RMS 不必单调；这里观察的是归一化之前的残差流，不是最终 logits。

第 7 部分仅在局部上下文管理器中注入全可见 mask，结束后恢复正确前向。训练时标签位于输入的下一个位置，除最后一位外都可能泄漏；全可见不意味着优化器会立即学会复制下一位。两种故障最终都用正确错位目标、正确因果设置评测。固定一批的低 loss 则是有意记忆训练样本，不属于泄漏故障。

## 3. 实验一：初始化标准差与前 200 步

**预测：** 把矩阵标准差从 0.002 改到 0.02、0.2，最初的 loss、logits 标准差和第 200 步的 loss 分别会怎样变化？过小是否一定更好？写出理由。

**运行：**

```bash
CUDA_VISIBLE_DEVICES="" python -m book.part2_lm.ch11_gpt.tour 8 --steps 200 --init-std 0.002
CUDA_VISIBLE_DEVICES="" python -m book.part2_lm.ch11_gpt.tour 8 --steps 200 --init-std 0.02
CUDA_VISIBLE_DEVICES="" python -m book.part2_lm.ch11_gpt.tour 8 --steps 200 --init-std 0.2
```

三组保留相同残差缩放、种子和数据批次，只改标准差。这里重采样唯一矩阵一次，所以显式 `--init-std 0.02` 不保证与省略该参数时的随机数轨迹相同；比较应使用上面的三条显式命令。

**观察：** 记录第 1、10、50、100、200 步的当前批次 loss，以及全量 val nat/token、bits/byte。当前批次 loss 会波动，不是全训练集均值。第 4 部分可补充 logits 尺度的诊断；不要把其“无缩放”故障直接当作本实验的单变量对照。

**记录：** 填写初始标准差、实际步数、曲线点、验证值和用时。若有非有限值，原样记录，不换种子删去失败结果。

## 4. 实验二：共享与不共享输出权重

**预测：** 不共享增加 V·d 个参数之后，训练 loss 与验证 loss 会一起改善吗？更多参数和更少约束可能分别带来什么？

**运行：**

```bash
CUDA_VISIBLE_DEVICES="" python -m book.part2_lm.ch11_gpt.tour 8 --steps 200 --init-std 0.02
CUDA_VISIBLE_DEVICES="" python -m book.part2_lm.ch11_gpt.tour 8 --steps 200 --init-std 0.02 --untied
```

**观察：** 两组共同模块使用相同的初始化随机序列；不共享模型另采样独立 head。默认词表 2258、维度 64 时，参数从 197952 增至 342464，多 144512。训练目标批次、步数和学习率保持一致。验证使用相同公式、相同目标与字节数。

**记录：** 同时写参数总数与 val 指标。该对照改变了参数量和共享约束，不是同预算架构排名；一次种子也不足以支持普遍结论。可重复种子 1、2，但不要只保留最好的结果。

## 5. 实验三：相同参数量下改变 L 与 d

**预测：** 在精确相同参数量下，较深较窄与较浅较宽的模型，训练速度、前 200 步和验证结果是否相同？注意固定步数不等于固定计算量。

**运行：** 本次 V=2258 时，默认 `ff_dim()` 给出以下精确匹配：

| 层数 L | 维度 d | 中间维 f | 总参数 |
|---|---|---|---|
| 13 | 88 | 256 | 1482360 |
| 7 | 120 | 320 | 1482360 |

```bash
CUDA_VISIBLE_DEVICES="" python -m book.part2_lm.ch11_gpt.tour 8 --layers 13 --dim 88 --steps 200
CUDA_VISIBLE_DEVICES="" python -m book.part2_lm.ch11_gpt.tour 8 --layers 7 --dim 120 --steps 200
```

**观察：** 先核对打印的参数量确实相等，再看训练和验证。这两组都使用 4 头，每头维度分别为 22、30，均满足 RoPE 偶数要求。若语料降级或词表变化，上表不再保证相等，先用公式重新选配置。扩展实验耗时比默认单层模型更长；若时间预算导致实际步数不同，不能称作同训练步数比较。

**记录：** 写出两组的嵌入参数、每块参数、总参数、实际训练步数、训练和验证用时。说明你控制了参数预算，但仍改变了嵌入占比、深度、头维度和优化难度。

## 6. 故障演练：标签没错开一位

**预测：** 对于序列 `[BOS, a, b, EOS]`，输入和正确目标各是什么？若目标直接复制输入，为什么形状检查能通过，loss 却会产生误导？

**运行：**

