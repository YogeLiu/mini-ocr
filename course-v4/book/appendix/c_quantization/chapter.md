# 附录 C 量化

本附录了解即可。读完你能说出量化误差从哪里来，也能回答 QLoRA 用了哪种量化。

实验在 `tour.py`，全部在 CPU 上运行。权重是 tiny 模型的随机初始化，GPTQ、AWQ 只用小矩阵演示思路，没有量化真实模型，也没有评测准确率。文中“第 k 部分”指 tour 的第 k 部分。

> **回顾：** 16.1 讲过浮点格式。20.8 讲过 LoRA 的显存账。20.9 讲过 QLoRA 把基座存成 4 bit。20.6.4 提醒过量化基座不宜合并。

## C.1 动机

Qwen3-0.6B 的权重，fp32 约 2.22 GiB，4 bit 约 0.28 GiB（20.9.2）。对大模型来说，权重常常是显存里最大的一项。

代价是精度。int4 只有 16 个值，要用这 16 个值表示一整个矩阵的权重。误差有多大？怎样放这 16 个值才划算？

## C.2 直觉

量化就像把身高记录改成“只准写整数厘米”。

- 刻度间隔越小，误差越小，但要的位数越多。
- 班里来了一个 3 米高的人，又坚持只用 16 个刻度，所有普通人都挤到一两个刻度上。这是离群值的问题。
- 如果你更关心某些人的数据，可以给他们更细的刻度。这是 AWQ 的想法。
- 前一个人记高了，后一个人可以故意记低一点，让总和接近。这是 GPTQ 的想法。

## C.3 推导

### C.3.1 线性量化

b 位整数的范围是 [q_min, q_max]。int8 是 [−128, 127]，int4 是 [−8, 7]。

- 量化：q = clamp(round(x/s + z), q_min, q_max)
- 还原：x̂ = (q − z) · s

s 是 scale（缩放，相邻两个刻度之间的间隔），z 是 zero point（零点，实数 0 对应的整数）。

**非对称：** 先取 lo = min(x, 0)，hi = max(x, 0)，让 0 落在范围内。s = (hi − lo)/(q_max − q_min)，z = round(q_min − lo/s)。若张量全零，hi = lo，s 会算成 0，必须特判；tour.py 的做法是令 s = 1。

**对称：** z = 0，s = max|x| / q_max。全零张量同样要特判。

同一组数，位数少 4 位，非对称的 s 变大 255/15 = 17 倍（数学结论）：int8 的 q_max − q_min 是 255，int4 是 15。

### C.3.2 误差上界

对范围内的 x，round 最多差 0.5，乘回 s 就是：

|x − x̂| ≤ s/2（数学结论）

z 取整后，刻度整体可能偏移，x 的端点可能算到 q_min − 0.5 或 q_max + 0.5 附近，再被截断。截断后误差仍是 0.5 个刻度，上界不变。

误差大致在 [−s/2, s/2] 上均匀分布时，均方误差约为 s²/12（近似，假设误差均匀）。s²/12 就是长度为 s 的区间上均匀分布的方差。

所以误差来自两处：**舍入**，由 s 决定；**s 本身的大小**，由位数和数值范围决定。

### C.3.3 GPTQ：把误差传给后面的列

看一层线性层的输出 WX。X 是输入，形状（通道，样本）。我们关心的是输出误差：

‖(Ŵ − W)X‖² = tr(E H Eᵀ)，其中 E = Ŵ − W，H = XXᵀ

这一步用了 Frobenius 范数的性质 ‖A‖² = tr(AAᵀ)，取 A = EX。H 的第 (i, j) 个元素是第 i、j 个输入通道的内积，衡量两个通道有多相关。

逐个取整时，各列的误差各管各。如果两列输入相关，一列的误差可以由另一列抵消。

GPTQ 逐列处理。量化第 c 列，误差 e = ŵ_c − w_c。还没量化的列 F 按最小二乘更新：

δ_F = −e · H[c, F] · H[F, F]⁻¹

这样 ‖e x_c + δ_F X_F‖² 最小（数学结论）。这里 x_c 是 X 的第 c 行，X_F 是 F 对应的那些行。这是一个关于 δ_F 的最小二乘问题，令导数为 0 得到 δ_F X_F X_Fᵀ = −e x_c X_Fᵀ，再用 H 的分块写出来就是上式。这里假设 H[F, F] 可逆，通道完全相关或校准样本太少时不成立，实际实现会先给 H 的对角线加一点阻尼。Frantar et al.（2022）用这个思路，并用 Cholesky 和批处理让它跑得动。本书只写最小实现。

### C.3.4 AWQ：给重要的通道更细的刻度

输入激活大的通道，权重误差会被放大。AWQ 先用 s 放大这些通道的权重，再量化，再缩回去：

Ŵ = Q(W · diag(s)) · diag(s)⁻¹，sᵢ = (平均|xᵢ|)^α

这里的 s 是每个输入通道一个的放大系数，和 C.3.1 的刻度间隔 s 不是同一个量。设放大前组的刻度间隔是 Δ，放大后变成 Δ′，这个通道放大了 s 倍，缩回去后它的有效间隔是 Δ′/s。只有 Δ′/s < Δ 时它才变细；如果它本来就决定了组的最大值，Δ′ ≈ sΔ，精度并不改善。组的间隔变大时，同组其他通道变粗。所以缩放是否有利要实测，C.4.5 里 α = 1 就比不缩放差。α = 0 是普通量化，α 用网格搜索。

GPTQ 和 AWQ 都要用校准数据收集 X 的统计量（论文报告）。

### C.3.5 QLoRA 用了哪种量化

**QLoRA 用 NF4（4-bit NormalFloat），加双重量化。**（Dettmers et al., 2023，论文报告。）

- 它和 C.3.1 的 int4 都是 16 个值。int4 的刻度等距。NF4 按正态分布的分位数放刻度，为权重近似正态的情况设计。
- 双重量化把各块的缩放常数也量化一次。
- 它和 GPTQ、AWQ 是不同路线：QLoRA 量化的是冻结的基座，用来训练 LoRA；GPTQ、AWQ 主要面向推理。

分块的大小、常数的位数、`bitsandbytes` 的具体行为，以及 NF4 是否需要校准数据，本书都没有验证（待验证）。本书也没有写 NF4 的实验，C.4 的 int4 数字不能代替 NF4。

## C.4 数值例子

### C.4.1 手算

x = [−1, 0, 0.5, 1]，int4，非对称（数学结论，第 1 部分）：

1. lo = −1，hi = 1，s = 2/15 = 0.1333。
2. z = round(−8 + 7.5) = round(−0.5) = 0。舍入到偶数。
3. q = [−8, 0, 4, 7]。
4. x̂ = [−1.0667, 0, 0.5333, 0.9333]。
5. 最大误差 0.0667 = s/2，恰好碰到上界。

对称时 s = 1/7，q = [−7, 0, 4, 7]，x̂ = [−1, 0, 0.5714, 1]，最大误差 0.0714 = s/2。

### C.4.2 tiny 模型的权重

tiny：V = 512，139,584 个参数，随机初始化，非对称（本项目观察，第 2 部分）：

| 张量 | 位数 | s/2 | 最大误差 | MSE | s²/12 | 相对误差 |
|---|---:|---:|---:|---:|---:|---:|
| tok | 8 | 3.0715 × 10⁻⁴ | 3.0714 × 10⁻⁴ | 3.132 × 10⁻⁸ | 3.145 × 10⁻⁸ | 0.89% |
| tok | 4 | 5.2216 × 10⁻³ | 5.2215 × 10⁻³ | 9.116 × 10⁻⁶ | 9.088 × 10⁻⁶ | 15.1% |
| attn.q | 8 | 2.7320 × 10⁻⁴ | 2.7320 × 10⁻⁴ | 2.486 × 10⁻⁸ | 2.488 × 10⁻⁸ | 0.79% |
| attn.q | 4 | 4.6445 × 10⁻³ | 4.6423 × 10⁻³ | 7.216 × 10⁻⁶ | 7.190 × 10⁻⁶ | 13.5% |

全部矩阵的最大误差都没有超过 s/2：最大误差与上界的比，最大值 int8 为 0.99998，int4 为 0.999999。

误差除以 s/2，分成 10 格，每格占比都在 0.098 到 0.103 之间（本项目观察，第 3 部分），接近均匀。MSE 和 s²/12 也很接近。

### C.4.3 离群值

把 `mlp.gate` 的一个权重改成最大绝对值的 10 倍，用对称量化（本项目观察，第 4 部分）：

| 位数 | 原样 MSE | 改后，整张量一个 s | 改后，每行一个 s |
|---:|---:|---:|---:|
| 8 | 2.91 × 10⁻⁸ | 2.87 × 10⁻⁶ | 2.98 × 10⁻⁸ |
| 4 | 9.53 × 10⁻⁶ | 3.92 × 10⁻⁴ | 6.84 × 10⁻⁶ |

一个离群值让 s 变大 10 倍，MSE 变大约 100 倍（int8）。细化 s 的粒度，影响就被关在一行里。

把全部矩阵量化后看 logits（随机模型，B = 2，T = 32，本项目观察，第 5 部分）：相对差 int8 为 1.27%，int4 为 21.7%。argmax 都没变。随机模型的结果不代表训练好的模型，这里只看量级。

### C.4.4 GPTQ

W = [0.6, 0.6]，H = [[1, 0.5], [0.5, 1]]，刻度间隔 1（数学结论，第 6 部分）：

- 逐个取整：Ŵ = [1, 1]，E = [0.4, 0.4]。输出误差 0.16 + 0.16 + 2·0.5·0.16 = **0.48**。
- GPTQ：第一列取 1，e = 0.4。第二列更新 −0.4 · 0.5/1 = −0.2，从 0.6 变成 0.4，取整到 0。E = [0.4, −0.6]。输出误差 0.16 + 0.36 − 2·0.5·0.24 = **0.28**。

第二列单看误差变大了，输出误差却变小了。

再用 W 为 4 × 8、X 为 8 × 64 的相关输入试五次，int4 刻度（本项目观察，第 6 部分）：GPTQ 与逐个取整的误差比在 0.06 到 0.57 之间，五次合计 0.358。这组 X 是故意造得相关的。

### C.4.5 AWQ

W = [0.1, 1]，X = [[10, 0], [0, 0.1]]，平均绝对激活 [5, 0.05]，int4 每行对称（数学结论，第 7 部分）：

| α | s | Ŵ | 权重误差 | 输出误差 |
|---:|---|---|---|---:|
| 0 | [1, 1] | [0.1429, 1] | [0.0429, 0] | 0.18367 |
| 1 | [5, 0.05] | [0.1, 1.4286] | [0, 0.4286] | 0.0018367 |

重要通道的误差没了。不重要通道的权重误差变成 0.4286，但它的激活很小，输出误差只有原来的 1/100。

再用 4 × 8 的随机矩阵，八个通道的幅度从 20 到 0.1（本项目观察，第 7 部分）：α = 0.2 最好，误差是 α = 0 的 0.117 倍；α = 1 时是 1.655 倍，比不做还差。所以 α 要搜索。

## C.5 代码

量化和还原只有几行：

```python
def quantize(x, scale, zero_point, bits):
    qmin, qmax = qrange(bits)
    return (x/scale+zero_point).round().clamp(qmin, qmax)

def dequantize(q, scale, zero_point):
    return (q-zero_point)*scale
```

GPTQ 的一步对应 C.3.3 的公式：

```python
out[:, col] = round_to_grid(w[:, col], step, qmax)
rest = list(range(col+1, w.shape[1]))
if rest:
    e = (out[:, col]-w[:, col]).unsqueeze(1)
    update = torch.linalg.solve(H[rest][:, rest], H[col, rest])
    out[:, rest] = w[:, rest]-e*update
```

AWQ 先放大，再量化，再缩回：

```python
s = awq_scales(x, alpha)
return per_row_roundtrip(w*s, bits)/s
```

这些函数把整数存在浮点张量里，只为验证误差，不省内存。真实的 int4 要打包存储，本书没有实现。

## C.6 常见错误

| 错误 | 现象 | 怎样发现 |
|---|---|---|
| 把 int4 的结论直接用到 NF4 | 误差估计不对 | 两者刻度不同（C.3.5） |
| 只算 0.5 字节/参数 | 实际占用偏大 | 还要加 scale 常数和不量化的层（20.9.2） |
| 整个模型共用一个 s | 少数离群值毁掉全部精度 | 打印每个张量的 s（C.4.3） |
| 范围没包含 0 | 0 不能精确表示 | 检查 lo ≤ 0 ≤ hi（第 1 部分） |
| 把 LoRA 直接合并回 4 bit 基座 | 合并后再量化到低比特，增量可能被舍入掉，指标可能下降（不是必然） | 区分保持高精度合并与合并后再量化，后者要重新评估；合并接口按版本核验（20.6.4） |
| 把 GPTQ、AWQ 的小矩阵比例当成真实模型的结论 | 高估收益 | 本附录的 X 是构造的；真实模型要测 |

## C.7 小结

- 线性量化：q = clamp(round(x/s + z), q_min, q_max)，x̂ = (q − z) · s。对称时 z = 0，s = max|x| / q_max。误差来自舍入，范围内上界是 s/2，误差近似均匀时 MSE ≈ s²/12。s 由位数和数值范围决定，同一组数做非对称量化，int4 的 s 是 int8 的 17 倍。
- tiny 模型上实测误差没有超过上界，分布接近均匀，MSE 接近 s²/12。
- 离群值会放大 s，细化 s 的粒度（比如每行一个 s）可以把影响关在一行里。
- 真正要压的是输出误差 tr(E H Eᵀ)，H = XXᵀ。GPTQ 利用输入通道的相关性，把已量化列的误差用最小二乘传给后面的列；AWQ 用 Q(W · diag(s)) · diag(s)⁻¹（这里 s 是按通道的放大系数）给激活大的通道更细的刻度，α 要搜索。
- QLoRA 用 NF4 加双重量化，量化冻结的基座，用来训练 LoRA。int4 的数字不能直接套到 NF4 上。
- 最常见的错误：整个张量共用一个 s，被一个离群值拖垮；只按 0.5 字节/参数估 4 bit 显存，忘了缩放常数和不量化的层。
